# T-419 — 公式サイト docs「チーム（Enterprise）」の支払い文言 (請求書はカードでも払える)

Worker 側 (desktop リポジトリ) で請求書経路の Subscription に
`payment_settings[payment_method_types] = [customer_balance, card]` を入れたので、
**Stripe のオンライン請求書ページで銀行振込とクレジットカードのどちらでも払える**ようになった。
サイトの説明が「請求書払い＝銀行振込」のままだと、実際にできることより狭い案内になる。

## 注意点・既知の制約

- **公開の順序**: サイトだけ先に出すと、Worker が未デプロイの間は
  「カードで払える」と書いてあるのに請求書ページにカードが出ない状態になる。
  **Worker (desktop/worker-auth0-updater) を本番に出してからサイトを公開すること。**
  すでに v3 で発行済みの請求書にはカードが出ない (作り直しが要る) 点も同じ。
- `_data/plans.yml:226` の料金ページ「支払方法」行は今も
  `クレジットカード払い、請求書払い（銀行振込）` のまま。**T-419 の指定範囲外なので触っていない**が、
  docs と食い違うので別チケットで揃えたい。直すときは
  `src/lib/plans-payment.test.js` が現在の文言を完全一致で固定しているので、テストも同時に更新する。
- `contact/index.html` / `enterprise/inquiry/index.html` の「請求書払い・銀行振込のご希望は」は
  **問い合わせの入口の文**で支払手段の約束ではないため、変更していない。
- `_site/` 配下は Jekyll のビルド成果物。ソース (`_includes/`) だけを直している。
