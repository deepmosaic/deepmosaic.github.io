## 解約の「月の末日」を個人と法人で分けた理由
- 計画の文言は「プロフィールメニューの決済ポータルから。請求書払いの法人契約はメールで」。
- 個人向けは docs (`_includes/docs/02-account.html`「解約の予約」) のとおり、解約後もプロフィールメニューに「〇〇 まで有効」が出て
  期限 (= 支払済みの契約期間の末日) までは有料プランのまま。旧文「解約手続きを行った月の末日にサービス提供が終了」は個人では不正確。
- 法人は asct「支払いの時期及び方法」の「毎月 1 日に当月分をご請求」(暦月課金) に合わせ、申出月の末日で提供終了・請求停止とした。
  plans.yml の Enterprise 記述に食い違う記載は見当たらなかった。
