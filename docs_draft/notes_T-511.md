## 変更点

- **`_includes/docs/web.html`**
  - 新しい節 3 つ (目次にも追加):
    - `#home`「ホーム画面の分類」: フォルダ (サブフォルダ・「フォルダへ移動」・ドラッグ・「すべての動画」へのドロップで分類解除)、
      タグ (カードのメニューで付け外し、「タグで絞り込み」)、「他のフォルダ」の行と「このプロジェクトフォルダに切り替える」。
      web 固有: 分類はブラウザ内 (OPFS の `library.json`) で Desktop 版とは共有されない / 複数タブは最後に保存したタブが残る
      (web はタブ内の書込直列化だけ、desktop-parity T-383) / カードのメニューに「プロジェクトフォルダを開く」「Premiere Pro」
      「プロジェクトをコピー」は無く「検出データをダウンロード」がある。
    - `#timeline`「タイムライン編集」: 操作は Desktop 版と同じ (サイドバー 6 種、トリム・分割・並べ替え・削除、空白、テキスト、音声)。
      素材は「メディアをインポート」か編集ページへのドロップで取り込み、ブラウザ内に保存、プレビューは **Blob URL** (解決前は黒, T-437)。
      空白 = 黒・無音で BGM は跨いで鳴る (T-440)、音声は AAC / Opus でミックス、取り込んだ動画クリップの音声は出ない (両版同じ, T-273)、
      長いトランジションはメモリを使う、**画像クリップは Web 版の書き出しでは今後の更新で対応** (desktop T-493 → web T-498)。
      モザイクは検出元の区間だけ。
    - `#team`「組織の管理（Enterprise）」: Desktop 版と同じ画面、詳細は `/docs/#team`。組織コードはログイン画面の
      「組織コードをお持ちの方」→「組織コード」欄 (ログイン後のメニューからは参加不可、ログイン済みならログアウトしてから)。
      請求書の「表示」「PDF」は新しいタブ (web の `openExternalUrlImpl` = `window.open`)。
  - 「Desktop 版との違い」の表: 編集ページの行にタイムライン編集、行を 2 つ追加 (ホーム画面の分類 / 組織の管理（Enterprise）)、

  - 「検出データをダウンロード」: 取り込んだ素材のファイルは含まれない旨を追記。
  - 冒頭の Liquid コメントに根拠 (desktop-parity.md の節) と project-io の注意を追記。

## ⚠️ チケットの記述と違うところ (要確認)

CHANGELOG の T-511 は「プロジェクトの書き出し・取り込みは未提供 → 提供済みに」だが、**web のコードでは未実装のまま**:

- `web/app/src/lib/api/project-io.ts` の `exportProject` / `importProject` はモック (`recordCall` して bytes 0 を返す)
- `web/app/src/lib/api/impl/index.ts` のコメント: 「project-io … W-6xx 後続 (今回スコープ外)」で本実装に差し替えていない
- HOME の「プロジェクトをエクスポート」は `routes/+page.svelte::handleExport` が「エクスポート (…) は W-6xx で実装予定です」の通知を出すだけ
- `app/docs/desktop-parity.md` D 節も「api はモック」

サイトの規約 (「未実装・無効の機能は書かない」) と安全側を優先し、**提供済みとは書かず**「Web 版ではまだご利用いただけません
（準備中です）」に言い換えた。web で W-6xx が実装されたら、この行と Liquid コメントを直すこと。
