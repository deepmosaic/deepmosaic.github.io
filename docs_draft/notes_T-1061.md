# T-1061 法務文書の修正 (企業名 / 保管国の細部 / 保存期間 / 配布形態の区別 / 法人様 / 特商法の表の幅)

## 方針 (以後の法務文書すべてに適用)

1. 委託先・サービス提供者の具体的な企業名を本文に出さない。例外は Google Analytics (Google LLC) だけ。
2. 所在国は「米国」とだけ書く。保存先の国・リージョン・テナントのドメインのような細部は書かない。
3. ログは削除しない (保持 sweep の停止は T-1062)。保存期間 (7日 / 90日) と退会時の扱いは書かない。
4. デスクトップ版 / Web 版のように配布形態で区別して書かない。「当社が提供するソフトウェア (本ソフトウェア)」とまとめる。
5. 「法人向け（Enterprise）」「法人向けの個別案件」は「法人様」と書く。
6. 特商法の表の見出し列は `min-w-[10rem]` で狭くしない。
