docs を desktop のリリースより先に公開する (2026-09-23 ユーザー決定、01-intro の先取り注記は T-509) ので、

## 変更点

- **`_includes/docs/07-team.html`**
  - 表示文字列の「チーム」23 箇所 (コメントを除く) を「組織」に (見出し kicker「組織」/「組織の管理（Enterprise）」、
    プロフィールメニューの項目名「組織の管理」= desktop T-484)。節 ID `team` は変えていない。
  - 権限名をアプリと同じ **「管理者」「メンバー」** に (desktop / web の `TeamMembersTab` の select は
    `owner → 管理者`。アプリに「オーナー」という語は出てこない)。
  - ダイアログの項目: 管理者は 権限 / 請求 / 請求書 / 利用量 の 4 つ、メンバーは 権限 / 利用量 の 2 つ (T-488)。
  - 「メンバーを招待する」: 招待と招待メールの再送は**管理者だけ** (T-487)、メンバーには権限タブに案内が出る。
    招待メールが届いたアドレスでログインすると自動で参加、別アドレスなら組織コード。
  - 「組織コードで参加する」: 入口は**ログインダイアログの「組織コードをお持ちの方 (Enterprise)」→「組織コード」欄だけ**
    (T-485 でアカウントメニューの項目を撤去)。ログイン済みならログアウトしてからやり直す (T-485 の `RETRY_HINT` と同じ案内)。
  - 「導入の流れ」: T-398 で見積書から組織コードの欄と断り書きを外したので、見積書の手順から組織コードを削除。
    組織コードは**ご契約が有効になったときの案内メール** (Worker `email-copy.ts` の `org-activated`) で届き、
    そのメールのアドレス (= 見積の `quote.email`、`enterprise-provision.ts` の `ownerEmail`) でログインすると自動で
    管理者として参加、他のメンバーは組織コード欄から、と書き直した。「お見積書にも記載」「お見積りの段階から使える /
    ご契約の前でも参加できる」「お見積書に記載したものから変わりません」の段落・文を削除。
  - 「対応版アプリの公開後」の断り書き → 章の冒頭近くに 01-intro と同じ版表記で
    「組織の管理と組織コードでの参加は、次回のデスクトップ更新 (v2.4) からご利用いただけます。配布中の v2.3.7 には
    含まれません（このページ冒頭の注記）」。v2.3.7 (tag, 2026-09-05) には TeamWindow も AuthDialog の組織コード欄も
    無いことを `git grep` で確認済み。
  - 新しい h3「請求書（過去のご請求）」: 管理者のみ、列 (請求日・請求書番号・期間・金額・状態、支払済みが違えば併記)、
    状態 5 種 (下書き / 未払い / 支払済み / 無効 / 回収不能)、「さらに読み込む」(10 件ずつ)、表示 / PDF (T-488)。
    「請求」の定義表にあった「請求書の表示 / PDF」の行は新しい節へ移した。
