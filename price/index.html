時間の計測について

  • {% include icon.html name="Check" class="mt-1 h-4 w-4 shrink-0 text-success" %}計測の単位は、検出が完了した動画の再生時間です。
  • {% include icon.html name="Check" class="mt-1 h-4 w-4 shrink-0 text-success" %}検出が完了したときに加算されます。エンコード（書き出し）は加算対象ではありません。
  • {% include icon.html name="Check" class="mt-1 h-4 w-4 shrink-0 text-success" %}ライセンスサーバーへ送信するのは使用量（動画の秒数）とファイルのハッシュ値のみで、ファイル名・映像・検出結果の座標は送信しません。

詳細はドキュメントの「使用時間の計測」をご覧ください。
