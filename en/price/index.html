How usage time is measured

  • {% include icon.html name="Check" class="mt-1 h-4 w-4 shrink-0 text-success" %}Usage is measured by the playback length of videos for which detection has finished.
  • {% include icon.html name="Check" class="mt-1 h-4 w-4 shrink-0 text-success" %}Time is added when detection finishes. Exporting is not counted.
  • {% include icon.html name="Check" class="mt-1 h-4 w-4 shrink-0 text-success" %}The only data sent to the license server are the usage (video length in seconds), the hash values of files, and the hash value of the device identifier. File names, footage, and the coordinates of detection results are not sent.

For details, see {% include ja-link.html href="/docs#usage" label="Measuring usage time" class="text-accent-soft hover:underline" %} in the documentation.
