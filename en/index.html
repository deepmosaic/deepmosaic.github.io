{% include section-title.html kicker="EXISTING MOSAIC" title="Find mosaic that is already in your footage and apply it again" sub="Automatically finds the position and extent of block mosaic that is already in your footage, and applies Deepmosaic mosaic over it. Use it for footage where you want to even out the block size, or where you want to change the blocks to meet the standards of where you submit." %}

It cannot take mosaic off or restore the original footage. This feature applies new mosaic over the areas it finds.

Footage: our own sample video (with mosaic burned into the faces)

  • {% include icon.html name="Check" class="h-4 w-4 shrink-0 text-accent" %}

    Finds the position and extent automatically

    Just turn on "Mosaic" in the detection options and run detection to find block mosaic that is already in your footage.

  • {% include icon.html name="Check" class="h-4 w-4 shrink-0 text-accent" %}

    Estimates the blocks and applies mosaic over them

    Estimates the block size of the original mosaic and applies Deepmosaic mosaic over it. You can change the blocks under "By ID" in the mosaic settings.

  • {% include icon.html name="Check" class="h-4 w-4 shrink-0 text-accent" %}

    Correct the boxes on the editing page

    The areas found are shown as polygon boxes, and you can correct them on the editing page just like other detection boxes.

Available in both the Desktop app and the Web app. The differences between the two (whether it can be used at the same time as detection of body areas and faces), mosaic that is hard to find, and estimated processing times are covered in the {% include ja-link.html href="/docs/#detect-mosaic" label="documentation" class="text-accent-soft hover:underline" %}.

{% include section-title.html kicker="MOSAIC" title="Flexible editing" sub="Mosaic that follows the shape of objects, consistent blocks regardless of video resolution (default), blocks set by the number across the screen width, blocks for each range of object size, and blocks proportional to a number of divisions. Adjust them to match the required values of each submission destination." %}

Apply mosaic along the shape of objects, not in a square box

Within each detected box, AI creates the outline of the target and applies mosaic in that shape (enabled by default on PCs with a CUDA-compatible GPU; there is no setting for it). Hair and background are not blocked out in a square, so you can hide only what needs hiding. You can work with the outlines directly on the editing page.
