Open Deepmosaic

Open the app with the organization code .

Open in app
  1. Select "Open in app".
  2. Check that the sign-in screen opens as "Organization sign-in" with the organization code entered in "Organization code".
  3. Select "Sign in" to sign in.

If the app doesn't open, copy the organization code, select "Have an organization code? (business)" on the app's sign-in screen, and paste it into "Organization code".

Sign in as an admin.

Open in app
  1. Select "Open in app".
  2. Sign in with the email address that received the welcome email (you don't enter an organization code).

This link isn't valid. Open the link in the email again, or launch the app and enter the organization code.

If you haven't installed the app yet

Get Deepmosaic for Windows from Microsoft Store. After installing it, select "Open in app" on this page again.
