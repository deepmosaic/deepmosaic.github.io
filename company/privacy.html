プライバシーポリシー

最終更新日: 2026-10-12（制定: 2019-06-01）

Deepmosaic合同会社（以下「当社」といいます。）は、当社の提供するサービス（以下「本サービス」といいます。）における、ユーザーについての個人情報を含む利用者情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます。）を定めます。

1.収集する利用者情報及び収集方法

本ポリシーにおいて、「利用者情報」とは、ユーザーの識別に係る情報、通信サービス上の行動履歴、その他ユーザーのスマートフォン、PC等の端末においてユーザーまたはユーザーの端末に関連して生成または蓄積された情報であって、本ポリシーに基づき当社が収集するものを意味するものとします。 本サービスにおいて当社が収集する利用者情報は、その収集方法に応じて、以下のようなものとなります。

    1. ユーザーからご提供いただく情報

      2. ユーザーが本サービスを利用するために、ご提供いただく情報は以下のとおりです。

        1. 氏名
        2. メールアドレス
        3. 会社名
        4. その他当社が定める入力フォームにユーザーが入力する情報
    2. ユーザーが本サービスの利用において、外部の認証サービスを介してログインすることにより、当該サービスからご提供いただく情報

      3. 当社は、本サービスのログインの機能を外部の認証サービス（Auth0）を通じて提供しています。ユーザーが同サービスでアカウントを登録し、またはログインした際に、以下の情報を同サービスから受け取ります。

        1. 認証サービス上のユーザー識別子、メールアドレス
        2. 外部のアカウントでログインした場合は、その際にユーザーが開示を認めた氏名その他の情報
    3. ユーザーが本サービスを利用するにあたって、当社が収集する情報

      4. 当社は、本サービスへのアクセス状況やそのご利用方法に関する情報を収集します。これには以下の情報が含まれます。

        1. 端末情報
        2. ログ情報
        3. Cookie及び匿名ID
        4. 端末識別子（ハッシュ化した値）
        5. アプリケーションの動作記録（12項に定めるもの）

2.利用目的

2-1 利用者情報は、2-2に定めるとおり本サービスの提供のために利用されるほか、2-3に定めるとおり、その他の目的にも利用される場合があります。

2-2　本サービスのサービス提供にかかわる利用者情報の具体的な利用目的は以下のとおりです。

    1. 本サービスに関する登録の受付、本人確認、利用料金の計算等本サービスの提供、維持、保護及び改善のため
    2. 本サービスに関するご案内、お問い合せ等への対応のため
    3. 本サービスに関する当社の規約、ポリシー等（以下「規約等」といいます。）に違反する行為に対する対応のため
    4. 本サービスに関する規約等の変更などを通知するため
    5. 上記の利用目的に付随する利用目的のため

上記2-2以外の利用目的と利用情報はそれぞれ以下のとおりです。

    1. 当社のサービスに関連して、個人を識別できない形式に加工した統計データを作成するため
        1. 端末情報
        2. ログ情報
        3. Cookie及び匿名ID
    2. その他マーケティングに利用するため
        1. 氏名
        2. メールアドレス
        3. その他当社が定める入力フォームにユーザーが入力する情報

3.通知・公表または同意取得の方法、利用中止要請の方法

3-1 以下の利用者情報については、その収集が行われる前にユーザーの同意を得るものとします。ただし、10項に定めるものを除きます。

    1. 端末情報

また、12項から14項に定める情報は、本サービスの提供の前提となるため、3-1の事前の同意取得の対象とせず、3-3に定める同意をもって取得します。

3-2 ユーザーは、本サービスの所定の設定を行うことにより、利用者情報の全部または一部についてその利用の停止を求めることができ、この場合、当社は速やかに、当社の定めるところに従い、その利用を停止します。なお利用者情報の項目によっては、その収集または利用が本サービスの前提となるため、当社所定の方法により本サービスを退会した場合に限り、当社はその収集を停止します。

3-3 当社は、デスクトップ版の初回起動時及びWeb版の初回利用時に、アプリケーション内の画面で使用許諾契約書及び利用規約への同意を求め、あわせて本ポリシーをご案内します。当社は、同意の有無と同意した文書の版を記録し、これらの文書を改定した場合には改めて同意を求めることがあります。

4.外部送信、第三者提供、情報収集モジュールの有無

当社ウェブサイトは、利用状況の把握のため Google Analytics を利用しており、閲覧に関する情報が Google LLC に送信されます（詳しくは8項及びクッキーポリシーをご覧ください）。本サービスのアプリケーションには、広告を配信する目的の情報収集モジュールは組み込まれていません。アプリケーションから当社が取得する情報と送信先は12項から15項に定めます。

5.第三者提供

当社は、利用者情報のうち、個人情報については、個人情報保護法その他の法令に基づき開示が認められる場合を除くほか、あらかじめユーザーの同意を得ないで第三者に提供しません。但し、次に掲げる場合はこの限りではありません。

    1. 当社が利用目的の達成に必要な範囲内において個人情報の取扱いの全部または一部を委託する場合
    2. 合併その他の事由による事業の承継に伴って個人情報が提供される場合
    3. 国の機関もしくは地方公共団体またはその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合であって、ユーザーの同意を得ることによって当該事務の遂行に支障を及ぼすおそれがある場合
    4. 別途定めに従って共同利用する場合
    5. その他、個人情報保護法その他の法令で認められる場合

6.個人情報の開示

当社は、お客様から、個人情報保護法の定めに基づき個人情報の開示を求められたときは、 お客様ご本人からのご請求であることを確認の上で、お客様に対し、遅滞なく開示を行います (当該個人情報が存在しないときにはその旨を通知いたします。)。但し、個人情報保護法その他の法令により、当社が開示の義務を負わない場合は、この限りではありません。

7.個人情報の訂正及び利用停止等

7-1 当社は、ユーザーから、⑴個人情報が真実でないという理由によって個人情報保護法の定めに基づきその内容の訂正を求められた場合、及び⑵あらかじめ公表された利用目的の範囲を超えて取り扱われているという理由または偽りその他不正の手段により収集されたものであるという理由により、個人情報保護法の定めに基づきその利用の停止を求められた場合には、ユーザー本人からのご請求であることを確認の上で遅滞なく必要な調査を行い、その結果に基づき、個人情報の内容の訂正または利用停止を行い、その旨をユーザーに通知します。なお、合理的な理由に基づいて訂正または利用停止を行わない旨の決定をしたときは、ユーザーに対しその旨を通知いたします。

7-2 当社は、ユーザーから、ユーザーの個人情報について消去を求められた場合、当社が当該請求に応じる必要があると判断した場合は、ユーザー本人からの請求であることを確認の上で、個人情報の消去を行い、その旨をユーザーに通知します。

7-3 個人情報保護法その他の法令により、当社が訂正等または利用停止等の義務を負わない場合は、前2項の規定は適用されません。

8.Google Analyticsやその他解析ツールの利用について

当社は、当社ウェブサイトにおいて、ユーザーの動向を調査するために Google LLC が提供する Google Analytics 4 を用い、統計的な利用情報を取得しています。詳しくはクッキーポリシーをご覧ください。Google Analytics の詳細は次のリンクからご確認ください。https://marketingplatform.google.com/about/analytics/

9.ダウンロード経路の記録について

当社は、本ウェブサイトからデスクトップアプリケーションをダウンロードした際に、どのような経路でお知りいただいたかを把握する目的で、次の情報を記録します。

    1. 参照元のURL（本サイトへ遷移する直前のページ）
    2. キャンペーンパラメータ（utm_source、utm_medium、utm_campaign）
    3. 国コード（IPアドレスそのものは保存しません）
    4. ご利用のブラウザ・OSの情報（User-Agent）
    5. ダウンロード日時および配布したアプリケーションのバージョン

この記録には、ダウンロードごとに発行するランダムな識別子を用います。当該識別子はインストーラーのファイル名に含まれ、アプリケーションの初回起動時に当社サーバーへ送信されます。これにより、上記のダウンロード経路の情報が、アプリケーションのご利用状況（本サービス上のアカウントまたは端末ごとの識別子）と紐づけて記録されます。

これらの情報は、どの経路からのご利用が多いかを把握し、本サービスの改善および広報活動の最適化に用いるものであり、それ以外の目的では利用しません。第三者への提供は行いません。

本記録を希望されない場合は、上記の識別子を含まないインストーラーを別途ご案内いたしますので、下記の問い合わせ窓口までご連絡ください。また、記録済みの情報の開示・訂正・利用停止・消去のご請求についても、6項および7項に定めるところに従い、同窓口にて承ります。

10.無料枠の管理のための端末識別子と利用時間の記録について

当社は、デスクトップアプリケーションの無料でご利用いただける範囲（以下「無料枠」といいます。）の管理のため、端末を識別するハードウェア由来の識別子をハッシュ化した値と、ログインしていない状態での利用時間（検出した動画の再生時間の累計）を収集・保存します。識別子から端末や個人を特定することはできません。識別子の元の値は当社サーバーへ送信しません。

これらの情報は、無料枠の管理（端末ごと・アカウントごとの利用時間の累計の計算）の目的にのみ用い、第三者への提供は行いません。アプリケーションをアンインストールした場合や、別のアカウントで登録し直した場合でも、同じ端末での無料枠の累計を正しく計算するため、当社サーバー上の記録は保持されます。この記録は端末単位のものでアカウントには紐づけず、アカウントを削除（退会）した後も保持されます。これらの情報は無料枠の提供の前提となるため、3-1の同意取得の対象とせず、アプリケーションの利用開始時の利用規約および本ポリシーへの同意をもって収集し、その利用の停止については3-2のなお書きに定めるところに従います。記録の開示・訂正・利用停止・消去のご請求は、6項および7項に定めるところに従い、下記の問い合わせ窓口にて承ります。

11.サンプルの動画の提供について

当社は、本サービスをお試しいただくため、アプリの初回利用時にサンプルの動画（顔の検出のみ）を自動で追加することがあります。サンプルの動画には、ユーザーの動画や情報は含まれません。サンプルは通常のプロジェクトと同様に削除でき、削除した後に再び追加されることはありません。

12.アプリケーションの動作記録について

当社は、本サービスの提供、不具合の調査及び改善のため、デスクトップ版及びWeb版のアプリケーションの動作記録を当社のサーバーに送信・保存します。動作記録は本サービスの提供の前提となるため、同意の有無にかかわらず送信し、3-3に定める同意をもって取得します。動作記録には、次の情報が含まれます。

    1. 端末識別子（ハッシュ化した値）
    2. OS、CPU、メモリ、GPU等のご利用のPCの情報
    3. 動画の長さ、解像度、形式、ファイルサイズ及びファイルのハッシュ値
    4. 検出の設定、処理時間及び処理の結果
    5. 主要な操作の記録
    6. 検出処理のログ（ファイルのパス、ユーザー名、メールアドレス等を伏せたうえで送信します）

当社は、動画の映像・音声・フレーム画像、ファイル名及びフォルダのパスを送信しません。

検出処理のログのうち詳細なものは7日、その他のログは90日を経過した後に削除します。実行の記録その他の動作記録は、本サービスの提供及び改善に必要な期間保存します。アカウントを削除（退会）した場合、これらの記録はアカウントとの紐づけを外し、個人に紐づかない形で保存されることがあります。

13.エラー診断レポートについて

当社は、不具合の調査のため、デスクトップ版のアプリケーションでエラーが起きたときに、エラーの種類、発生箇所の記録（スタックトレース）、アプリケーションのバージョン及びOSの情報を、Functional Software, Inc.（米国）が提供するエラー診断サービス Sentry に送信します。送信の際、ファイル名及びファイルのパスは伏せます。

Web版はエラー診断レポートを送信しません。

14.認証と決済について

14-1 本サービスのログインの機能は、Okta, Inc. が提供する認証サービス Auth0 を通じて提供します。当社は、ユーザーのパスワードを受け取らず、保持しません。

14-2 本サービスの決済は、Stripe, Inc. 及びその関係会社が提供する決済サービス Stripe が処理します。クレジットカード番号は当社のサーバーを経由せず、当社はクレジットカード番号を保持しません。当社が Stripe から受け取るのは、メールアドレス、契約の状態、支払の結果等の情報です。

16.安全管理措置について

当社は、利用者情報の漏えい、滅失または毀損の防止その他の安全管理のため、次の安全管理措置を講じています。

    1. 組織的安全管理措置: 利用者情報の取扱いに関する規程を定め、取り扱う担当者を限定しています。
    2. 人的安全管理措置: 担当者に対し、利用者情報の適切な取扱いについて周知しています。
    3. 物理的安全管理措置: 利用者情報を取り扱う機器の盗難・紛失を防ぐ措置を講じています。
    4. 技術的安全管理措置: アクセス制御、通信の暗号化及び管理者の権限の分離を行い、アプリケーションに利用者情報の管理権限を持たせない構成としています。
    5. 委託先の監督: 利用者情報の取扱いを委託する場合は、委託先を適切に選定し、監督します。
    6. 外的環境の把握: 外国において利用者情報を取り扱う場合は、当該外国の個人情報の保護に関する制度を把握したうえで、安全管理措置を講じます。
