有料プランのお申し込み

有料プランは、アプリのプロフィールメニュー（Windows 版をダウンロードしてお使いの方）、またはこのページから Web 版のアカウントでお申し込みいただけます。どちらでお申し込みいただいても、同じアカウントで Desktop 版と Web 版の両方でご利用いただけます。 このページでは、下のボタンから Web 版を開き、アプリと同じアカウントでサインインしてクレジットカードでお支払いください。

{%- include store-subscribe-note.html %}

お申し込みの流れ

  1. STEP 1

    下のプランから「申し込む」を押すと、Web 版（ブラウザ）が開きます。

  2. STEP 2

    アプリと同じアカウントでサインインします（アカウントが無い場合も、初めてのサインインで自動で作成されます）。サインインするとそのまま決済画面に進みます。

  3. STEP 3

    クレジットカードでお支払いいただくと、アカウントのプランが切り替わります。アプリでは同じアカウントでサインインするだけで反映されます。
