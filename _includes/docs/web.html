{% include docs-h2.html kicker="Web 版" title="はじめに" %}

Web 版は、インストール不要でブラウザから使える Deepmosaic です。動画の読み込みから AI 検出、検出結果の編集、モザイクを焼き込んだ動画の書き出しまでを、すべてお使いの PC のブラウザの中で処理します。映像・音声・フレーム画像・検出結果がサーバーに送られることはなく、通信するのはログインとプランの確認、AI モデルの取得だけです。

アカウントとプラン、無料枠の時間は Desktop 版と共通です。検出対象（局部 / 男性の顔 / 女性の顔）と編集ページの機能も同じなので、操作の詳細は Desktop 版のガイドを参照してください。このページでは Web 版に固有の要件と違いをまとめます。

{% if site.data.site.web_app.enabled %}

Web 版は app.deepmosaic.co.jp から開けます。

{% endif %}
{% include docs-h2.html kicker="Web 版" title="対応ブラウザと要件" %}

起動時にブラウザの機能を確認し、足りないものがあれば案内が表示されます。必須の機能が無い場合は利用できません。推奨の機能が無い場合は「低速モード」として続行できます。

ブラウザ（必須）
WebCodecs に対応したブラウザ: Google Chrome / Microsoft Edge 119 以降、Safari 17 以降。Chrome または Edge の最新版を推奨します
ブラウザ内ストレージ（必須）
動画のコピーとモデルをブラウザ内（OPFS）に保存します。プライベート（シークレット）ウィンドウでは利用できません
HTTPS（必須）
https:// で始まる URL から開いてください（通常は自動で満たされます）
WebGPU（推奨）
AI 検出を GPU で実行します。無い場合は CPU（WebAssembly）で動作しますが、数倍〜十数倍の時間がかかります。Chrome / Edge では通常有効です
動画のサイズ
1 本あたり約 1.9GB まで。超える場合は「ブラウザ版で扱える上限 (約 1.9GB) を超えています。デスクトップ版をご利用ください。」と表示されます
動画の形式
mp4 / mov / m4v（ブラウザが再生できるコーデック、通常は H.264）。MKV / WebM / AVI / WMV / FLV / TS / MPEG は「この形式はブラウザ版では未対応です。mp4 (H.264) に変換してからお試しください。」と表示されます
メモリ
長尺・高解像度の動画では多くのメモリを使います。他のタブや重いアプリを閉じてからの実行をおすすめします
{% include docs-h2.html kicker="Web 版" title="始め方" %}
  1. ログインします。Web 版はログインが必須です。トップページの「ブラウザで試す」から開くとすぐにログイン画面が表示されます。アカウントをお持ちでない方は「新規登録」から無料で作成できます
  2. 初回はモデルを取得します。AI モデルがブラウザ内にダウンロードされます（進捗が表示されます）。2 回目以降はブラウザ内のモデルをそのまま使います
  3. 動画を読み込みます。画面へのドラッグ&ドロップ、またはメニューの「ファイル」から選びます。動画はブラウザ内にコピーされ、ホーム画面にプロジェクトとして並びます
  4. 検出オプションを設定して開始します。検出範囲・検出対象・ピクセルサイズ自動・一括実行は Desktop 版と同じです（検出オプション）。検出はフローティングウィンドウで進み、その間も他の操作ができます
  5. 編集して書き出します。編集ページの機能とショートカットは Desktop 版と同じです（編集ページ）。書き出しは書き出しとダウンロードを参照してください

人物ギャラリーを初めて使うときは、顔の識別用モデル（約 249MB）の追加ダウンロードを確認する画面が出ます。回線速度に応じた所要時間の目安が表示され、途中で止めても続きから再開できます。

{% include docs-h2.html kicker="Web 版" title="Desktop 版との違い" %}
検出
同じ（検出対象 3 種、検出範囲、ピクセルサイズ自動、一括実行、シーンの自動判定）
編集ページ
同じ（枠の編集、1f / ∞ の追加、モザイク設定の 4 タブ、シーン、人物ギャラリー、ズーム、ショートカット、タイムライン編集）。タイムライン編集の違いはタイムライン編集を参照してください
ホーム画面の分類
同じ（フォルダとタグ、「他のフォルダ」の行）。分類はブラウザ内に保存されます（ホーム画面の分類）
書き出し形式
MP4 (H.264) / WebM (VP9) / WebM (AV1) の 3 種類。H.265・ProRes・MKV・AVI は Desktop 版のみ。ブラウザが対応しない形式を選ぶと MP4 (H.264) に切り替わります
解像度 / フレームレート / ビットレート
解像度は同じ 7 種類。フレームレートは「元動画と同じ」のみ（変換はできません）。ビットレートの「自動」は解像度から決まります
タイムコード
同じ（埋め込みと文字サイズ・位置・色・表示形式の設定）
GPU エンコード
ブラウザが対応している場合に「GPU エンコード」として選べます（NVIDIA ドライバの条件はありません）
保存先
ブラウザの保存ダイアログで指定するか、いったんブラウザ内に保存してからダウンロードします（書き出しとダウンロード）
Premiere Pro 連携
ありません（Desktop 版のみ）
プロジェクトの書き出しと取り込み
zip の書き出し・取り込みは Web 版ではまだご利用いただけません（準備中です）。代わりに「検出データをダウンロード」で検出結果と編集データを保存できます（書き出しとダウンロード）
組織の管理（Enterprise）
同じ（招待と権限、アカウント数、請求書、利用量）。参加の手順は組織の管理を参照してください
アップデート
自動更新の通知はありません。ページを再読み込みすると常に最新版になります
同時実行
1 アカウントにつき検出 1 件・エンコード 1 件まで（検出とエンコードは同時に進められます）。Desktop 版で実行中のジョブとも排他になります
オフライン
ログインの確認に通信が必要なため、オフラインでは「サーバーに接続できません」と表示され利用できません。Desktop 版はセットアップ後にオフラインでも検出・編集・書き出しができます
{% include docs-h2.html kicker="Web 版" title="ホーム画面の分類" %}

ホーム画面の左サイドバーで、プロジェクトをフォルダとタグで分類できます。操作は Desktop 版と同じです（動画の読み込み）。

  • フォルダ: 一覧上部の「新規フォルダ」でフォルダを作り、フォルダのメニューからサブフォルダも作れます。動画カードのメニュー（右クリックでも開きます）の「フォルダへ移動」で移すか、カードをサイドバーのフォルダへドラッグします。「すべての動画」にドロップすると分類を外せます
  • タグ: 動画カードのメニューのタグ欄で付け外しします。サイドバーの「タグで絞り込み」でタグを選ぶと、そのタグの動画だけが並びます
  • 「他のフォルダ」: 現在のプロジェクトフォルダの外にあるプロジェクトは、サイドバーの「他のフォルダ」の行にまとまります（0 件のときは表示されません）。フォルダとタグは使えないので、分類したいときは動画カードのメニューの「このプロジェクトフォルダに切り替える」を選びます
分類の保存先
フォルダとタグは、ブラウザ内のプロジェクトフォルダに保存されます。Desktop 版とは共有されません（別のブラウザ / PC とも共有されません）
複数のタブ
同じブラウザの複数のタブで同時に分類を変えると、最後に保存したタブの内容が残ります。分類の変更は 1 つのタブで行ってください
動画カードのメニュー
「プロジェクトフォルダを開く」「Premiere Pro」「プロジェクトをコピー」はありません。Web 版には代わりに「検出データをダウンロード」があります（書き出しとダウンロード）
{% include docs-h2.html kicker="Web 版" title="タイムライン編集" %}

編集ページのタイムライン編集は Desktop 版と同じ操作で使えます。左のサイドバー（メディア / テキスト / 透かし / 音声 / フェード / トランジション）から素材や効果を追加し、クリップのトリム・分割・並べ替え・削除、クリップ間の空白、テキスト、音声（BGM）を編集できます。編集した内容は、そのまま書き出しに反映されます（編集ページ）。

素材の取り込み
動画・音声・画像の素材は、メディアパネルの「メディアをインポート」から選ぶか、ファイルを編集ページにドラッグ&ドロップして取り込みます。素材はブラウザ内のプロジェクトに保存され、プレビューではブラウザ内の一時的な URL（Blob URL）から読み込みます。ページを開いた直後など、素材の読み込みが終わるまではプレビューのその区間が黒く表示されることがあります
空白
クリップの間に置いた空白は、黒い画面・無音として書き出されます（Desktop 版と同じ結果です）。BGM は空白をまたいで流れ続けます
テキスト・透かし・フェード・トランジション
同じ。書き出しではブラウザが映像に焼き込みます。トランジションを長くするほど、書き出し中のメモリを多く使います
音声
元の動画の音声と BGM などの音声トラックをミックスして書き出します（MP4 は AAC、WebM は Opus）。取り込んだ動画クリップの音声は書き出しに含まれません（Desktop 版と同じです）
画像クリップ
同じ。画像の素材は好きな長さのクリップとしてタイムラインに置け、書き出しにもその長さのまま入ります。透過 PNG の透明な部分は、Web 版の書き出しでは黒になります

モザイクは、AI で検出した元の動画の区間にかかります。取り込んだ素材は検出の対象外です。

{% include docs-h2.html kicker="Web 版" title="実行ウィンドウとキュー" %}

検出とエンコードの進捗、キューは、画面の上に重なるフローティングウィンドウで表示されます。ヘッダーをドラッグして移動でき、最小化すると画面右下に小さなチップとして残り、クリックで戻せます。表示中でもホーム画面や編集ページの操作はそのまま行えます。

メニューバーの「キュー」で検出とエンコードの待ち行列を確認・操作できます（並べ替え、一時停止、キャンセルは Desktop 版のキューと同じです）。同じアカウントで別のタブや Desktop 版がジョブを実行中のときは、新しいジョブの開始時に引き継ぐかどうかの確認が表示されます。

{% include docs-h2.html kicker="Web 版" title="書き出しとダウンロード" %}
保存ダイアログで保存
Chrome / Edge では、エンコード開始時にブラウザの保存ダイアログで保存先ファイルを指定し、そこへ直接書き出します
ブラウザ内に保存してダウンロード
保存ダイアログに対応しないブラウザでは、いったんブラウザ内のプロジェクトに書き出し、完了後の「出力をダウンロード」でファイルとして保存します
検出データをダウンロード
プロジェクトの検出結果と編集データを JSON ファイルとして保存します。Desktop 版のプロジェクトフォルダに置くと、Desktop 版で編集や Premiere Pro への送信を続けられます。タイムライン編集で取り込んだ素材のファイルは含まれません
{% include docs-h2.html kicker="Web 版" title="データの保存と自動削除" %}

読み込んだ動画のコピー、検出結果、編集データ、タイムライン編集で取り込んだ素材、ホーム画面の分類（フォルダとタグ）、ブラウザ内に書き出した動画、AI モデルは、すべてブラウザのサイト専用ストレージに保存されます。サーバーには保存されません。

AI モデル
7 日間使われなかったモデルは自動で削除されます（次回の検出時に再取得します）
プロジェクト
自動では削除されません。不要になったらホーム画面から削除してください。ブラウザの容量が足りなくなると読み込みに失敗します
ブラウザのデータ削除
ブラウザの設定で「サイトのデータを削除」すると、プロジェクトとモデルはすべて消えます。残しておきたい成果物は先にダウンロードしてください
別のブラウザ / PC
ストレージはブラウザごとに独立しています。別の環境で続きの作業をするには、書き出した動画や検出データをダウンロードして移してください

初回の読み込み時にブラウザから「ストレージの永続化」の許可を求められることがあります。許可すると、ブラウザが容量不足のときにデータを自動で消しにくくなります。

{% include docs-h2.html kicker="Web 版" title="プランと使用時間" %}

アカウント、プラン、使用時間は Desktop 版と共通です。無料アカウントでは累計 {{ free_plan.included_hours }} 時間分の動画を検出でき、フッターに残り時間が表示されます。使用時間は検出が完了したときに加算され、エンコードは加算されません。有料プランの込み時間と料金は料金ページをご覧ください。

プランの申し込み・変更・解約はプロフィールメニューから行います。決済画面は新しいタブで開き、手続きが終わって元のタブに戻ると自動で反映されます。Enterprise はプロフィールメニューの「お問い合わせ」からご相談ください。

{% include docs-h2.html kicker="Web 版" title="組織の管理（Enterprise）" %}

Enterprise の組織に参加しているアカウントでは、プロフィールメニューの「組織の管理」から、メンバーの招待と権限、アカウント数の変更、請求書、利用量を Desktop 版と同じ画面で扱えます。権限や導入の流れは Desktop 版のガイドの組織の管理（Enterprise）をご覧ください。

組織コードでの参加
ログイン画面の「組織コードをお持ちの方」を開き、「組織コード」欄にコードを入力してからログインします。認証を終えてこのページに戻ると、組織への参加が行われます。ログインした後のメニューからは参加できないので、ログイン済みの場合はいったんログアウトしてから入力し直してください
請求書の表示 / PDF
「請求書」の「表示」と「PDF」は、ブラウザの新しいタブで開きます
{% include docs-h2.html kicker="Web 版" title="トラブルシューティング" %}
  • 「https:// で始まる URL から開いてください。」と出る場合: アドレスバーの URL を https://app.deepmosaic.co.jp/ に直してください。
  • ブラウザの機能が足りないと表示される場合: Chrome / Edge を最新版に更新してください。プライベートウィンドウではストレージが使えないため、通常のウィンドウで開いてください。
  • 「サーバーに接続できません」と出る場合: ネットワーク接続を確認し、「再試行」を押してください。
  • 検出が極端に遅い場合: WebGPU が無効になっている可能性があります。ブラウザを最新版にし、グラフィックドライバを更新してください。他のタブや重いアプリを閉じるのも効果があります。
  • 動画を読み込めない場合: 約 1.9GB を超える動画は Desktop 版をご利用ください。mp4 / mov 以外の形式は mp4 (H.264) に変換してからお試しください。
  • 書き出しの保存ダイアログが出ない場合: ブラウザ内に保存されています。完了後に「出力をダウンロード」を押してください。
  • 解決しない場合: プロフィールメニューの「お問い合わせ」から、ブラウザの種類とバージョンを添えてご連絡ください。
