Microsoft Store 版をお使いの方へ

Microsoft Store 版でも、使える機能・アカウント・プランはインストーラ版と同じです。次の点だけが異なります。

  • 入手先: 上の「Microsoft Store で入手」から Microsoft Store の掲載ページを開き、「入手」（または「インストール」）を押してください。Microsoft Store アプリで「Deepmosaic」を検索しても見つかります（Microsoft Store アプリで直接開く場合はこちら）。インストール先は Windows が管理するアプリのフォルダで、変更できません
  • アップデート: 新しいバージョンは Microsoft Store が配信し、自動で更新されます。アプリ内の更新ダイアログと、メニューの「ファイル ▸ アップデートを確認」はありません。AI モデルは起動時に自動で取得します（アップデート）
  • 有料プランの申し込み: Microsoft Store 版のアプリには購入画面がありません。有料プランの申し込み・変更・解約は、Web 版（ブラウザ）でアプリと同じアカウントにサインインして行います（プランの変更）
  • 同梱する第三者ソフト: Microsoft Store 版はパッケージの中身が読み取り専用・署名済みのため、同梱の FFmpeg をその場で差し替えることはできません（GPL に従って別途入手・改変した FFmpeg を使うことはできます。同梱する第三者ソフトとライセンス）
  • Premiere Pro 連携: Microsoft Store 版で Premiere Pro 連携を使うには、プラグインの更新（0.1.21 以降）が必要です。「Premiere Pro へインポート」から案内に従って更新してください（Premiere Pro 連携）
  • アンインストール: 確認画面のチェックは無く、設定とサインインの情報（%USERPROFILE%\.deepmosaic）とプロジェクトフォルダは残ります。不要になったフォルダは、アンインストールの後にエクスプローラーで削除してください（プロジェクトフォルダの中に保存した書き出し動画も消えるのでご注意ください）
  • インストーラ版から切り替える場合: プロジェクトフォルダ・設定とサインインの情報・AI モデル等（%LOCALAPPDATA%\deepmosaic）は Microsoft Store 版がそのまま使います。インストーラ版をアンインストールすると AI モデル等は削除され、Microsoft Store 版は次回起動時にこれらを取得し直します。アンインストールの確認画面の「アプリのデータとプロジェクトフォルダを削除する」にチェックを入れないでください（Microsoft Store 版と共有している設定・検出結果・プロジェクトフォルダも削除されます）
