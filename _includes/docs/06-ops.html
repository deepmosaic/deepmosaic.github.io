Microsoft Store 版は、新しいバージョンを Microsoft Store が配信し、自動で更新されます。AI モデルは起動時に新しいものがあれば自動で取得・差し替えられます。以下は、インストーラ版（2026 年 12 月 31 日まで。移行）の説明です。

インストーラ版のアプリは、起動時に自動で新しいバージョンを確認します。更新がある場合はダイアログが表示され、「今すぐ更新」「あとで」のどちらかを選択します。

自動確認のタイミング
起動直後、その後は 1 時間ごと、およびウィンドウに戻ったとき。検出やエンコードの実行中は完了まで表示を待ちます
今すぐ更新
新しいバージョンをダウンロードして適用し、アプリが自動で再起動します。実行中の処理がある場合は完了後に更新してください
あとで
このセッションではそれ以上の自動確認を行いません。次回起動時に再度確認します
検出エンジン
アプリに含まれていて、アプリと一緒に更新されます
AI モデル
起動時に新しいものがあれば自動で取得・差し替えられます（初回セットアップと同じ仕組み）

手動で確認する

メニューの「ファイル ▸ アップデートを確認」で、本体 / エンジン / モデル・アセットの 3 つについて「現在」「最新」「状態」が表示されます。「更新があります」のときは「今すぐ更新」（本体）または「モデル・アセットを更新」で適用できます。「再確認」で問い合わせ直します。ネットワークに接続できないときは「ネットワーク接続をご確認のうえ、もう一度お試しください。」と表示されます。

{% include docs-h2.html kicker="運用" title="データの保存場所" %}

Deepmosaic は映像やその検出結果をサーバーに送りません。すべてお使いの PC の次の場所に保存されます。

プロジェクトフォルダ
既定 C:\Users\（ユーザー名）\deepmosaic。動画ごとのサブフォルダに、検出結果と編集データをまとめたデータベース（project.db）、サムネイル、顔の代表画像などが入ります。読み込んだ動画自体はコピーされず元の場所から参照します。タイムライン編集で追加した素材（動画・音声・画像）はサブフォルダの assets にコピーされ、プロジェクトの書き出しにも含まれます（プロジェクトフォルダ）
%USERPROFILE%\.deepmosaic
設定（config.json）、ホームの一覧・フォルダ・タグの登録簿（catalog.db）、暗号化されたサインインの情報、端末 ID、ログ（logs\app.log、検出ごとのログは logs\runs）。お問い合わせの際にログの添付をお願いすることがあります
%LOCALAPPDATA%\deepmosaic
AI モデル、GPU 用ランタイム（NVIDIA 製 GPU 搭載機のみ）など（合計で 10GB程度）。初回セットアップと起動時の確認で自動管理されます。検出エンジンと動画処理ツールはアプリに含まれています
書き出した動画
エンコード時に指定した保存先。アプリは管理しません

プロジェクトフォルダをクラウド同期フォルダ（OneDrive など）の中に置くと、編集中の自動保存と同期が競合して「保存失敗」になることがあります。ローカルのフォルダをおすすめします。

project.db と catalog.db はアプリが管理するデータベースです。アプリの起動中に他のツールで開いたり、中身を書き換えたりしないでください（データが壊れる原因になります）。バックアップやコピーはアプリを終了してから行い、project.db と同じ名前で始まるファイル（-wal / -shm）があれば一緒にコピーしてください。

{% include docs-h2.html kicker="運用" title="アンインストール" %}
  1. Windowsの「設定」→「アプリ」→「インストールされているアプリ」を開きます
  2. 一覧から「Deepmosaic」を探し、「アンインストール」を選択します（管理者権限は不要です）

Microsoft Store 版も同じ手順でアンインストールできます。確認画面のチェックは無く、設定とサインインの情報とプロジェクトフォルダは残ります（Microsoft Store 版とインストーラ版の違い）。

インストーラ版をアンインストールすると、AI モデル等（%LOCALAPPDATA%\deepmosaic、10GB程度）は自動で削除されます（再インストールしたときは初回セットアップで再ダウンロードします。Microsoft Store 版が入っている PC の 2.18 以降のインストーラ版では削除しません）。アンインストールの確認画面で「アプリのデータとプロジェクトフォルダを削除する (中の書き出し動画も削除されます)」にチェックを入れると、設定とサインインの情報（%USERPROFILE%\.deepmosaic）と、Deepmosaic が作ったプロジェクトフォルダ（検出結果・編集データ。フォルダの中に保存した書き出し動画も含みます）も削除されます。チェックしない場合、これらは残ります。プロジェクトフォルダの外にある元の動画や書き出した動画は削除されません。アップデートの際は何も削除されません。

アカウント自体を削除したい場合はアカウントの削除を参照してください。

セットアップ

  • 起動時にダウンロードが繰り返される場合: 回線を確認のうえアプリを再起動してください。破損したデータのみ自動で再取得されます。
  • 「整合性チェック失敗」が繰り返される場合: 「再ダウンロード」を試し、改善しなければお問い合わせください。「セルフテスト失敗」「依存ランタイム不足」と表示される場合: 「サポートフォームを開く」から、表示されたメッセージを添えてご連絡ください（初回セットアップのエラー一覧）。
  • 画面右下の「GPU 高速化」に「取得に失敗しました。「再試行」を押すか、次回の起動時にもう一度取得します」と出る場合: 回線を確認のうえ「再試行」を押すか、アプリを起動し直してください（次回の起動時に自動で取り直します）。取得が終わるまでは CPU で検出できますが、速度は落ちます。
  • 「Windows のセキュリティ機能が検出エンジンの起動を一時的にブロックしています」と出る場合: Windows のスマート アプリ コントロールなどが、取得したばかりの検出エンジンを安全性の確認が終わるまで数分間止めていることがあります。初回セットアップの画面は数分おきに自動で再試行するので、閉じずにお待ちください（「今すぐ再試行」でもう一度試すこともできます）。しばらく待っても続く場合は、Windows セキュリティ アプリ → アプリ & ブラウザー コントロール → スマート アプリ コントロール設定 で状態をご確認のうえ（Windows セキュリティ アプリはスタート メニューで検索して開けます）、改善しなければお問い合わせください。アップデートで検出エンジンが新しくなるときは、確認が終わるまで今の検出エンジンで動き続け、終わり次第自動で切り替わります。

サインインとプラン

  • ブラウザで認証したのにアプリが「認証画面に移動しています…」のままになる場合: 「キャンセル」で一度閉じ、もう一度「サインイン」を押してください。
  • 確認コードのメールが届かない場合: 迷惑メールフォルダをご確認ください。届くまで数分かかることがあるので、少し待ってから認証画面でコードを再送信してください。
  • 以前からパスワードでお使いの方: 「サインイン」から同じメールアドレスで確認コードを入力すると、今までと同じアカウントでサインインできます（サインインとライセンス）。
  • 「いまはサインインを受け付けられません。しばらくしてからもう一度お試しください。」と表示された場合: 認証サービスに一時的につながらない状態です。時間をおいてから、もう一度「サインイン」を押してください。続く場合は問い合わせフォームからご連絡ください。
  • 「他の端末でサインイン済みです」と出る場合: 同時に使える端末は 1 台です。「続行」でこの端末に切り替えられます（サインインとライセンス）。
  • 画面上部にオフラインの帯が出る場合: ローカルの機能はそのまま使えます。「もう一度サインインしてください」と出たときだけ、プロフィールメニューからサインインし直してください。
  • プランを変更したのにアプリに反映されない場合: アプリは、画面を前面に戻したとき（前回の確認から 1 分以上たっているとき）、検出オプションを開いたとき、画面が表示されている間は 5 分ごとに変更を確かめ、変わっていれば数秒で反映します（検出の実行中は、終わってから反映されます）。それでも変わらないときはアプリを再起動してください。
  • 残り時間が減らない / 増えない場合: 使用時間は検出が完了したときに加算されます。サインインで無料枠が増えるのはサインイン後の起動から反映されます。

読み込みと検出

  • すでにかかっているモザイクが見つからない場合: 検出オプションの「モザイク」を ON にして検出したかを確かめたうえで、次の順にご確認ください。粒が小さすぎないか（特に 4K の素材）、ぼかし・黒塗りではないか（ブロック状のモザイクだけが対象です）、半透明に重ねたモザイクや背景と同じ色のブロックではないか、GPU の無い PC で検出していないか（結果が少し変わることがあります）。見つからなかった範囲は、編集ページで枠を描き足してください（すでにかかっているモザイクを見つけて、かけ直す）。
  • 検出が極端に遅い場合: GPUが認識されているか（フッターの GPU 表示）、NVIDIAドライバが最新かをご確認ください。GPU不在時はCPUモードで動作し、速度が低下します。
  • 検出オプション画面にプレビューが出ない場合: 「動画情報を取得できませんでした」と表示されるときは、ファイルの破損か非対応形式の可能性があります。「プレビューに必要な動画処理のファイルが見つかりません」と表示されるときは、アプリを再起動して、必要なファイルのダウンロードを完了させてください。
  • 「検出結果の保存先にプロジェクトのフォルダを作成できませんでした」と出る場合（検出オプション画面では「検出結果の保存先にプロジェクトのフォルダを作成できません」と表示されます）:動画の場所ではなく、検出結果の保存先（プロジェクトフォルダ）に書き込めない状態です。保存先を選び直す（メニューの「ファイル」→「プロジェクトフォルダを選択」、または検出オプション画面の「プロジェクトフォルダを選び直す」）か、「既定の場所に戻す」を押してください。セキュリティソフトのフォルダ保護が書き込みを止めている場合は Deepmosaic を許可し、フォルダのアクセス権もご確認ください。外付けドライブやネットワークのフォルダを保存先にしている場合は、接続を確かめてください（プロジェクトフォルダ）。
  • フォルダを選んでも「処理できる動画が見つかりませんでした」と出る場合: サブフォルダの中は対象外です。動画が入っているフォルダを直接選び直してください。
  • 「開始」が押せない場合: モデルファイルの確認中です。しばらく待つか、エラー表示のときは「再試行」を押してください。上限に達している場合はプランの変更（サインインしていないならサインイン）が必要です。残りの検出可能時間が動画の全長より少ない場合も、「開始」の上に理由が表示されて押せません（範囲を絞っても全長で数えます。検出オプション）。
  • 検出したのにホーム画面に出てこない場合: 「すべての動画」には、現在のプロジェクトフォルダにある、サインインしているアカウントで作成したものだけが表示されます。別のプロジェクトフォルダに保存したものは、サイドバーの「他のフォルダ」の行から確認できます（プロジェクトフォルダ）。
  • 「高精度モデルの利用にはサインインが必要です」と出る場合: サインインすると、GPU 搭載機では次の検出から高精度モデルを使えます（それまでは軽量モデルで検出します）。「高精度モデルを準備中」と出る場合は、取得が終わるまで軽量モデルで検出します。
  • 中断した検出が再開できない場合: カードに表示された理由をご確認ください。元の動画を移動・変更した、編集済みなどの場合は再開できないため、「破棄」してから読み込み直してください（AI検出）。

編集

  • 「詳細データがありません」と出る場合: プロジェクトフォルダが移動・削除されています。元の場所に戻すか、「プロジェクトを削除」で一覧から外して読み込み直してください。
  • 「保存失敗」が出る場合: プロジェクトフォルダに書き込めません。ディスクの空き容量、フォルダの権限、クラウド同期の競合をご確認ください（データの保存場所）。
  • 顔の性別が逆に検出されている場合: 枠の右クリックメニュー、または人物ギャラリーで修正できます。
  • 手動で置いた ∞ の枠が途中で消える場合: ∞ の枠は削除したフレームの手前で終わります。続けたい位置でもう一度 2 で追加してください。
  • ホーム画面に「このプロジェクトは前回の起動で問題を起こしました」と出る場合: 「検査」を押し、問題が無ければそのまま開けるようになります。問題が見つかったときは「修復」で直前の保存内容からの復元を試してください。
  • 「変換に失敗したプロジェクトが N 件あります」と出る場合: 「再試行」を押してください。繰り返す場合はお問い合わせください。

エンコード

  • 「GPU エンコードには NVIDIA ドライバ 570 以降が必要です」と出る場合: ドライバを更新するまでは CPU で出力されます（時間はかかりますが結果は同じです）。
  • エンコードが「失敗」になる場合: 保存先の空き容量と権限、出力ファイルを他のアプリで開いていないかをご確認ください。進捗ウィンドウの「失敗」の下にエラー内容が表示されます。
  • 「モザイクが 1 つも適用されません。」と出る場合: 検出が無いか、すべてのトラックをモザイク対象から外しています。編集ページで確認してください。
  • 進捗ウィンドウを閉じてしまった場合: メニューバーの「キュー」から「進捗を別ウィンドウで開く」で開き直せます。

Premiere Pro 連携

  • 「Adobe Premiere Pro がこの PC に見つかりませんでした。」と出る場合: Premiere Pro 25.3 以降をインストールしてください。
  • 「自動インストールに必要な Creative Cloud のコンポーネントが見つかりません」と出る場合: Creative Cloud デスクトップアプリをインストール / 更新してサインインするか、「プラグインのフォルダを開く」から手動でインストールしてください。
  • 送信が「タイムアウト」になる場合: Premiere Pro で Deepmosaic のパネルを開いた状態でやり直してください。プラグインを入れた直後は Premiere Pro の再起動が必要です。

解決しない場合はアプリ内のお問い合わせ、または問い合わせフォームからご連絡ください。フッターのバージョンと、%USERPROFILE%\.deepmosaic\logs\app.log（検出の不具合では、検出ごとのログの置き場 %USERPROFILE%\.deepmosaic\logs\runs の、その検出のころに更新されたファイルも）を添えていただくと調査が早く進みます。

Microsoft Visual C++ 再頒布可能パッケージ

  • 提供元: Microsoft Corporation。Microsoft Visual Studio のライセンス条項に定める再頒布可能コードとして、アプリの実行に必要なランタイム DLL（vcruntime140 / msvcp140 ほか）を同梱しています。

初回に取得する第三者ソフト（NVIDIA 製 GPU 搭載機のみ）

次のコンポーネントはアプリに含めず、NVIDIA 製 GPU を搭載したパソコンでだけ、初回に当社の配信元から自動で取得します（約 1.7 GB をダウンロード、展開後 約 2.4 GB）。NVIDIA 製 GPU の無いパソコンでは取得しません。取得が終わるまでは CPU で動き、機能は変わりません。

NVIDIA CUDA / cuDNN ほか（GPU 高速化のコンポーネント）

  • 提供元: NVIDIA Corporation。NVIDIA GPU 搭載機では、NVIDIA Corporation のソフトウェア (CUDA / cuDNN ほか) をその使用許諾条件に従って当社の配信元から取得し、このパソコンに保存します。取得したものは GPU での処理にだけ使います。
