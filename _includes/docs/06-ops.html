新しいバージョンは Microsoft Store が配信し、Windows の設定に従って自動で更新されます。アプリ内で更新を操作する必要はありません。

自動更新
Microsoft Store の「アプリの更新」が有効なら、新しいバージョンが自動でインストールされます。アプリの起動中は、次に起動したときに新しいバージョンになります
手動で更新する
Microsoft Store アプリの「ライブラリ」（または「ダウンロードと更新」）で「更新プログラムを取得する」を押します。検出やエンコードの実行中は、完了してから更新してください
検出エンジン
アプリに含まれていて、アプリと一緒に更新されます
AI モデル
起動時に新しいものがあれば自動で取得・差し替えられます（初回セットアップと同じ仕組み）
設定とデータ
更新しても設定・検出結果・プロジェクトフォルダはそのまま残ります

手動で確認する（インストーラ版）

{% include docs-h2.html kicker="運用" title="データの保存場所" %}

Deepmosaic は映像やその検出結果をサーバーに送りません。すべてお使いの PC の次の場所に保存されます。

プロジェクトフォルダ
既定 C:\Users\（ユーザー名）\deepmosaic。動画ごとのサブフォルダに、検出結果と編集データをまとめたデータベース（project.db）、サムネイル、顔の代表画像などが入ります。読み込んだ動画自体はコピーされず元の場所から参照します。タイムライン編集で追加した素材（動画・音声・画像）はサブフォルダの assets にコピーされ、プロジェクトの書き出しにも含まれます（プロジェクトフォルダ）
%USERPROFILE%\.deepmosaic
設定（config.json）、ホームの一覧・フォルダ・タグの登録簿（catalog.db）、暗号化されたログイン情報、端末 ID、ログ（logs\app.log、検出ごとのログは logs\runs）。お問い合わせの際にログの添付をお願いすることがあります
%LOCALAPPDATA%\deepmosaic
AI モデル、GPU 用ランタイム（NVIDIA 製 GPU 搭載機のみ）など（合計で 10GB程度）。初回セットアップと起動時の確認で自動管理されます。検出エンジンと動画処理ツールはアプリに含まれています。インストーラ版から Microsoft Store 版に切り替えた場合も、この場所をそのまま使います（Microsoft Store 版を新しく入れた PC では、Windows がアプリ専用の場所に振り替えて保存することがあります）
書き出した動画
エンコード時に指定した保存先。アプリは管理しません

プロジェクトフォルダをクラウド同期フォルダ（OneDrive など）の中に置くと、編集中の自動保存と同期が競合して「保存失敗」になることがあります。ローカルのフォルダをおすすめします。

project.db と catalog.db はアプリが管理するデータベースです。アプリの起動中に他のツールで開いたり、中身を書き換えたりしないでください（データが壊れる原因になります）。バックアップやコピーはアプリを終了してから行い、project.db と同じ名前で始まるファイル（-wal / -shm）があれば一緒にコピーしてください。

{% include docs-h2.html kicker="運用" title="アンインストール" %}
  1. Windowsの「設定」→「アプリ」→「インストールされているアプリ」を開きます（スタートメニューの「Deepmosaic」を右クリックして「アンインストール」でもかまいません）
  2. 一覧から「Deepmosaic」を探し、「アンインストール」を選択します（管理者権限は不要です）

アンインストールしても、設定とログイン情報（%USERPROFILE%\.deepmosaic）とプロジェクトフォルダ（検出結果・編集データ）は残ります。AI モデル等（%LOCALAPPDATA%\deepmosaic、10GB程度）は、Microsoft Store 版を新しく入れた PC ではアンインストールと一緒に削除されますが、インストーラ版から引き継いだ場合は残ります。不要になったフォルダは、アプリをアンインストールした後にエクスプローラーで削除してください（プロジェクトフォルダの中に保存した書き出し動画も消えるのでご注意ください）。元の動画や、プロジェクトフォルダの外に書き出した動画は削除されません。アップデートの際は何も削除されません。

インストーラ版（2.11.1 まで）のアンインストールでは、AI モデル等（%LOCALAPPDATA%\deepmosaic）が自動で削除され、確認画面の「アプリのデータとプロジェクトフォルダを削除する (中の書き出し動画も削除されます)」にチェックを入れると、設定とログイン情報とプロジェクトフォルダも削除されます。Microsoft Store 版を使い続ける場合は、このチェックを入れないでください。

アカウント自体を削除したい場合はアカウントの削除を参照してください。

{% include docs-h2.html kicker="運用" title="トラブルシューティング" %}

セットアップ

  • 起動時にダウンロードが繰り返される場合: 回線を確認のうえアプリを再起動してください。破損したデータのみ自動で再取得されます。
  • 「整合性チェック失敗」が繰り返される場合: 「再ダウンロード」を試し、改善しなければお問い合わせください。「セルフテスト失敗」「依存ランタイム不足」と表示される場合: 「サポートフォームを開く」から、表示されたメッセージを添えてご連絡ください（初回セットアップのエラー一覧）。
  • 画面右下の「GPU 高速化」に「取得に失敗しました。「再試行」を押すか、次回の起動時にもう一度取得します」と出る場合: 回線を確認のうえ「再試行」を押すか、アプリを起動し直してください（次回の起動時に自動で取り直します）。取得が終わるまでは CPU で検出できますが、速度は落ちます。
  • 「Windows のセキュリティ機能が検出エンジンの起動を一時的にブロックしています」と出る場合: Windows のスマート アプリ コントロールなどが、取得したばかりの検出エンジンを安全性の確認が終わるまで数分間止めていることがあります。初回セットアップの画面は数分おきに自動で再試行するので、閉じずにお待ちください（「今すぐ再試行」でもう一度試すこともできます）。しばらく待っても続く場合は、Windows の設定 → アプリとブラウザー コントロール → スマート アプリ コントロール の状態をご確認のうえ、改善しなければお問い合わせください。アップデートで検出エンジンが新しくなるときは、確認が終わるまで今の検出エンジンで動き続け、終わり次第自動で切り替わります。

ログインとプラン

  • ブラウザで認証したのにアプリがログイン中のままになる場合: ダイアログの「キャンセル」で一度閉じ、もう一度「メールアドレスではじめる」または「パスワードで登録済みの方はこちら」を押してください。
  • 確認コードのメールが届かない場合（「メールアドレスではじめる」を選んだ方）: 迷惑メールフォルダをご確認ください。届くまで数分かかることがあるので、少し待ってから認証画面でコードを再送信してください。パスワードで登録済みの方は、待っている画面の「パスワードでログインする」、またはログイン画面の「パスワードで登録済みの方はこちら」から、パスワードでログインすることもできます。前回この PC でパスワードでログインした場合は、ログイン画面の大きいボタンが「パスワードでログイン」になっています（ログインとライセンス）。
  • パスワードを忘れた場合（パスワードで登録済みの方）: 「パスワードで登録済みの方はこちら」を押し、ブラウザの認証画面でパスワードを再設定してください。
  • 確認コードを入力した後に「このメールアドレスはパスワードで登録済みです。『パスワードで登録済みの方はこちら』からログインするか、パスワードを再設定してください。」と表示された場合: パスワードで登録したアカウントのメールアドレスの確認が済んでいません。このとき Desktop 版ではログイン画面のボタンの並びが入れ替わり、大きいボタンが「パスワードでログイン」になっています（案内文にある「パスワードで登録済みの方はこちら」は、この並びでは表示されません）。大きい「パスワードでログイン」からパスワードでログインしてください。パスワードが分からない場合は、同じボタンから開くブラウザの認証画面でパスワードを再設定してください。パスワードを再設定すると、メールアドレスの確認も済み、次からは「メールアドレスではじめる」でもログインできます。
  • 「他の端末でログイン中です」と出る場合: 同時に使える端末は 1 台です。「続行」でこの端末に切り替えられます（ログインとライセンス）。
  • 画面上部にオフラインの帯が出る場合: ローカルの機能はそのまま使えます。「再ログインしてください」と出たときだけ、プロフィールメニューからログインし直してください。
  • プランを変更したのにアプリに反映されない場合: 反映には数十秒かかることがあります。「再確認」またはアプリの再起動で更新されます。
  • 残り時間が減らない / 増えない場合: 使用時間は検出が完了したときに加算されます。ログインで無料枠が増えるのはログイン後の起動から反映されます。

読み込みと検出

  • すでにかかっているモザイクが見つからない場合: 検出オプションの「モザイク」を ON にして検出したかを確かめたうえで、次の順にご確認ください。粒が小さすぎないか（特に 4K の素材）、ぼかし・黒塗りではないか（ブロック状のモザイクだけが対象です）、半透明に重ねたモザイクや背景と同じ色のブロックではないか、GPU の無い PC で検出していないか（結果が少し変わることがあります）。見つからなかった範囲は、編集ページで枠を描き足してください（すでにかかっているモザイクを見つけて、かけ直す）。
  • 検出が極端に遅い場合: GPUが認識されているか（フッターの GPU 表示）、NVIDIAドライバが最新かをご確認ください。GPU不在時はCPUモードで動作し、速度が低下します。
  • 検出オプション画面にプレビューが出ない場合: 「動画情報を取得できませんでした」と表示されるときは、ファイルの破損か非対応形式の可能性があります。「ffmpeg / ffprobe が見つかりません」と表示されるときは、アプリを再起動して初回セットアップのダウンロードを完了させてください。
  • フォルダを選んでも「処理できる動画が見つかりませんでした」と出る場合: サブフォルダの中は対象外です。動画が入っているフォルダを直接選び直してください。
  • 「開始」が押せない場合: モデルファイルの確認中です。しばらく待つか、エラー表示のときは「再試行」を押してください。上限に達している場合はプランの変更（未ログインならログイン）が必要です。残りの検出可能時間が動画の全長より少ない場合も、「開始」の上に理由が表示されて押せません（範囲を絞っても全長で数えます。検出オプション）。
  • 検出したのにホーム画面に出てこない場合: 「すべての動画」には、現在のプロジェクトフォルダにある、ログイン中のアカウントで作成したものだけが表示されます。別のプロジェクトフォルダに保存したものは、サイドバーの「他のフォルダ」の行から確認できます（プロジェクトフォルダ）。
  • 「高精度モデルの利用にはログインが必要です」と出る場合: ログインすると、GPU 搭載機では次の検出から高精度モデルを使えます（それまでは軽量モデルで検出します）。「高精度モデルを準備中」と出る場合は、取得が終わるまで軽量モデルで検出します。
  • 中断した検出が再開できない場合: カードに表示された理由をご確認ください。元の動画を移動・変更した、編集済みなどの場合は再開できないため、「破棄」してから読み込み直してください（AI検出）。

編集

  • 「詳細データがありません」と出る場合: プロジェクトフォルダが移動・削除されています。元の場所に戻すか、「プロジェクトを削除」で一覧から外して読み込み直してください。
  • 「保存失敗」が出る場合: プロジェクトフォルダに書き込めません。ディスクの空き容量、フォルダの権限、クラウド同期の競合をご確認ください（データの保存場所）。
  • 顔の性別が逆に検出されている場合: 枠の右クリックメニュー、または人物ギャラリーで修正できます。
  • 手動で置いた ∞ の枠が途中で消える場合: ∞ の枠は削除したフレームの手前で終わります。続けたい位置でもう一度 2 で追加してください。
  • ホーム画面に「このプロジェクトは前回の起動で問題を起こしました」と出る場合: 「検査」を押し、問題が無ければそのまま開けるようになります。問題が見つかったときは「修復」で直前の保存内容からの復元を試してください。
  • 「変換に失敗したプロジェクトが N 件あります」と出る場合: 「再試行」を押してください。繰り返す場合はお問い合わせください。

エンコード

  • 「GPU エンコードには NVIDIA ドライバ 570 以降が必要です」と出る場合: ドライバを更新するまでは CPU で出力されます（時間はかかりますが結果は同じです）。
  • エンコードが「失敗」になる場合: 保存先の空き容量と権限、出力ファイルを他のアプリで開いていないかをご確認ください。進捗ウィンドウの「失敗」の下にエラー内容が表示されます。
  • 「モザイクが 1 つも適用されません。」と出る場合: 検出が無いか、すべてのトラックをモザイク対象から外しています。編集ページで確認してください。
  • 進捗ウィンドウを閉じてしまった場合: メニューバーの「キュー」から「進捗を別ウィンドウで開く」で開き直せます。

Premiere Pro 連携

  • 「Adobe Premiere Pro がこの PC に見つかりませんでした。」と出る場合: Premiere Pro 25.3 以降をインストールしてください。
  • 「自動インストールに必要な Creative Cloud のコンポーネントが見つかりません」と出る場合: Creative Cloud デスクトップアプリをインストール / 更新してサインインするか、「プラグインのフォルダを開く」から手動でインストールしてください。
  • 送信が「タイムアウト」になる場合: Premiere Pro で Deepmosaic のパネルを開いた状態でやり直してください。プラグインを入れた直後は Premiere Pro の再起動が必要です。

解決しない場合はアプリ内のお問い合わせ、または問い合わせフォームからご連絡ください。フッターのバージョンと、%USERPROFILE%\.deepmosaic\logs\app.log（検出の不具合では、検出画面のログの「ログフォルダを開く」で開くフォルダの該当ファイルも）を添えていただくと調査が早く進みます。
