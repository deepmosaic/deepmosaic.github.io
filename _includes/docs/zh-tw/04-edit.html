在首頁畫面按一下影片卡片，就會開啟編輯頁面。畫面由上方的「頁首」、沿邊緣直向排列的「側邊欄」（以及在其旁邊開啟的抽屜面板）、中央的「影片播放器（內建編輯工具列）」與下方的「時間軸」組成。

頁首左側

中繼資訊
影片長度 / 總影格數 / fps / 解析度 / 新增日期
頁首右側
開啟資料夾 / 人物圖庫 / 匯入至 Premiere Pro / 匯出 等按鈕，以及儲存狀態的顯示。匯出的等候清單可在選單列的「佇列」中查看
儲存狀態
編輯內容會在操作後約 1 秒自動儲存。即時顯示「儲存中…」「未儲存」「已儲存」，失敗時會顯示「儲存失敗」。開始匯出時、離開編輯頁面時與關閉應用程式時，也會儲存尚未儲存的部分
側邊欄
媒體 / 文字 / 浮水印 / 音訊 / 淡化 / 轉場 共 6 個項目。按下後會在旁邊開啟抽屜面板，可匯入素材，或設定文字、背景音樂等（側邊欄與抽屜面板）
時間軸
排列著場景列、文字、片段與音訊的通道，以及各偵測類別的列。按下片段接點上的剪刀，即可選擇淡化或轉場（播放器與時間軸 / 編輯片段 / 淡化）
工具提示
將滑鼠移到按鈕上，就會立即（約 0.15 秒）以工具提示顯示該功能的說明與快捷鍵
載入中的顯示
開啟編輯頁面後，在偵測結果全部就緒之前會顯示「正在載入偵測結果」與進度，接著顯示播放器，且從第一個影格起就已顯示框。第一次開啟以舊版偵測的專案時，會顯示「正在將偵測結果轉換為新的儲存格式」（只會轉換 1 次）
沒有詳細資料
找不到偵測結果的檔案時會顯示（例如移動或刪除了專案資料夾）。可用此畫面的「刪除專案」將其從清單中移除
{% include docs-h2.html kicker="編輯" title="播放器與時間軸" %}

播放器會以各類別的顏色疊加顯示偵測框（BBox）。可直接拖曳框來編輯位置與大小。支援逐格移動與跳轉，下方的時間軸會繪製偵測的分布與場景（鏡頭）列，按一下即可跳至任意影格。

偵測類別會以顏色區分：身體部位（紅）/ 男性臉部（藍）/ 女性臉部（粉紅）/ 使用者建立（黃）/ 排除遮罩（青綠）/ 馬賽克（紫，素材上原本就有的馬賽克。僅限在偵測選項中開啟「馬賽克」後偵測的專案）。框上方的標籤會顯示「類別名稱 #ID（3 字元的代碼） 信賴度%」；手動新增的框會標示「使用者」，排除遮罩會標示「排除」，排除於馬賽克對象之外的追蹤軌跡則會加上「[已排除馬賽克]」。在側邊欄的「設定」中關閉「顯示 BBox 標籤（名稱、ID、機率）」後，就不會顯示標籤（框仍會顯示。側邊欄與抽屜面板）。

馬賽克（紫）的框是多邊形（最多 255 點），與其他多邊形的框一樣，可以移動頂點來修正形狀（下方的「頂點的範圍選取與彎曲」、找出既有馬賽克並重新套用）。

播放控制

播放 / 逐格移動
移至開頭（Home）/ 後退 1 個影格（←）/ 播放、暫停（Space）/ 前進 1 個影格（→）/ 移至結尾（End）。按 PageUp / PageDown 移動 10 個影格。也可用滑鼠滾輪逐格移動，Shift+滾輪則移動 10 個影格。選取 BBox 時，以 Shift+→（或 Shift+滾輪向上）前進，會沿用該框的形狀逐格前進（下方「偵測框的操作」中的「沿用形狀逐格前進」）
跳轉
拖曳滑桿、在時間軸上按一下 / 拖曳，以及時間與影格編號（frame N / M）的顯示
靜音（V）
關閉預覽的聲音。不影響匯出
切換疊加層顯示（H）
隱藏所有偵測框、標籤、ID 與機率，只確認影像。編輯內容不會改變
播放速度
在工具列中從 0.25x / 0.5x / 1x / 1.5x / 2x / 4x 選擇（按 , 變慢、按 . 變快）

偵測框的操作

選取
按一下框，會顯示粗框與 8 個控點。同時，邊緣羽化所及的範圍會以虛線顯示在框的外側（與 Premiere Pro 的遮色片羽化相同，寬度為設定值的一半，位於輪廓外側。邊緣羽化為 0、框屬於不套用馬賽克的追蹤軌跡，或已隱藏疊加層（H）時不會顯示）
移動 / 變更大小
拖曳框的內側即可移動，拖曳控點即可變更大小。播放中也可以拖曳
刪除
選取後按 Delete、按兩下框，或使用右鍵選單的「刪除此 BBox」。刪除只會套用到該影格的框（同一 ID 的其他影格會保留）
連續刪除（橡皮擦）
在影像上按住 E 鍵，同時按住右鍵拖曳，即可當作橡皮擦。預設會從該影格刪除碰到圓圈的框。可用工具列的橡皮擦按鈕選擇擦除方式（刪除觸碰到的 BBox / 僅刪除觸碰到的部分）、形狀（圓形 / 圓角矩形）與大小（8～120px）。使用「僅刪除觸碰到的部分」時，擦除後的痕跡會以框的形狀（多邊形）保留下來；手動新增的框被分成 2 塊時，每一塊會各自成為獨立的框。按住不放時播放或用滾輪逐格移動，也能接著擦除經過的影格中的框（沒有按住 E 的右鍵拖曳，或右鍵沒有移動就放開時，會開啟一般的右鍵選單）
刪除整個 ID（標籤的 ✕）
按下偵測到的框的標籤右端的 ✕，會從所有影格一次刪除該 ID 的框。刪除前會出現確認訊息，並顯示要刪除的影格數。手動新增的框的標籤不會顯示 ✕，但可用右鍵選單的「刪除此 ID 的全部」達到相同效果
右鍵選單
臉部的框有「變更為男性臉部」「變更為女性臉部」（修正偵測到的性別）。所有的框都有「排除於馬賽克對象之外」「重新納入馬賽克對象」（將整條追蹤軌跡排除於馬賽克對象之外 / 恢復），其下方是「反轉（外側套用馬賽克）」「反轉（外側套用模糊）」（下方的「反轉」）、「設為排除遮罩」（排除遮罩的框則為「改回馬賽克」。將既有的框改為排除遮罩）、「刪除此 BBox」、「刪除此 ID 的全部」（用於偵測到的框時，與標籤的 ✕ 相同。用於手動新增的連續 BBox / 1 個影格的框 / 排除遮罩時，會從所有影格一次刪除該框。若有合併到偵測 ID 的連續 BBox 也會一併刪除，確認中會顯示其數量。兩者都可用 Ctrl+Z 按 1 次復原）。連續 BBox 有軌跡時會有「清除移動軌跡」。有可合併的 ID 時會有「合併 ID…」，已合併的 ID 則有「取消合併」（下方的「ID 合併」）。使用「變更形狀」可選擇範圍（此 BBox / 此 ID 全部 / 全部）並改為矩形 / 橢圓 / 多邊形，使用「將形狀重設為預設」可恢復原本的形狀。「從這裡連接」，已選擇連接來源時則有「設為中間點」「連接到這裡」。關鍵影格與連接操作請參閱追蹤與關鍵影格
反轉（套用於外側）
在框上按右鍵並選擇「反轉（外側套用馬賽克）」或「反轉（外側套用模糊）」，該 ID 就會切換為反轉。反轉中的框的選單會變成「取消反轉（套用於內側）」，選擇後即可恢復。排除遮罩不會顯示此項目。套用的位置與在「依 ID」分頁的切換方式，請參閱馬賽克設定面板的「反轉（套用於外側）」
ID 合併
同一個對象卻被分成不同的 ID 時，在要保留的框上按右鍵並選擇「合併 ID…」。可合併的 ID 清單（「要合併到 #XXX 的 ID」）會依距離由近到遠開啟，選擇要合併的 ID 後，就會合併到按右鍵的 ID。清單的每一列會列出 #ID 與類別名稱、區段（影格與時間）、相隔幾個影格之後 / 之前（或「相鄰」），選取中的框會在開頭顯示「已選取」。也可以用 ↑ / ↓ 與 Enter 選擇，按 Esc 關閉。超過 8 個時，可用「還有 N 個」顯示其餘項目。在下方時間軸中各 ID 的列上按右鍵，也會開啟相同的清單。合併後會當作 1 個 ID 處理（時間軸的列、依 ID 的馬賽克設定與匯出皆是如此），中間若有沒有框的影格會自動內插。可合併的是同一類別、且沒有在同一時間出現的 ID（同時出現的是不同的對象）。沒有可合併的 ID 時，清單中會顯示「沒有可合併的 ID」
連續 BBox 的合併
連續 BBox（∞）之間，以及連續 BBox 與偵測到的 ID 也可以合併。在連續 BBox 上按右鍵並選擇偵測到的 ID 時，會保留偵測到的 ID（清單的該列會顯示「偵測到的 ID 會成為主體」）。連續 BBox 之間的時間重疊時，會將較早開始的一方在另一方開始之前截斷（取消合併後即恢復原狀）。排除遮罩無法合併
合併的復原與取消
剛合併後，按 1 次 Ctrl+Z 就能回到合併前的狀態。之後要恢復時，可在合併目標的框上按右鍵並選擇「取消合併（N 個 ID）」，或在時間軸的 ID 列上按右鍵，選擇清單最後的「取消合併（N 個 ID）」
頂點的範圍選取與彎曲（Shift+左鍵拖曳）
選取多邊形的框後，按住 Shift 並以左鍵拖曳圈住頂點，即可一次選取圈住的頂點（會整合為相連的區段。只有 1 點時為選取 1 點，短按一下或按 Esc 即可解除）。拖曳所選區段內側的頂點，會在固定區段兩端的情況下彎曲，越靠中央移動越大。圈住所有頂點時，會保持形狀移動。拖曳區段端點的頂點時，只有該 1 點會移動。選取多個頂點時，無法按 Delete 刪除頂點（請一次選取 1 點後再刪除）
排除馬賽克的提示
有排除於對象之外的追蹤軌跡時，會持續顯示「N 條追蹤軌跡已排除馬賽克」。可用「全部恢復套用馬賽克」一次恢復。排除的部分在匯出時也不會套用馬賽克
預覽的留白與框外
預覽中，影像的上下左右有留白（每邊約 15%，深灰色），影像的邊界會畫上細框線。框可以移動或放大到超出影像、延伸至留白的位置，即使人物走出畫面，也能放置橢圓等形狀而不被壓扁。超出的部分不會匯出，但影像內側會維持該形狀，一直套用馬賽克到影像邊緣。新繪製的框必須與影像重疊，只拖曳留白無法繪製
在畫面邊緣被截斷的偵測框
碰到畫面邊緣而被截斷的偵測框，會依碰到邊緣前後影格的大小，自動補足到畫面外。馬賽克只會繪製在畫面內，但形狀（橢圓等）是依補足後的框決定，因此即使臉部走出畫面，馬賽克的形狀也不會在邊緣被壓扁。預覽與匯出都會反映。此補足功能適用於以 2.8.1 以上版本偵測的影片
繪製框（左鍵拖曳）
在影像的空白處以左鍵拖曳，即可繪製工具列形狀選擇中所選形狀（矩形 / 橢圓 / 多邊形）的框。多邊形是按一下放置頂點，再按一下起點 / 按 Enter / 按兩下即可封閉。繪製的框預設是會延續到之後影格的連續 BBox，可在形狀選擇選單的「繪製的 BBox」中改為「僅此影格」，在「繪製的 BBox 類型」中改為「排除遮罩」。只拖曳留白無法繪製框（請繪製成與影像重疊）。放大時要移動影格，請使用 Ctrl+左鍵拖曳（中鍵拖曳也可以）
手動新增的框的顯示
手動新增的框的標籤會顯示「使用者」，ID 與偵測到的框一樣是 3 字元的代碼（例：#K7Q）。在時間軸中會排列在「使用者」的列
沿用馬賽克設定
在偵測到的框上重疊新增框，或在其附近（間隔在畫面短邊的 5% 以內）新增框時，會複製該偵測框所套用的馬賽克設定（類型、模糊、不透明度、馬賽克格的大小）。馬賽克格的大小會固定為與該偵測框看起來相同。複製的設定隨時可在馬賽克設定的「依 ID」分頁中變更
沿用形狀逐格前進（Shift+→）
按一下框將其選取，按住 Shift 並按 →（或將滾輪向上）前進，會以開始按 Shift 時的位置、大小與形狀逐格前進，並覆寫前進到的影格中的該框。沿用中的框的標籤會顯示「[沿用中]」。到放開 Shift 為止是 1 個操作，按 1 次 Ctrl+Z 即可一併復原。前進到的影格中沒有該框時會略過，連 1 個影格都無法寫入時，會顯示「前進到的影格中沒有此 BBox，無法沿用形狀。」。Shift+← 會不沿用形狀後退 1 個影格。以播放按鈕播放、以 PageDown 移動 10 個影格、僅 1 個影格的手動框，以及匯入素材的區段，都不會沿用
固定沿用（Shift ×2）
選取框後快速按 2 次 Shift，會進入放開 Shift 後仍持續沿用的「固定」狀態，標籤會顯示「[沿用：固定]」。固定期間，不按 Shift 的 → 或滾輪向上也會沿用形狀前進（PageDown 與播放按鈕不會沿用）。再快速按 2 次 Shift，或按 Esc 即可解除。固定期間重新選擇其他框，下次前進時就會沿用該框的形狀。在輸入法（IME）等軟體會使用單按 Shift 的環境中，可能無法進入固定狀態

只有在播放指標位於原始影片（偵測來源）的區段時，才能選取、新增偵測框與使用橡皮擦。匯入的素材區段不在 AI 偵測的範圍內，因此沒有框。

時間軸

時間軸由上而下依序為工具列、刻度、場景（鏡頭）列、文字、片段與音訊的通道（編輯片段），以及各偵測類別的列。類別的列會以色條畫出有偵測的區段，手動新增的框排列在「使用者」列，排除遮罩排列在「排除」列。可用列首的 {% include icon.html name="ChevronDown" class="inline h-3.5 w-3.5 align-[-2px]" %} 展開為各追蹤 ID 的列。在 ID 的列上按右鍵，會開啟可合併到該 ID 的 ID 清單（上方的「ID 合併」。已合併的 ID 會在清單最後顯示「取消合併」）。按右鍵不會移動到該位置。排除於馬賽克對象之外的追蹤軌跡會以淡色顯示。時間軸依匯出影像的時間排列，因此修剪或移動片段時，偵測的色條也會一起移動。

時間軸可用 Ctrl+滾輪，或工具列左端的放大、縮小按鈕放大到最多 16 倍。高度的變更與摺疊請參閱編輯片段。

{% include docs-h2.html kicker="編輯" title="縮放與平移" %}

為了精確對齊小對象的框，可將播放器的影像放大到最多 8 倍。放大時也能照常移動框、變更大小、新增與刪除。

放大 / 縮小
Ctrl+滾輪（以游標位置為中心縮放）、+ / - 鍵，或播放器右上的 {% include icon.html name="Maximize2" class="inline h-3.5 w-3.5 align-[-2px]" %} 按鈕。目前的倍率會顯示在按鈕之間
平移（移動顯示位置）
Ctrl+左鍵拖曳，或中鍵（滾輪）拖曳。沒有放大時（原始大小）不會移動。在空白處以左鍵拖曳會繪製框
重設
按 0 鍵或「重設縮放」按鈕，即可回到原始大小並置中
{% include docs-h2.html kicker="編輯" title="新增偵測框（1f 與 ∞）" %}

沒有偵測到的地方，可用工具列的「1f」（內有＋的方框，附有 1f）與「∞」（內有 ∞ 的方框）按鈕手動新增框。新增的框會以「使用者」類別（黃）放在目前影格的中央，請拖曳以對齊位置與大小。馬賽克設定（包括依 ID）也會直接套用到手動的框。

1f（1）
只在此影格放置框。不影響前後的影格。適合修補只有幾個影格沒有偵測到的「中間缺漏」
∞ 連續 BBox（2）
從放置的影格起，之後的所有影格都會在相同位置延續框。不想延續到影片結尾時，請在要結束的影格刪除框（刪除影格之前的部分會確定為有效範圍）
移動連續 BBox
一邊播放一邊拖曳 ∞ 的框，其移動會記錄為軌跡，可讓框跟隨被攝體的移動。記錄的軌跡可用右鍵選單的「清除移動軌跡」清除。要讓框自動跟隨對象時，請使用追蹤
復原
若上一個編輯是 ID 的合併、全部刪除、對範圍套用形狀或依類別改為排除遮罩，Ctrl+Z 只會復原該編輯（偵測框的操作）。其他情況下，以刪除方式結束 ∞ 框後立刻按下，會先取消已確定的結尾（快捷鍵說明中為「解除凍結」）；若沒有，則與「重設目前影格」相同，將目前影格的編輯復原

排除遮罩（不套用馬賽克的範圍）

想讓重疊的馬賽克只空出其中一部分時（例如只想讓臉旁邊的手部露出），請放置排除遮罩。排除遮罩的內側不會套用馬賽克，會以原本的影像顯示與匯出。排除遮罩不會追蹤，對於移動的對象，請拖曳以對齊位置。

1f 排除遮罩（3）
只放置在此影格
∞ 連續排除遮罩（4）
從放置的影格起延續到之後的影格（結束方式與連續 BBox 相同，在要結束的影格刪除）
形狀與繪製
會以工具列形狀選擇中所選的形狀（矩形 / 橢圓 / 多邊形）放置。將形狀選擇選單的「繪製的 BBox 類型」設為「排除遮罩」後，即可用左鍵拖曳繪製排除遮罩
顯示
框與標籤為青綠色的「排除」，排列在時間軸的「排除」列。可在馬賽克套用預覽（M）中確認馬賽克被挖空的樣子
邊緣的羽化
排除遮罩的邊緣會以與手動框相同的邊緣羽化設定來融合。大小（框擴展比例）沒有作用
Premiere Pro
排除遮罩不會傳遞到 Premiere Pro 整合

將既有的框改為排除遮罩

偵測到的框與手動新增的框，之後也可以改為排除遮罩。改為排除遮罩的框內側，重疊的其他馬賽克也不會套用。

逐一變更
在框上按右鍵，選擇「設為排除遮罩」。偵測到的框，該 ID（含合併的 ID）的所有影格都會成為排除遮罩。手動新增的框，則是該框改為排除遮罩。要改回時，在排除遮罩的框上按右鍵，選擇「改回馬賽克」
依類別一次變更
在馬賽克設定（G）的「依類別」分頁選擇類別，按下「將此類別全部設為排除遮罩」。會出現顯示對象 ID 數量的確認。對象為當時存在的、該類別中偵測到的 ID（臉部包含男性臉部與女性臉部兩者。不包含手動新增的框，以及之後才增加的 ID）。按「將此類別全部改回馬賽克」即可一次改回馬賽克。兩者都可用 Ctrl+Z 按 1 次復原
顯示
改為排除遮罩的框，會與其他排除遮罩一樣以青綠色的「排除」顯示，並列在時間軸的「排除」列。改為排除遮罩的 ID 無法合併。合併後才將 ID 改為排除遮罩時，以「取消合併」分開的 ID 會回到馬賽克
Premiere Pro 與舊版本
改為排除遮罩的變更不會傳遞到 Premiere Pro 整合。以早於 2.18 的 Deepmosaic 開啟並儲存專案時，改為排除遮罩的偵測框會回到馬賽克（會回到被遮住的狀態，因此不會出現未遮住的部分）

框的新增、移動與刪除都會自動儲存，並反映在匯出中。傳遞到 Premiere Pro 整合的只有偵測結果與邊緣羽化的值，在此畫面中對框的編輯（移動、變更形狀、刪除、排除遮罩等）不會傳遞。

「追蹤」是讓手動放置的 ∞ 連續 BBox 隨著播放，自動跟上對象移動的功能。以控制列的按鈕切換開啟 / 關閉。「關鍵影格」是將手動修正的影格當作移動的基準，自動連接關鍵影格之間的機制。

追蹤

  1. 放置框。放置或繪製 ∞ 連續 BBox（2），並對齊對象（新增偵測框）
  2. 開啟追蹤模式。按下控制列的追蹤按鈕（{% include icon.html name="Crosshair" class="inline h-3.5 w-3.5 align-[-2px]" %}），或按 X
  3. 前進。以播放、→ 或滾輪向上任一方式前進，框就會跟著對象移動
追蹤模式（X）
開啟期間，以前進的操作（播放 / → / 滾輪向上）進行追蹤。← 等後退的操作不會追蹤。再按一次即關閉
追蹤的框
會追蹤目前影格中可見的所有 ∞ 連續 BBox。不需要選取框。也能同時追蹤多個框，數量沒有上限。框越多，追蹤越慢，播放也會相應地等待追蹤。1f 的框與排除遮罩不會追蹤（「排除遮罩無法追蹤。」）
播放速度
追蹤期間最快以原速播放。追蹤跟不上時，會暫停等待直到追上
停止的時機
跟丟對象、對象移出畫面、場景切換等情況下會停止追蹤，並顯示原因（例：「在此處跟丟目標，已停止追蹤。」）。此時 ∞ 框會在最後成功追蹤的影格結束，不會延續到之後。追蹤到影片的結尾時，會顯示「已追蹤到影片的結尾。」
復原（Ctrl+Z）
1 次追蹤的結果，即使同時追蹤了多個框，也能按 1 次 Ctrl+Z 一併回到開始追蹤之前的狀態（框的結尾也會復原）
追蹤完畢的框
追蹤完畢的框，即使再次播放也不會重新追蹤。在追蹤模式開啟時手動修正框，會從修正的影格起（到下一個手動修正的影格之前）重新追蹤。要從頭重新追蹤時，請刪除框後重新放置
追蹤的種類
有 GPU 的電腦會自動選擇「高精度追蹤」，其他電腦則自動選擇「標準追蹤」。偵測執行期間會使用標準追蹤。開始追蹤後將滑鼠移到追蹤按鈕上，會以「使用中：高精度追蹤（GPU）」的形式顯示正在使用的追蹤
需要新的偵測引擎
顯示「追蹤需要較新的偵測引擎。」時，請套用更新

關鍵影格

修正 ∞ 連續 BBox 時
對於沒有追蹤的 ∞ 框，手動修正的影格會成為「關鍵影格」，與前一個關鍵影格之間會自動平順地連接。在追蹤模式關閉時修正已追蹤的 ∞ 框，只有修正的影格會改變
關鍵影格（F）
將選取中的框的目前位置，在不移動的情況下設為關鍵影格
修正 AI 的框時
只有修正的影格會改變

連接

以不同影格中的框作為點，建立 1 條在各點之間依對象的移動而移動的 ∞ 連續 BBox。除了開始與結束之外，途中的點（中間點）可以放置任意多個。

  1. 放置開始的點。在起始的影格選取框，按 Y（或選擇框的右鍵選單中的「從這裡連接」）。播放器的左下會顯示「連接來源：#K7Q @ 3」之類的內容，以及下一步操作的說明
  2. 視需要放置中間點。移到途中的影格，選取貼合對象的框後按 Shift+Y（或選擇右鍵選單中的「設為中間點」）。可放置任意多個。在同一影格再放置一次會取代原本的點（「已取代同一影格的點。」）
  3. 在結束的點連接。在結束的影格選取框，按 Y（或選擇右鍵選單中的「連接到這裡」）。各點之間會立即以平滑內插連接，並顯示「已連接 BBox（#K7Q → #K7Q，31 個影格）」之類的訊息。放置了中間點時會一併顯示其數量
  4. 依序進行追蹤。連接的區段會加入「追蹤佇列」，各點之間的框會依對象的移動重新修正（下方的「追蹤佇列」）。不必等待完成，即可繼續進行下一次連接或其他編輯
可連接的框
作為點的框可以是 AI 的框，也可以是手動新增的框。可連接同一場景中、不同影格的框（中間點也相同）
無法追蹤時
追蹤時跟丟對象時，會套用到能追蹤的部分為止，其餘維持平滑內插（追蹤佇列的列會顯示「在 f120 失去目標」之類的內容）。開始的點為排除遮罩時，或連接相鄰影格的框時，只會以內插連接，不會加入追蹤佇列。無法使用追蹤時也只會以內插連接，並顯示「無法追蹤對象，因此以平滑內插連接。」
以連續 BBox 作為點時
開始的點或中間點的框為 ∞ 連續 BBox 時，在設為點的當下就會變成只在該影格的框（若是放置在該影格的框，該框會變成只有 1 個影格的框；若是從之前的影格延續過來的框，會在此影格之前結束，並在此影格建立 1 個影格的框）。結束的點的框為 ∞ 連續 BBox 時，該框會在點之前結束（若是放置在該影格的框則會消失），並由連接的框取代
原本的框
原本的 AI 的框不會消失，在中間的影格會與連接的框重疊。作為點的只有 1 個影格的框會消失。連接的框會在結束的點的影格結束
修正中間
以追蹤連接的框會被視為已追蹤的框。在追蹤模式（X）開啟的狀態下修正中間的影格，會從該處重新追蹤到下一個點之前。關閉時，只有修正的影格會改變。全部以平滑內插連接的框，在暫停時於中間的影格修正，該影格就會成為關鍵影格，前後會重新平順地連接（上方的「關鍵影格」）
復原（Ctrl+Z）
剛連接後，按 1 次 Ctrl+Z 即可回到連接之前（以連續 BBox 作為點時，會回到原本的連續 BBox。追蹤佇列的追蹤完成後，只要沒有進行其他編輯也相同）。修正中間之後，按 Ctrl+Z 也不會回到連接之前，要重新建立時，請以框的右鍵選單中的「刪除此 ID 的全部」刪除
停止（Esc）
放置點之後要停止時，按 Esc。若已將點的框變成只有 1 個影格的框，會維持原樣（在 Esc 之後立即按 Ctrl+Z，變更過的框會全部還原為原本的連續 BBox。中間做了其他編輯就無法還原）
追蹤前修正了區段時
在追蹤佇列中等待或追蹤期間，手動修正該區段的框時，該次連接會從佇列移除，框維持內插的結果（「因手動修改了區段內的框，已取消追蹤。框保留為內插結果。」）
無法連接時
以下情況不會連接，並會顯示原因：同一影格的框（「無法連接：這是同一個影格。」）、跨場景的框（「無法連接：跨場景的 BBox 無法連接。」）、中間有排除遮罩（「無法連接：中間有排除遮罩。」）、BBox 與排除遮罩的組合（「無法連接：BBox 與排除遮罩的類型不同。」）

追蹤佇列

連接的區段的追蹤會加入「追蹤佇列」，並依序一次處理 1 件。在有 GPU 的電腦上，追蹤之後還會接著進行輪廓精修（與馬賽克精修相同，讓框貼合物體形狀的處理）。完成後，各點之間的內插框會替換為追蹤（與精修）的結果。手動放置的點所在影格的框不會改變。

面板與顯示
有連接的區段時，播放器上方會出現「追蹤 45% · 等待 2」之類的小型顯示（附進度列）。按下後會開啟「追蹤佇列」面板，按面板的「—」即可回到小型顯示。面板與小型顯示都可拖曳移動，位置與開關狀態在下次開啟編輯頁面時也會沿用。畫面下方的狀態列也會顯示「● 追蹤 45%（3 項）」之類的進度，按下即可開關面板（沒有項目時為「追蹤：無等待項目」，有跟丟目標的區段等情況時為「● 追蹤發生錯誤」）
面板的看法
由上而下依序為：執行中的 1 件（狀態「追蹤中」「精修輪廓中」「已暫停」、ID、A 點與 B 點的影格、進度 %、速度、剩餘時間的估計）、「等待中 · N」的清單、「已完成 · N」的清單。面板下方會顯示「全部剩餘約 2 分 10 秒」之類的整體剩餘時間估計，全部完成後會顯示「全部處理完成」
暫停 / 取消
按執行中列的「暫停」即可停止，按「繼續」會從停止處繼續。以 ✕（「取消」）停止該處理時，框會維持內插的結果
調整順序 / 移除
按等待中列的 ↑（「優先處理」）可與前一件交換順序。以 ✕（「從佇列移除」）移除時，該區段的框會維持內插的結果
查看 / 重試
按已完成列的「查看」，會移到該區段的開頭並選取結果的框。跟丟目標的列會以紅色顯示「在 f120 失去目標」之類的內容。跟丟之前能追蹤的部分會套用，其餘維持內插的結果。按「重試」可回到等待中。追蹤中途停止時會顯示「無法完成追蹤」。按「清除已完成」可從清單中一次清除已結束的列
與其他操作的關係
追蹤模式（X）以及手動修正框後的重新追蹤會優先進行。在這段期間佇列的處理會暫停，結束後會自動繼續。偵測執行中不會進行輪廓精修，只會套用追蹤的結果（「偵測執行中，已略過輪廓精修，只套用追蹤結果。」）
不進行精修的電腦
沒有 GPU 的電腦、GPU 記憶體少於 4 GB 的電腦，或尚未取得馬賽克精修的 AI 模型時，不會進行輪廓精修，只以追蹤完成
離開編輯頁面時
追蹤佇列只在開啟編輯頁面期間運作。在仍有未完成的處理時離開編輯頁面、進行編碼或傳送到 Premiere Pro，會出現「追蹤尚未完成」的確認。直接繼續時，未完成的區段會維持內插的結果
進度列上的帶狀標示
佇列中的區段會以帶狀標示顯示在進度列上方（執行中顯示進度，完成後為綠色）。可在側邊欄「設定」中的「在進度列顯示追蹤區段」設為不顯示

一次修正一段區間

手動修正 AI 的框時，只有該影格會改變。要一次修正數秒到數分鐘的區間時，請依情況使用以下操作。

對象會移動
以開頭與結尾（及途中）影格的框作為點，以追蹤連接（Y / Shift+Y）（上方的「連接」）。要手動修正時，在暫停且追蹤模式關閉的狀態下，於區間的開頭放置 ∞ 連續 BBox（2）並對齊對象，再於中間與結尾的影格修正位置與大小。修正的影格之間會自動平順地連接（上方的「關鍵影格」）。移動複雜時，以追蹤（X）讓框跟隨對象，只修正偏移的影格（上方的「追蹤」）
對象幾乎不動
選取修正後的框，快速按 2 次 Shift，再以 → 前進，相同的位置、大小與形狀就會寫入之後的影格（固定沿用）。按 Esc 解除
一律放大或縮小區間內的框
在馬賽克設定（G）的「依時間」分頁按「新增範圍」，將開始與結束對齊區間後，變更「大小（框擴展比例）」。對範圍內所有的框（包含手動新增的框）有效。要以場景為單位變更時，在「依場景」分頁的「目標場景：」選擇該場景（在區間的開頭與結尾按 Ctrl+K 即可分隔。場景）。只要變更特定對象時，請使用「依 ID」分頁（對該 ID 的所有影格有效）

請注意以下幾點。

  • 手動新增的框會與 AI 的框重疊，AI 的框仍會保留。AI 的框過大或偏移的區間，可用橡皮擦（按住 E+右鍵拖曳並播放）連續擦除，或以框的右鍵選單中的「排除於馬賽克對象之外」將該 ID 整體排除於馬賽克對象之外（偵測框的操作）
  • 關鍵影格之間的內插，只有在暫停且追蹤模式關閉的狀態下修正時才會作用。追蹤模式開啟期間，以及播放中拖曳（記錄軌跡）時不會內插
  • ∞ 連續 BBox 在刪除之前，會以相同位置持續出現在之後的影格（場景切換也不會停止）。在要結束的影格選取框後按 Delete，或選擇右鍵選單中的「刪除此 BBox」，就會刪除從該影格起的部分
  • 連接只限同一場景中的框
  • 手動新增的框（∞ 連續 BBox、連接的框）會將建立時的大小當作「依 ID」的設定儲存。之後在「全部」「依場景」「依時間」等設定的值，對手動新增的框也有效（以最後設定的為優先。馬賽克設定面板）
  • 將預覽切換為馬賽克套用預覽（M），即可確認馬賽克的範圍

偵測時會自動判定影像的鏡頭切換（場面的轉換），並以場景列顯示在時間軸的上方。場景是「自動像素大小」開啟時保持馬賽克格大小一致的單位，也是依場景變更馬賽克設定的單位。

移至場景
按一下場景列，就會跳至該場景的第一個影格。場景列會顯示編號（#1, #2 …），將滑鼠移到上面即可確認區段
分割（Ctrl+K）
使用時間軸工具列（放大、縮小按鈕右側）的 {% include icon.html name="Scissors" class="inline h-3.5 w-3.5 align-[-2px]" %} 按鈕或 Ctrl+K，以目前影格為界將場景分成 2 個。適用於自動判定遺漏的鏡頭切換，或想在同一鏡頭內變更設定的地方

刪除

{% include docs-h2.html kicker="編輯" title="馬賽克設定面板" %}

可依 5 個套用範圍（分頁）設定馬賽克的外觀。同一個框在同一影格套用多個設定時，以最後設定的為優先（下方的「設定的優先」）。面板可拖曳頁首移動到任意位置，拖曳右下角即可變更大小（也可選取角後用方向鍵調整，按兩下則恢復預設大小）。開啟時也能繼續編輯。變更值後，會當場反映在馬賽克套用預覽（M）中。

套用範圍分頁
全部（全域預設值）/ 依類別（身體部位、臉部等。在有既有馬賽克框的專案中也會出現「馬賽克」）/ 依 ID（被追蹤的各個對象）/ 依場景（以鏡頭為單位）/ 依時間（時間範圍。下方的「依時間」）。在依 ID、依場景與依時間中，以下拉式選單選擇對象。正在覆寫的範圍會顯示「已覆寫」，可用「清除」個別解除。「依類別」分頁中也有「將此類別全部設為排除遮罩」「將此類別全部改回馬賽克」（將既有的框改為排除遮罩）
信賴度臨界值
只將信賴度在指定值以上的偵測結果顯示並列為馬賽克對象（0～100%，不受分頁影響的全域設定）
類型
馬賽克（方塊狀）/ 模糊（高斯模糊）。預設：馬賽克
大小（框擴展比例）
從中心放大或縮小偵測框，以調整馬賽克範圍（0.50x～2.00x）。預設：1.05x。若不想讓範圍太貼近邊緣，請設大一些
不透明度
馬賽克 / 模糊合成的強度（0～100%）。預設的 100% 會完全覆蓋對象。值越低，遮蔽效果越弱，因此通常維持 100% 即可
邊緣羽化
羽化馬賽克區域的邊緣，使其與背景融合（0～64px）。預設：6px。與 Premiere Pro 遮色片的「遮色片羽化」意思相同，以輪廓為中心向內側與外側各羽化一半（值為內外合計的寬度）。在播放器中選取框後，羽化所及的外側範圍會以虛線顯示。排除遮罩的邊緣也會以相同的值融合
模糊強度
僅在類型為「模糊」時顯示。數值（2～64）越大，模糊越強。在拖曳之前會顯示「自動 (n)」，並依邊緣羽化的寬度決定（外觀與以往相同）。拖曳後，即使變更邊緣羽化，模糊強度也不會改變。按還原按鈕（「重設為自動」）即可回到「自動」。將類型改回「馬賽克」後，值仍會保留。不會傳送到 Premiere Pro 整合
像素大小
以「設定像素大小」按鈕開啟設定畫面。按鈕下方會顯示目前的設定（例：固定：橫向 53 個馬賽克格、依大小範圍：橫向 42～96 個馬賽克格、依分割數等比 ÷16）。馬賽克格的大小以畫面寬度上排列的格數來代表（數量越多越細），即使影片的解析度不同，看起來也一樣。只有類型為「馬賽克」時才會顯示，在「依 ID」「依場景」「依時間」分頁中，選擇對象後即可按下。按下「套用」會反映到開啟中的分頁（全部 / 依類別 / 依 ID / 依場景 / 依時間），按下「取消」則不會有任何變更。新偵測的影片的初始值由偵測選項決定（預設為固定）
設定畫面說明
左側是預覽與圖表。預覽中的橢圓框可拖曳移動，並以右下的控點變更大小，框內會以實際的馬賽克格套用馬賽克。預覽圖片可從人物、測試圖樣中選擇，也能換成自己的圖片。圖表呈現對象大小（橫軸，相對於畫面寬度的比例）與格數（縱軸，越上面越細）的關係，可拖曳線或控點來變更。右上的結果會顯示目前的框對應的格數（例：橫向 53 個馬賽克格），以及決定因素（範圍、分割數、下限、上限等）。由於自主規範的最小馬賽克（長邊 400px 以上為長邊÷100，最小 4px）一律優先，無法選擇比它更細的格數
固定
「自動像素大小」關閉時的設定。讓所有影格、所有對象都使用相同大小的馬賽克格。以「橫向的馬賽克格數」指定（預設為寬度 53 格。越少越粗，越多越細）
依大小範圍
開啟「自動像素大小」後選擇。依對象大小（每個鏡頭 × ID 的框的代表大小，以相對於畫面寬度的比例呈現）的範圍，分別決定寬度上排列的格數。範圍為 1～6 個，可新增、刪除或恢復為預設。在同一鏡頭、同一 ID 內，馬賽克格保持一致，不會在影格之間閃爍
依分割數等比
開啟「自動像素大小」後選擇。以對象大小除以「細緻度（目標物的分割數）」（8～64，預設 16）的值作為馬賽克格的邊長。畫面中越大的對象，馬賽克格也越大；值越大則越細。可用「最粗的馬賽克格」（寬度 N 格以上）限制最粗的程度（也可選擇無限制）。在同一鏡頭、同一 ID 內，馬賽克格保持一致
先前的專案
先前的設定會在開啟時轉換為新的設定。自動（以對象為基準）與固定（以解析度為基準）的外觀不會改變。手動（分割數）會轉換為「依分割數等比」，由於改以對象大小而非框的寬度為基準來分割，即使分割數相同，馬賽克格的大小也可能改變（縱向較長的對象會變粗，橫向較長的對象會變細）。轉換時，設定畫面會顯示「已轉換先前的手動設定（分割數 N）」
銳利色彩
馬賽克格的顏色不取區域平均，而改用單點取樣（相當於 Premiere Pro 的 Sharp Colors，預設關閉）
反轉（套用於外側）
只有在「依 ID」分頁中選擇偵測到的對象或新增的框時才會顯示（排除遮罩，以及「全部」「依類別」「依場景」「依時間」分頁中沒有此項目。預設關閉）。開啟後，該框的內側會保留原本的影像，並在框的外側（背景）套用馬賽克 / 模糊（使用該框的類型、馬賽克格與模糊設定）。同時作用於馬賽克套用預覽（M）與匯出。同一畫面中有多個反轉的框時，會保留位於任一框內側的部分。此設定不包含在「將此設定設為預設」中，新增框時的設定自動沿用也不會沿用（以橡皮擦分割出的區塊，會連同原本框的設定一起沿用）。與框的右鍵選單中的「反轉（外側套用馬賽克）」「反轉（外側套用模糊）」是相同的設定（偵測框的操作）。有反轉框的專案無法傳送到 Premiere Pro（Premiere Pro 整合）

各項目可用右端的 {% include icon.html name="RotateCcw" class="inline h-3.5 w-3.5 align-[-2px]" %} 按鈕恢復為預設值。按下「全部」分頁中的「將此設定設為預設」，其內容就會成為下次偵測的影片的初始設定（此影片的設定不會改變）。

依時間

在「依時間」分頁中，可依影片的時間範圍變更馬賽克的外觀。

  1. 將播放磁頭對齊範圍的開頭，按下「新增範圍」。會從播放磁頭的位置建立 5 秒的範圍並選取（內容與「全部」的設定相同）
  2. 調整「開始」「結束」。在欄位中以「分：秒：影格」的格式（例 1:05:12）輸入，或移動播放磁頭後按「使用目前位置」
  3. 與其他分頁相同，變更類型、大小、不透明度等
範圍的選擇與刪除
在「目標範圍」中選擇範圍。按「刪除此範圍」即可刪除。開始晚於結束時，會顯示「開始必須早於結束」
時間軸上的帶狀標示
依時間的範圍會以帶狀標示顯示在時間軸的場景帶下方。按一下帶狀標示，會在選取該範圍的狀態下開啟「依時間」分頁。沒有作用的範圍（之後變更了「全部」時等。下方的「設定的優先」）的帶狀標示會淡化顯示
與片段編輯的關係
範圍是依原始影片的時間記錄，因此即使分割、修剪或移動片段，也會套用到原始影片的同一場面（同一場面使用了 2 次的片段，會套用到 2 處）。無法對只有匯入的素材或空白的範圍設定（「此範圍不含原始影片的區間（僅含素材或空白的範圍無法設定）」）
套用的框
對範圍內偵測到的框與手動新增的框都有效（開啟「反轉（套用於外側）」的 ID 除外）

設定的優先

同一個框在同一影格中重疊套用「全部」「依類別」「依 ID」「依場景」「依時間」的設定時，以最後設定的為優先，並直接使用該設定的所有項目（不會依項目混合）。

  • 算作「設定」的，是在面板中實際變更了值時（包含以 {% include icon.html name="RotateCcw" class="inline h-3.5 w-3.5 align-[-2px]" %} 恢復為預設值），以及新增或變更依時間的範圍時。重新選擇相同的值，順序不會改變
  • 之後變更「全部」時，在那之前設定的依類別、依 ID、依場景、依時間的設定就不再有作用，所有項目都會成為「全部」的值。即使把值改回原本的值，順序也不會恢復
  • 在分頁中開啟沒有作用的設定時，會顯示「由於之後變更了「全部」，此設定目前沒有作用」之類的內容。按下「優先使用此設定」，即可在不變更值的情況下，讓該設定成為最後設定的設定，重新生效
  • 變更設定後使其他設定失去作用時，會出現「此變更使其他 2 項設定不再有作用」之類的通知。按下通知中的「復原」，即可回到該變更之前的值與順序（只限最近 1 次。中間做了其他編輯時，會顯示「無法復原（之後已有其他編輯）」）
  • 新增、貼上框或連接框時自動附加的依 ID 的設定（沿用馬賽克設定），不算作「設定」。剛建立後的外觀與之前相同，之後設定的設定會優先
  • 開啟「反轉（套用於外側）」的 ID，無論順序都會使用該 ID 的設定。既有馬賽克框的依 ID 設定（包含偵測時加入的馬賽克格設定），也無論順序都會使用。排除馬賽克、排除遮罩與信賴度閾值，也無論順序都會有作用
  • 在 2.18 之前建立的專案，開啟時的外觀與之前相同（沒有記錄順序的設定，會照以往以依 ID、依類別、依場景、全部的順序優先）
  • 以早於 2.18 的 Deepmosaic 開啟專案時，依時間的設定與順序會被忽略，並以以往的順序優先（在該版本中儲存後，依時間的設定與順序會遺失）
  • 依時間的設定不會傳遞到 Premiere Pro 整合

片段會在緊接其後的位置、文字會在長條的緊後方、音訊軌道會在相同位置建立副本
複製 / 貼上（Ctrl+C / Ctrl+V）
貼上複製的元素。文字與音訊軌道會放在播放指標的位置，片段會插入選取的片段（若未選取，則為播放指標所在的片段）的緊後方。剪貼簿中只會保留上一次複製的 1 個元素，且與電腦的剪貼簿分開（只能在編輯頁面中使用）
刪除（Delete）
刪除選取的元素。最後操作的是播放器時，Delete 會刪除偵測框（快捷鍵）

復原與記錄

時間軸的編輯（片段、文字、音訊、浮水印、淡化、轉場、新增素材）會記錄在與偵測框編輯分開的記錄中。可用時間軸縮放按鈕右側的「復原」（Ctrl+Shift+Z）/「重做」（Ctrl+Shift+Y）逐步操作，或從 {% include icon.html name="History" class="inline h-3.5 w-3.5 align-[-2px]" %} 記錄按鈕的清單中選擇，一次復原到該操作為止。清單中會由新到舊列出「分割」「修剪」「移動」「新增文字」等操作名稱與時間，最多保留 100 筆。重新開啟影片時，記錄會清空。

時間軸的高度與摺疊

變更高度
拖曳時間軸的上緣，即可在 220～720px 的範圍內變更高度（播放器始終保留 200px 以上）。選取上緣後按 ↑ / ↓ 鍵，也能以 16px 為單位調整，按兩下即可恢復為預設的 400px
摺疊（Ctrl+Shift+T）
按工具列右端的 {% include icon.html name="ChevronDown" class="inline h-3.5 w-3.5 align-[-2px]" %} 按鈕，可將時間軸摺疊成只剩 1 列工具列，讓播放器使用更大的空間。再按一次即可展開

高度與摺疊狀態，下次開啟編輯頁面時也會沿用。

{% include docs-h2.html kicker="時間軸編輯" title="媒體（匯入素材）" %}

在側邊欄的「媒體」（A）開啟的媒體面板中，匯入要在時間軸上使用的影片、音訊、圖片素材。匯入的素材會複製到專案資料夾中，因此即使移動原始檔案也能繼續使用（也會包含在專案匯出的 zip 中）。

匯入
按「匯入媒體」選擇類型（影片 / 音訊 / 圖片）再選擇檔案，或從檔案總管將檔案拖放到編輯頁面
支援的格式與上限
影片：與載入影片相同的格式（每個檔案最多 2GB）/ 音訊：MP3、WAV、AAC、M4A、FLAC、OGG、Opus（最多 200MB）/ 圖片：PNG、JPEG、WebP、BMP（最多 50MB）
新增到時間軸
按素材列上的「新增到時間軸」，影片會作為片段放在結尾，音訊會作為音訊軌道放在播放指標的位置。也可以將素材拖曳到通道上，放在任意位置（影片與圖片放在片段通道，音訊放在音訊通道）
圖片
按「新增到時間軸」會放置為 5 秒的圖片片段，拖曳長條的邊緣即可伸縮為任意長度。選擇「設定為浮水印」，即可作為疊加在整部影片上的標誌使用（浮水印）
影片的音訊
匯入的影片作為片段放置的區段，匯出時不會包含該影片的音訊，而是成為無聲（音訊軌道的背景音樂等仍會播放）。若要使用匯入影片的音訊，請將同一個素材也拖放到音訊通道
刪除素材
按該列的刪除按鈕，即可從專案中刪除素材。檔案本身也會被刪除，因此無法復原（時間軸的復原也無法還原）。時間軸中正在使用的素材無法刪除

匯入的素材不在 AI 偵測的範圍內。素材的區段不會加上馬賽克，也無法新增偵測框或使用橡皮擦。需要馬賽克的影像，請先作為影片載入，完成偵測與匯出後再匯入。

{% include docs-h2.html kicker="時間軸編輯" title="文字" %}

在側邊欄的「文字」中，將文字燒錄到影像上。文字可以新增任意數量，並可分別設定顯示的區段、位置與樣式。顯示的區段以匯出影像的影格編號指定。

新增
按「新增文字」，會在下方中央新增在整部影片中顯示的「文字」。從清單中選取後進行編輯
顯示的區段
輸入開始與結束的影格編號。按「設為目前位置」會填入播放指標的位置。勾選「顯示到最後」，就會顯示到影像的最後
位置
拖曳預覽上的文字，即可自由移動到任意位置。以數值指定時使用「位置 X / Y（%）」（從左上角起算的位置）。選擇「位置預設」（左上～右下的 9 個位置），會以距離邊緣 2% 的邊距靠齊
大小
以相對於影像高度的比例指定文字的高度（2～50%，預設 6%）
字型與粗體
字型有 5 種：黑體（預設）/ Yu Gothic / 明體 / MS Gothic / BIZ UDGothic。也可設為「粗體」。電腦中未安裝的字型會改用相同系列的字型燒錄，若也沒有則以黑體燒錄。沒有粗體的字型（MS Gothic 等）會以一般粗細顯示
顏色、外框、不透明度
文字的顏色（預設：白色）、外框的粗細（文字高度的 0～25%，預設 8%）與顏色（預設：黑色）、不透明度（預設 100%）

文字通道

在時間軸的片段通道上方，每個文字各佔 1 列，排列著代表顯示區段的長條（文字通道）。拖曳長條會連同顯示區段一起移動，拖曳兩端則可變更開始與結束。選取長條時，文字面板中也會選取相同的文字。按一下右鍵可建立副本、複製、貼上、刪除。

{% include docs-h2.html kicker="時間軸編輯" title="浮水印" %}

在側邊欄的「浮水印」中，將標誌等 1 張圖片疊加在匯出影像的整部影片上。請先在媒體面板匯入圖片（也可從媒體面板中圖片的「設定為浮水印」設定）。

圖片
從匯入的圖片中選擇。選擇「無」即可移除浮水印
位置
從左上～右下的 9 個位置中選擇（預設：右下）
大小
以相對於影像寬度的比例指定圖片的寬度（1～100%，預設 15%）。會保持長寬比
不透明度
0～100%（預設 80%）
水平邊距 / 垂直邊距
以相對於影像寬度、高度的比例，指定與影像邊緣的距離（0～50%，預設 2%）

若要加入文字的浮水印，請使用在整部影片中顯示的文字。

{% include docs-h2.html kicker="時間軸編輯" title="音訊與背景音樂" %}

在側邊欄的「音訊」中，調整原始影片的音訊，以及背景音樂等音訊軌道。匯出時，原始影片的音訊與所有音訊軌道會疊加（混音）後輸出。

偵測影片的音訊
原始影片的音量（-40～+12dB）與靜音
新增音訊軌道
在媒體面板的音訊素材上按「新增到時間軸」（會放在播放指標的位置），或將音訊素材拖曳到音訊通道。將影片素材放到音訊通道時，可只使用該影片的音訊
音量 / 靜音
每個軌道 -40～+12dB。靜音可暫時只讓該軌道不發出聲音
淡入 / 淡出
每個軌道可在 0～20 秒內讓聲音的開頭與結尾淡化

音訊通道與波形

在時間軸的片段通道下方，每個音訊軌道各佔 1 列排列著長條（音訊通道）。長條上會繪製背景音樂的波形，可一邊查看樂曲的高潮與無聲的位置一邊對齊。拖曳長條可移動位置，拖曳兩端可縮短使用的範圍（樂曲的開頭與結尾）。背景音樂會跨越片段之間的空白持續播放。長度不明的音訊，會以「長度不明」取代長條顯示。

{% include docs-h2.html kicker="時間軸編輯" title="淡化" %}

讓匯出的影像從黑色淡入、淡出至黑色。淡化分為套用在整個影像開頭與結尾的「整體淡化」，以及套用在每個片段開頭與結尾的「片段淡化」。整體淡化在側邊欄的「淡化」中輸入秒數。片段淡化則在從接點的剪刀選擇「淡化」後開啟的「選取的接點」區塊，或選取片段時出現的「選取的片段」區塊中輸入。秒數只在側邊欄中輸入（不在時間軸上輸入秒數）。

從剪刀選擇
按下片段接點的 {% include icon.html name="Scissors" class="inline h-3.5 w-3.5 align-[-2px]" %} 徽章（剪刀）後（也可選取後按 Enter / Space），會開啟「淡化」「轉場」2 個項目的選單。按 ↑ / ↓ 移動項目，按 Esc 或按一下選單外側即可關閉。選擇「淡化」後，側邊欄的「淡化」會開啟並聚焦在該接點（「轉場」請見轉場）
整體淡化
在側邊欄的「淡化」中，輸入整個影像的淡入與淡出秒數。輸入後，尺規的兩端會出現該長度的斜坡（三角形的標記）
片段淡化
在「選取的接點」區塊中，輸入接點前一個片段的淡出與後一個片段的淡入。影像第一個片段的開頭或最後一個片段的結尾，請選取片段後在「選取的片段」區塊中輸入。輸入後，長條的下緣會出現斜坡。淡化的只有該片段的影像（原始影片的片段也包括音訊），浮水印與文字不會變暗
調整秒數
以秒指定（0～20 秒，0 秒為不淡化），秒數旁會顯示實際淡化的影格數。按一下斜坡（也可選取後按 Enter）也會開啟側邊欄的「淡化」；從片段的斜坡開啟時，會選取該片段。按「清除」會將選取的淡化兩側都移除
無法放置的位置
有轉場的接點那一側的邊緣無法加入片段淡化，側邊欄的輸入欄位會無法操作，並顯示原因。移除轉場後即可設定
移至開頭 / 移至結尾
以側邊欄「淡化」中的按鈕，將播放指標移至影像的開頭 / 結尾。整體淡化只套用在兩端，因此可在預覽中確認效果時使用

淡化會與匯出時一樣反映在預覽中。整體淡化與片段淡化重疊的影格，會同時套用兩者。每個音訊軌道的淡化請在音訊與背景音樂中設定，片段接點的切換請在轉場中設定。

{% include docs-h2.html kicker="時間軸編輯" title="轉場" %}

在相鄰片段的接點上加上切換效果（轉場）。按下接點的剪刀並選擇「轉場」，側邊欄的「轉場」（抽屜面板的標題也是「轉場」）會開啟並聚焦在該接點，接著選擇類型與長度。類型與長度只在側邊欄中輸入（不在時間軸上輸入）。只有 1 個片段時沒有接點，因此無法放置。有轉場的接點那一側的邊緣，無法放置片段的淡化。

類型
淡化 / 溶解 / 擦除（向左、向右）/ 滑動（向左、向右）/ 淡化至黑 / 淡化至白，共 8 種
放置方式
按下時間軸接點的 {% include icon.html name="Scissors" class="inline h-3.5 w-3.5 align-[-2px]" %} 徽章（剪刀），從選單中選擇「轉場」。側邊欄的接點清單（「前一個片段 → 下一個片段」）中會選取該接點的列，接著選擇類型（選擇「無」即可移除），並以 0.1～5 秒指定長度。放置後，接點上會出現與前後片段重疊長度相同的斜線長條。由於前後片段會重疊該長度，整個影像會相應縮短
長條與徽章
按一下斜線長條（也可選取後按 Enter），不經過選單即可開啟側邊欄的「轉場」。將滑鼠移到徽章上，會顯示目前的類型與秒數
有空白的接點
夾著空白（黑畫面）的接點無法放置。側邊欄中該接點的列會顯示原因（不會自動消除空白）。設定後若在中間產生空白，轉場會失效；消除空白後即會恢復
片段淡化
已加入片段淡化的接點，該列會顯示「放置轉場後，此接點的淡化會在匯出時被忽略。」的附註。淡化不會自動刪除
預覽
在重疊期間，會以與匯出相同類型的切換合成前後片段並顯示。後一個片段那一側在預覽中不會顯示馬賽克（匯出時會套用）
