Deepmosaic 是一款 Windows 桌面應用程式，透過 AI（深度學習）物體偵測，自動完成為影片加上馬賽克的作業。從載入影片、AI 偵測、編輯偵測結果，到匯出已燒錄馬賽克的影片，全都能在應用程式內完成。本軟體是用來「加上」馬賽克的工具，不具備從已套用馬賽克的影像中去掉馬賽克，或還原原始影像的功能。

本頁是 Windows 版（Deepmosaic Desktop）的使用指南。關於免安裝、可直接在瀏覽器中使用的網頁版，請參閱網頁版使用說明（與桌面版的差異也整理在本頁末尾）。

以影片了解基本使用方式

作業流程

  1. 載入影片 — 檔案 / 資料夾 / 拖放。載入的影片會以「專案」的形式排列在首頁畫面上
  2. 以 AI 偵測 — 決定偵測範圍與對象（身體部位 / 男性臉部 / 女性臉部 / 既有馬賽克）後開始。處理會在背景進行，並可透過佇列依序處理多部影片
  3. 在編輯頁面確認與修正 — 新增或刪除偵測框、調整馬賽克的外觀、確認漏偵測
  4. 匯出 — 匯出已燒錄馬賽克的影片。也可以將偵測結果傳給 Premiere Pro

安裝程式版停止提供與移轉至 Microsoft Store 版

從官方網站下載的安裝程式版（應用程式畫面中顯示為「exe 版」）於 2026 年 12 月 31 日之後將無法再使用。在此之前仍可繼續使用。請儘早移轉至 Microsoft Store 版。費用、使用條款與功能皆不變。

  • 會沿用的項目：專案資料夾、設定與登入資訊、AI 模型等會由 Microsoft Store 版直接沿用。方案與帳號綁定，因此可繼續使用
  • 安裝程式版 2.18 以後，啟動時會顯示移轉公告（按「稍後」關閉後，在下次啟動前不會再顯示）。於 2027 年 1 月 1 日以後啟動時，會顯示停止提供的畫面，無法操作
  • 在 2026 年 12 月 31 日之前，安裝程式版仍會收到應用程式內的更新
  1. 安裝 Microsoft Store 版（使用上方按鈕，或應用程式公告中的「從 Microsoft Store 下載」）
  2. 先結束安裝程式版，再啟動 Microsoft Store 版，確認設定與專案已沿用
  3. 確認可正常運作後，解除安裝安裝程式版（解除安裝）。2.18 以後的安裝程式版，在已安裝 Microsoft Store 版的電腦上，不會刪除與 Microsoft Store 版共用的設定、登入資訊與 AI 模型等（確認畫面也不會顯示刪除資料的核取方塊）

解除安裝 2.18 之前的安裝程式版時，請不要勾選確認畫面中的「アプリのデータとプロジェクトフォルダを削除する」（此項目以日文顯示，意為：刪除應用程式資料與專案資料夾）（與 Microsoft Store 版共用的設定、偵測結果與專案資料夾也會被刪除）。AI 模型等會被刪除，Microsoft Store 版會在下次啟動時重新取得。若先以應用程式內的更新升級至 2.18 以後，這些資料就不會被刪除。

同意使用者授權合約

第一次啟動時，在初始設定之前會顯示「開始使用之前」對話方塊。確認使用者授權合約與服務條款（可從對話方塊中的連結查看全文）後，勾選「我同意使用者授權合約及服務條款」並按下「同意並繼續」，就會開始設定。選擇「不同意（結束）」時，應用程式會結束。使用者授權合約或服務條款修訂時，啟動時會顯示「使用者授權合約與服務條款已更新」，請重新同意。

下載資料

偵測引擎與輕量的偵測模型已包含在應用程式中。第一次啟動時，會自動下載 AI 偵測所需的模型資料（{{ spec_storage.val }}）。下載期間會顯示整體進度（%）與剩餘時間，完成前無法進行其他操作。依網路速度而定，可能需要數分鐘到十幾分鐘。

高精度模型等部分資料，會在進入首頁畫面後於背景取得。取得完成前的偵測會使用輕量模型，偵測選項畫面會顯示「正在準備高精度模型（剩餘約 N MB） — 這次將以輕量模型進行偵測。」

下載完成後，會自動執行偵測與匯出的運作測試（「運作測試中…」）。若發現問題，只會自動重新下載相關的資料。完成後會自動切換到首頁畫面，並顯示「安裝完成」（不需要按「繼續」）。

設定期間無法進行的操作

在下載與運作測試完成前，選單中除了「檔案 ▸ 結束」與「說明」（「教學影片」除外）以外都會停用，關閉視窗與重新載入畫面的操作也會被阻止。若中途結束，下次啟動時只會取得不足的部分並繼續。

出現錯誤時

完整性檢查失敗
取得的檔案已損毀。按「重新下載」只會重新取得相關的檔案（會自動重試，最多 2 次）
缺少相依執行階段元件
找不到偵測引擎運作所需的 Windows 元件。請從「開啟支援表單」附上環境資訊（作業系統版本等）與我們聯絡
自我測試失敗
下載雖已完成，但偵測引擎的運作測試失敗。請從「開啟支援表單」附上顯示的訊息與環境資訊（作業系統版本等）與我們聯絡
下載沒有進展
確認網路連線後按「重試」，或重新啟動應用程式。已取得的檔案會直接沿用，只會重新取得不足的部分

準備 GPU 加速（僅限搭載 NVIDIA GPU 的電腦）

在搭載 NVIDIA GPU 的電腦上，第一次會自動取得加速用的元件（NVIDIA 提供。下載約 1.7 GB，解壓縮後約 2.4 GB）。沒有 NVIDIA GPU 的電腦不會取得。取得完成前會以 CPU 運作（功能不變，但處理會變慢）。取得期間，畫面右下的「GPU 加速」會顯示進度，取得完成後，之後的偵測會以 GPU 執行。

取得失敗時，右下的顯示會出現「取得失敗。請按「重試」，或於下次啟動時再次取得」。請確認網路連線後按「重試」，或重新啟動應用程式（下次啟動時會自動重新取得）。關於其作為第三方軟體的處理方式，請參閱隨附的第三方軟體與授權。
