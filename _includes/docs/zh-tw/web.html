{% include docs-h2.html kicker="網頁版" title="簡介" %}

網頁版是不需安裝、直接在瀏覽器中使用的 Deepmosaic。從載入影片、AI 偵測、編輯偵測結果，到匯出已燒錄馬賽克的影片，全部在本機電腦的瀏覽器中處理。影像、音訊、影格圖片與偵測結果都不會傳送至伺服器。只有登入與方案確認、取得 AI 模型、記錄使用狀況（畫面切換與操作的記錄，以及處理時間、影片格式與長度等數值），以及回報錯誤時才會進行通訊（{% include ja-link.html href="/company/privacy" label="隱私權政策" %}）。

網頁版僅供試用。每部影片最長可處理 {{ site.data.site.web_app.trial_minutes }} 分鐘。更長的影片、大量的影片，以及超過 1.9GB 的影片，請使用桌面版（影片長度）。付費方案與組織（Enterprise）的帳號沒有此長度限制。

帳號、方案與免費額度的時數都與桌面版共用。偵測對象（身體部位 / 男性臉部 / 女性臉部）與編輯頁面的功能也相同，操作的詳細說明請參閱桌面版使用說明。本頁整理網頁版特有的需求與差異。

{% if site.data.site.web_app.enabled %}

網頁版可從 app.deepmosaic.co.jp 開啟。

{% endif %}
{% include docs-h2.html kicker="網頁版" title="支援的瀏覽器與需求" %}

啟動時會檢查瀏覽器的功能，若有不足的功能會顯示說明。缺少必要的功能時無法使用。缺少建議的功能時，可以「低速模式」繼續使用。

瀏覽器（必要）
支援 WebCodecs 的瀏覽器：Google Chrome / Microsoft Edge 119 以上版本、Safari 17 以上版本。建議使用最新版的 Chrome 或 Edge。Firefox 不在運作驗證的範圍內，長影片的偵測可能會中途失敗
瀏覽器內儲存空間（必要）
影片的副本與模型會儲存在瀏覽器內（OPFS）。無法在私密（無痕）視窗中使用（各瀏覽器的名稱不同）
HTTPS（必要）
請從以 https:// 開頭的網址開啟（通常會自動符合）
WebGPU（建議）
以 GPU 執行 AI 偵測。自 2.6.5 起，在支援 WebGPU 的環境中，偵測速度約為以往的 2.5 倍，馬賽克精修所需的時間也縮短約 2 成。沒有 WebGPU 時會以 CPU（WebAssembly）運作，但需要數倍至十數倍的時間。Chrome / Edge 通常已啟用
影片大小
每部影片最大約 1.9GB。超過時會顯示「此影片（N GB）超過瀏覽器版可處理的上限（約 1.9 GB）。請使用桌面版。」（N 為影片的大小）
影片長度
免費方案每部影片最長 {{ site.data.site.web_app.trial_minutes }} 分鐘（以影片的總長度判斷）。超過的影片會在開始偵測前顯示桌面版的相關提示，且不會進行處理。付費方案與組織（Enterprise）的帳號沒有限制
影片格式
mp4 / mov / m4v（瀏覽器可播放的編解碼器，通常為 H.264）。MKV / WebM / AVI / WMV / FLV / TS / MPEG 會顯示含有格式名稱的訊息，例如「瀏覽器版不支援此格式（MKV）。請轉換為 mp4（H.264），或使用桌面版。」
記憶體
長片與高解析度的影片會使用大量記憶體。建議先關閉其他分頁與占用大量資源的應用程式再執行
{% include docs-h2.html kicker="網頁版" title="開始使用" %}
  1. 登入。網頁版必須登入。從網站首頁的「在瀏覽器中試用」開啟後，會顯示登入畫面。按下「登入」，輸入寄到電子郵件的 6 位數驗證碼（不需要密碼。第一次使用時會自動建立免費帳號）。以往使用密碼登入的使用者，只要以同一個電子郵件地址輸入驗證碼，也能以原本的帳號登入。自 2.13 起，登入畫面的入口與桌面版相同，分為「登入」與「持有組織代碼者（企業）」2 個（登入與授權）
  2. 第一次使用時會取得模型。AI 模型會下載到瀏覽器內（會顯示進度）。第 2 次起會直接使用瀏覽器內的模型
  3. 載入影片。將影片拖放到畫面上，或從選單的「檔案」選取。影片會複製到瀏覽器內，並以專案的形式列在首頁畫面。第一次載入影片時，會出現確認是否同意使用者授權合約與服務條款的畫面（不同意則會中止載入）。同意狀態會依瀏覽器分別記錄，因此在其他瀏覽器中會再次確認
  4. 設定偵測選項並開始。偵測範圍、偵測對象、像素大小設定與批次執行都與桌面版相同（偵測選項）。偵測會在浮動視窗中進行，期間也可以進行其他操作
  5. 編輯並匯出。編輯頁面的功能與快捷鍵都與桌面版相同（編輯頁面）。匯出請參閱匯出與下載

第一次使用人物圖庫時，會出現確認是否追加下載臉部辨識用模型（約 249MB）的畫面。畫面會顯示依連線速度估算的預估所需時間，中途停止也能從中斷處繼續下載。

{% include docs-h2.html kicker="網頁版" title="與桌面版的差異" %}
偵測
幾乎相同（3 種偵測對象與「馬賽克」（素材中既有的馬賽克）、偵測範圍、像素大小設定（固定 / 依大小範圍 / 依分割數等比）、批次執行、場景的自動判定）。網頁版可將「馬賽克」與身體部位、臉部同時使用（桌面版兩者互斥，開啟「馬賽克」時只會偵測馬賽克的框。既有馬賽克）。自 2.6.1 起，網頁版也可使用馬賽克精修（限支援 WebGPU shader-f16 的 GPU 與瀏覽器。會另外取得約 175 MB 的精修用模型作為相關檔案）。不支援的環境會以方形框加上馬賽克。處理速度約為桌面版的一半以下。偵測框軌跡的自動修正（AI 偵測）僅限桌面版，網頁版的偵測不含此功能。也可以使用「不偵測直接匯入」（不偵測，直接將影片匯入編輯畫面。不會消耗偵測時間。免費方案每部影片最長 {{ site.data.site.web_app.trial_minutes }} 分鐘的限制，與偵測相同也會套用）
編輯頁面
相同（框的編輯與繪製、1f / ∞ 的新增與排除遮罩、E+右鍵拖曳的橡皮擦擦除方式、形狀與大小、形狀沿用（Shift+→ / Shift+滾輪向上、Shift ×2 固定）、∞ 連續 BBox 的關鍵影格（F）、放置點並以追蹤連接（Y / Shift+Y）與追蹤佇列、框的複製與貼上（Ctrl+C / Ctrl+V）、標籤的顯示與篩選、選取的框的羽化範圍虛線、以 Shift+左鍵拖曳範圍選取多邊形的頂點並彎曲、右鍵選單的「反轉（套用於外側）」、將既有的框改為排除遮罩（右鍵選單的「設為排除遮罩」與依類別分頁的一次變更）、ID 的合併（框的右鍵選單中的「合併 ID…」與時間軸 ID 列的右鍵選單、連續 BBox 的合併、取消合併）、預覽的邊距與框外的馬賽克、馬賽克設定的 5 個分頁（包含「依時間」）與各分頁的「套用馬賽克」開關、依類別的目標類別（身體部位 / 男性臉部 / 女性臉部 / 手動新增的遮罩）、設定的優先（以最後設定的為優先）與沿用、模糊強度、場景、人物圖庫、縮放、快捷鍵、側邊欄的「設定」（最上方的「位置」、拖曳移動、按一下外側即可關閉、偵測疊加層與標籤的顯示及滾輪方向的設定）、時間軸編輯）。人物圖庫的「重新歸類人物」僅限桌面版。也可以使用追蹤（X），但網頁版的追蹤只有「標準追蹤」（使用 GPU 的「高精度追蹤」僅限桌面版）。網頁版的追蹤佇列只進行追蹤，不進行輪廓精修（桌面版在有 GPU 的電腦上，追蹤之後也會進行輪廓精修）。時間軸編輯的差異請參閱時間軸編輯
首頁畫面的分類
相同（資料夾與標籤、「其他資料夾」列）。分類會儲存在瀏覽器內（首頁畫面的分類）
匯出格式
MP4 (H.264) / WebM (VP9) / WebM (AV1) 3 種。H.265、ProRes、DV、DNxHR、CineForm、MKV、AVI 僅限桌面版。選擇瀏覽器不支援的格式時，會切換為 MP4 (H.264)
解析度 / 影格速率 / 位元速率
解析度同樣有 7 種。影格速率只有「與原始影片相同」（無法轉換）。位元速率的「自動」會依解析度決定
時間碼
相同（嵌入，以及文字大小、位置、顏色、顯示格式的設定）。將時間碼記錄到檔案中僅限桌面版
GPU 編碼
瀏覽器支援時，可選擇「GPU 編碼」（沒有 NVIDIA 驅動程式的條件）
儲存位置
在瀏覽器的儲存對話方塊中指定，或先儲存在瀏覽器內再下載（匯出與下載）
Premiere Pro 整合
無（僅限桌面版）
專案的匯出與匯入
網頁版目前還無法使用 zip 的匯出與匯入（準備中）。可改用「下載偵測資料」儲存偵測結果與編輯資料（匯出與下載）
繼續已中斷的偵測
無（僅限桌面版）。在網頁版中，中途停止的偵測會從頭重新執行。首頁畫面的「已中斷的偵測」與「未使用的專案資料夾」的提示也僅限桌面版
組織管理（Enterprise）
相同（邀請與權限、帳號數、請款單、用量）。加入的步驟請參閱組織管理
更新
沒有自動更新的通知。重新載入頁面後，一律會是最新版
同時執行
每個帳號最多偵測 1 項、匯出 1 項（偵測與匯出可同時進行）。與桌面版中正在執行的工作也會互斥
離線
確認登入需要網路通訊，因此離線時會顯示「無法連線到伺服器」，無法使用。桌面版在完成初始設定後，離線時也能偵測、編輯與匯出
影片長度
網頁版僅供試用，因此免費方案只能處理每部最長 {{ site.data.site.web_app.trial_minutes }} 分鐘的影片（付費方案與組織的帳號沒有限制）。桌面版的單部影片長度沒有限制（免費額度的時數為共用）。長影片或大量的影片請使用桌面版
多個視窗
無（僅限桌面版。桌面版可在編輯頁面以「多視窗」在多個視窗中開啟同一專案。編輯頁面）
{% include docs-h2.html kicker="網頁版" title="首頁畫面的分類" %}

可在首頁畫面的左側邊欄，以資料夾與標籤分類專案。操作與桌面版相同（載入影片）。

  • 資料夾：以清單上方的「新增資料夾」建立資料夾，也可從資料夾的選單建立子資料夾。可從影片卡片選單（按右鍵也能開啟）的「移至資料夾」移動，或將卡片拖曳到側邊欄的資料夾。拖放到「所有影片」即可取消分類
  • 標籤：在影片卡片選單的標籤欄加上或移除標籤。在側邊欄的「依標籤篩選」選取標籤後，只會列出該標籤的影片
  • 「其他資料夾」：位於目前專案資料夾以外的專案，會集中在側邊欄的「其他資料夾」列（0 個時不顯示）。這些專案無法使用資料夾與標籤，若要分類，請選擇影片卡片選單中的「切換到此專案資料夾」
分類的儲存位置
資料夾與標籤會儲存在瀏覽器內的專案資料夾。不會與桌面版共用（也不會與其他瀏覽器 / 電腦共用）
多個分頁
在同一個瀏覽器的多個分頁中同時變更分類時，會保留最後儲存的分頁的內容。請只在 1 個分頁中變更分類
影片卡片的選單
沒有「開啟專案資料夾」「Premiere Pro」「複製專案」。網頁版改為提供「下載偵測資料」（匯出與下載）
{% include docs-h2.html kicker="網頁版" title="時間軸編輯" %}

編輯頁面的時間軸編輯，可用與桌面版相同的方式操作。從左側的側邊欄（媒體 / 文字 / 浮水印 / 音訊 / 淡化 / 轉場）新增素材與效果，可編輯片段的修剪、分割、重新排序與刪除，以及片段之間的空白、文字與音訊（背景音樂）。編輯的內容會直接反映在匯出中（編輯頁面）。

匯入素材
影片、音訊、圖片素材，可從媒體面板的「匯入媒體」選取，或將檔案拖放到編輯頁面來匯入。素材會儲存在瀏覽器內的專案中，預覽時會從瀏覽器內的暫時網址（Blob URL）讀取。剛開啟頁面時等情況下，在素材讀取完成前，預覽中的該區段可能會顯示為黑色
空白
放在片段之間的空白，會以黑畫面、無聲的形式匯出（與桌面版的結果相同）。背景音樂會跨越空白持續播放
文字、浮水印、淡化、轉場
相同。匯出時由瀏覽器燒錄到影像上。轉場越長，匯出時使用的記憶體越多
音訊
將原始影片的音訊與背景音樂等音訊軌道混音後匯出（MP4 為 AAC，WebM 為 Opus）。匯入的影片片段的音訊不會包含在匯出中（與桌面版相同）
圖片片段
相同。圖片素材可作為任意長度的片段放在時間軸上，匯出時也會維持該長度。透明 PNG 的透明部分，在網頁版的匯出中會變成黑色

馬賽克會套用在以 AI 偵測的原始影片區段。匯入的素材不列入偵測對象。

{% include docs-h2.html kicker="網頁版" title="執行視窗與佇列" %}

偵測與匯出的進度及佇列，會以疊在畫面上方的浮動視窗顯示。拖曳標題列即可移動；最小化後會以小方塊留在畫面右下角，按一下即可還原。顯示期間仍可照常操作首頁畫面與編輯頁面。

可在選單列的「佇列」確認與操作偵測與匯出的等候清單（重新排序、暫停、取消與桌面版的佇列相同）。同一個帳號在其他分頁或桌面版中有執行中的工作時，開始新工作時會顯示確認畫面，詢問是否要接手。

{% include docs-h2.html kicker="網頁版" title="匯出與下載" %}
以儲存對話方塊儲存
在 Chrome / Edge 中，開始匯出時會以瀏覽器的儲存對話方塊指定要儲存的檔案，並直接匯出到該檔案
儲存在瀏覽器內後下載
在不支援儲存對話方塊的瀏覽器中，會先匯出到瀏覽器內的專案。完成後，在匯出進度視窗（或佇列的列）中按下「下載」，儲存為檔案
下載偵測資料
將專案的偵測結果與編輯資料儲存為 JSON 檔案（留存、備份用）。不包含在時間軸編輯中匯入的素材檔案
{% include docs-h2.html kicker="網頁版" title="資料的儲存與自動刪除" %}

載入的影片副本、偵測結果、編輯資料、在時間軸編輯中匯入的素材、首頁畫面的分類（資料夾與標籤）、匯出到瀏覽器內的影片，以及 AI 模型，全部儲存在瀏覽器為此網站保留的儲存空間。不會儲存在伺服器上。

AI 模型
7 天未使用的模型會自動刪除（下次偵測時會重新取得）
專案
不會自動刪除。不再需要時，請從首頁畫面刪除。瀏覽器的容量不足時，載入會失敗
刪除瀏覽器資料
在瀏覽器設定中刪除網站資料後，專案與模型會全部消失。想保留的成果請先下載
其他瀏覽器 / 電腦
儲存空間在各個瀏覽器之間是獨立的。若要在其他環境繼續作業，請下載匯出的影片或偵測資料後移過去

第一次載入時，瀏覽器可能會要求「永久儲存空間」的權限。允許後，瀏覽器在容量不足時較不容易自動刪除資料。

帳號、方案與使用時間都與桌面版共用。免費帳號自首次使用桌面版或網頁版的當日起 {{ free_plan.free_window_days }} 天內，可偵測累計 {{ free_plan.included_hours }} 小時的影片（與桌面版共用的免費期間），頁尾會顯示剩餘時間。使用時間會在偵測完成時計入，匯出不會計入。付費方案的內含時數與價格請參閱價格頁面。

方案的申請、變更與取消訂閱，都從個人資料選單進行。付款畫面會在新分頁中開啟，完成手續並回到原本的分頁後，會自動反映。Enterprise 請從選擇方案畫面的「洽詢導入事宜」，在導入洽詢頁面（新分頁）中與我們洽詢。

{% include docs-h2.html kicker="網頁版" title="組織管理（Enterprise）" %}

已加入 Enterprise 組織的帳號，可從個人資料選單的「組織」，在與桌面版相同的畫面中處理成員的邀請與權限、確認組織代碼與查看用量（變更帳號數與取消訂閱，請透過導入洽詢與我們聯絡）。權限與導入流程請參閱桌面版使用說明中的組織管理（Enterprise）。

以組織代碼加入
按下登入畫面的「持有組織代碼者（企業）」，在「組織代碼」欄輸入代碼後，按下「登入」。完成驗證並回到此頁面後，就會加入組織。登入後無法從選單加入，若已登入，請先登出再重新輸入。1 個帳號只能加入 1 個組織，已屬於其他組織時無法加入
請款單的檢視 / PDF
「請款單」的「檢視」與「PDF」會在瀏覽器的新分頁中開啟。以銀行轉帳簽約的請款單會以電子郵件寄送（不會顯示在「請款單」中）
{% include docs-h2.html kicker="網頁版" title="疑難排解" %}
  • 出現「請從以 https:// 開頭的網址開啟。」時：請將網址列的網址改為 https://app.deepmosaic.co.jp/。
  • 顯示瀏覽器的功能不足時：請將 Chrome / Edge 更新為最新版。私密（無痕）視窗無法使用儲存空間，請在一般視窗中開啟。
  • 出現「無法連線到伺服器」時：請確認網路連線，並按下「重試」。
  • 偵測速度極慢時：WebGPU 可能已停用。請將瀏覽器更新為最新版，並更新顯示卡驅動程式。關閉其他分頁與占用大量資源的應用程式也有幫助。
  • 無法載入影片時：超過約 1.9GB 的影片請使用桌面版。mp4 / mov / m4v 以外的格式，請轉換為 mp4 (H.264)，或使用桌面版。
  • 沒有出現匯出的儲存對話方塊時：檔案會儲存在瀏覽器內。完成後，請在匯出進度視窗或佇列中按下「下載」。
  • 仍無法解決時：請從個人資料選單的「聯絡我們」，附上瀏覽器的種類與版本，與我們聯絡。
