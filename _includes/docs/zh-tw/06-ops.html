{% include docs-h2.html kicker="維護" title="更新" %}

Microsoft Store 版的新版本由 Microsoft Store 提供並自動更新。啟動時若有新的 AI 模型，會自動取得並替換。以下說明安裝程式版（至 2026 年 12 月 31 日為止，請參閱移轉）。

安裝程式版的應用程式會在啟動時自動檢查是否有新版本。有可用的更新時會顯示對話方塊，可選擇「立即更新」或「稍後」。

自動檢查的時機
啟動後立即檢查，之後每 1 小時檢查一次，回到視窗時也會檢查。偵測或匯出執行期間，會等到完成後才顯示
立即更新
下載並套用新版本，應用程式會自動重新啟動。若有正在執行的處理，請在完成後再更新
稍後
在本次工作階段中不會再自動檢查。下次啟動時會再次檢查
偵測引擎
包含在應用程式中，會與應用程式一起更新
AI 模型
啟動時若有新的模型，會自動取得並替換（與初始設定相同的機制）

手動檢查

在選單中選取「檔案 ▸ 檢查更新」，會顯示應用程式 / 引擎 / 模型與資源這 3 項的「目前」「最新」「狀態」。顯示「有可用的更新」時，可按「立即更新」（應用程式）或「更新模型與資源」套用。按「重新檢查」會重新查詢。無法連線到網路時，會顯示「請確認網路連線後再試一次。」。

{% include docs-h2.html kicker="維護" title="資料儲存位置" %}

Deepmosaic 不會將影像或其偵測結果傳送到伺服器。所有資料都儲存在電腦上的下列位置。

專案資料夾
預設為 C:\Users\<使用者名稱>\deepmosaic。每部影片的子資料夾中，會存放整合了偵測結果與編輯資料的資料庫（project.db）、縮圖、臉部的代表圖片等。載入的影片本身不會被複製，而是從原始位置參照。在時間軸編輯中加入的素材（影片、音訊、圖片）會複製到子資料夾的 assets，也會包含在專案的匯出中（專案資料夾）
%USERPROFILE%\.deepmosaic
設定（config.json）、首頁的清單、資料夾與標籤的登記資料（catalog.db）、加密的登入資訊、裝置 ID、記錄檔（logs\app.log，每次偵測的記錄檔位於 logs\runs）。聯絡我們時，我們可能會請求附上記錄檔
%LOCALAPPDATA%\deepmosaic
AI 模型、GPU 用執行階段（僅限搭載 NVIDIA GPU 的電腦）等（合計約 10GB）。由初始設定與啟動時的檢查自動管理。偵測引擎與影片處理工具已包含在應用程式中
匯出的影片
匯出時指定的儲存位置。應用程式不會管理

若將專案資料夾放在雲端同步資料夾（OneDrive 等）中，編輯期間的自動儲存可能會與同步發生衝突，導致「儲存失敗」。建議使用本機資料夾。

project.db 與 catalog.db 是由應用程式管理的資料庫。應用程式執行期間，請勿以其他工具開啟，或改寫其中的內容（這會導致資料損毀）。請在結束應用程式後再進行備份或複製；若有名稱開頭與 project.db 相同的檔案（-wal / -shm），請一併複製。

{% include docs-h2.html kicker="維護" title="解除安裝" %}
  1. 開啟 Windows 的「設定」→「應用程式」→「已安裝的應用程式」
  2. 在清單中找到「Deepmosaic」，然後選取「解除安裝」（不需要系統管理員權限）

Microsoft Store 版也可以用相同的步驟解除安裝。確認畫面中沒有核取方塊，設定與登入資訊以及專案資料夾都會保留（Microsoft Store 版與安裝程式版的差異）。

解除安裝安裝程式版後，AI 模型等（%LOCALAPPDATA%\deepmosaic，約 10GB）會自動刪除（重新安裝時，會在初始設定中重新下載。在已安裝 Microsoft Store 版的電腦上，2.18 以後的安裝程式版不會刪除）。若在解除安裝的確認畫面中勾選「アプリのデータとプロジェクトフォルダを削除する (中の書き出し動画も削除されます)」（此項目以日文顯示，意為：刪除應用程式資料與專案資料夾，其中的匯出影片也會一併刪除）核取方塊，設定與登入資訊（%USERPROFILE%\.deepmosaic），以及 Deepmosaic 建立的專案資料夾（偵測結果、編輯資料，也包含儲存在資料夾中的匯出影片）也會一併刪除。若未勾選，這些資料會保留。位於專案資料夾以外的原始影片與匯出的影片不會被刪除。更新時不會刪除任何資料。

若要刪除帳號本身，請參閱刪除帳號。

  • 計算單位：累計已完成偵測的影片播放長度。頁尾會顯示剩餘時間（免費方案為「剩餘可偵測時間」，付費方案為「本月剩餘」）
  • 計算時機：於偵測完成時計入。匯出不列入計算。即使縮小偵測範圍，也會以整部影片的長度計算
  • 上限的適用方式：不會產生超額費用。額度不足時，可追加訂閱同一方案（{% include contract-limits.html %}，價格頁面）
  • 免費期間：免費方案自首次啟動新版本的當天起，可使用 {{ free_plan.free_window_days }} 天。於達到累計上限或天數屆滿時（以較早者為準）結束
  • 不計算的項目：範例專案的重新偵測不列入計算。同一部影片再次偵測，也不會重複計算
  • 剩餘時間不多時：免費額度使用達 80% 後，每次啟動時會顯示 1 次「您已使用 N% 的免費可偵測時間（剩餘 …）。」。用完後，開始偵測時會顯示對話方塊，提示變更方案（未登入時則提示登入）
  • 傳送的內容：為了計算使用時間而傳送的，僅有使用量（影片的秒數）、檔案的雜湊值，以及裝置識別碼的雜湊值（裝置識別碼用於管理免費額度，無法從識別碼辨識出裝置或個人。已登入時會與帳號連結）。此外，為了調查問題並進行改善，會傳送畫面切換與操作的記錄（以固定的名稱記錄，不包含輸入的文字）、處理時間與錯誤等應用程式的運作記錄，以及發生錯誤時的錯誤診斷報告（不會傳送檔案名稱與路徑）。不會傳送檔案名稱、影像與偵測結果的座標。詳細內容請參閱通訊內容揭露與{% include ja-link.html href="/company/privacy" label="隱私權政策" %}（第 12、13 項）
{% include docs-h2.html kicker="維護" title="系統需求" %}
  • OS：Microsoft Windows 10、11（64 位元）
  • 記憶體：8GB 以上（建議 16GB）
  • GPU：NVIDIA GeForce RTX 3000 系列以上（支援 CUDA）+ 最新驅動程式。低於 RTX 3000 系列的 GPU 尚未確認能否運作。沒有 GPU 的電腦也能以 CPU 運作，但處理速度會大幅下降，且無法使用馬賽克精修（貼合物體形狀的馬賽克）。GPU 記憶體不足 4 GB 的機型會以輕量模型偵測，且無法使用馬賽克精修。NVENC 編碼需要 570 以上版本的驅動程式
  • 儲存空間：初始設定時，AI 模型等約需 10GB
  • 網路環境：初始設定時下載模型，以及授權驗證時需要

各 GPU 處理速度的實測值、支援格式的清單，以及 macOS 版的狀況，都整理在系統需求頁面中。瀏覽器版的需求請參閱網頁版支援的瀏覽器與需求。

設定

  • 每次啟動都重複下載時：請確認網路連線後重新啟動應用程式。只有損毀的資料會自動重新取得。
  • 反覆出現「完整性檢查失敗」時：請試試「重新下載」，若仍未改善，請聯絡我們。顯示「自我測試失敗」「缺少相依執行階段元件」時：請從「開啟支援表單」附上顯示的訊息與我們聯絡（初始設定的錯誤清單）。
  • 畫面右下的「GPU 加速」顯示「取得失敗。請按「重試」，或於下次啟動時再次取得」時：請確認網路連線後按「重試」，或重新啟動應用程式（下次啟動時會自動重新取得）。在取得完成前可用 CPU 偵測，但速度會變慢。
  • 出現「Windows 安全性功能暫時封鎖了偵測引擎的啟動」時：Windows 的智慧型應用程式控制等功能，可能會在安全性確認完成前，將剛取得的偵測引擎暫停數分鐘。初始設定畫面每隔數分鐘會自動重試，請勿關閉畫面並稍候（也可以按「立即重試」再試一次）。若等待一段時間後仍持續發生，請在 Windows 安全性 應用程式 → 應用程式 & 瀏覽器控制 → 智慧型應用程式控制設定 中確認狀態（Windows 安全性 應用程式可從開始功能表搜尋開啟），若仍未改善，請聯絡我們。透過更新換成新的偵測引擎時，在確認完成前會繼續以目前的偵測引擎運作，確認完成後會自動切換。

登入與方案

  • 已在瀏覽器中完成驗證，應用程式卻一直停在「正在前往登入頁面…」時：請按「取消」關閉一次，再按一次「登入」。
  • 收不到驗證碼郵件時：請檢查垃圾郵件資料夾。郵件可能需要數分鐘才會送達，請稍候片刻後，在驗證畫面重新傳送驗證碼。
  • 過去使用密碼登入的使用者：從「登入」使用相同的電子郵件地址並輸入驗證碼，即可以與以往相同的帳號登入（登入與授權）。
  • 顯示「目前無法登入。請稍後再試一次。」時：目前暫時無法連線到驗證服務。請稍待一段時間後，再按一次「登入」。若持續發生，請透過聯絡表單與我們聯絡。
  • 出現「您的帳號目前已在其他裝置登入」時：同時只能在 1 台裝置上使用。按「繼續」即可切換到這台裝置（登入與授權）。
  • 畫面上方出現離線橫幅時：本機功能可照常使用。只有出現「請重新登入。」時，才需要從個人資料選單重新登入。
  • 變更方案後，應用程式中未反映變更時：應用程式會在視窗切回前景時（距離上次確認已超過 1 分鐘時）、開啟偵測選項時，以及畫面顯示期間每 5 分鐘確認是否有變更，有變更時會在數秒內反映（偵測執行中時，會在偵測結束後反映）。若仍未變更，請重新啟動應用程式。
  • 剩餘時間沒有減少 / 沒有增加時：使用時間會在偵測完成時計入。因登入而增加的免費額度，會在登入後啟動應用程式時開始反映。

載入與偵測

  • 找不到既有馬賽克時：請先確認偵測時是否已在偵測選項中開啟「馬賽克」，再依序確認下列事項：馬賽克格是否過小（尤其是 4K 素材）、是否為模糊或塗黑（僅以方塊狀的馬賽克為對象）、是否為半透明疊加的馬賽克或與背景同色的方塊、是否在沒有 GPU 的電腦上偵測（結果可能會略有不同）。未找到的範圍，請在編輯頁面中補畫框（找出既有馬賽克並重新套用）。
  • 偵測極度緩慢時：請確認是否已辨識到 GPU（頁尾的 GPU 顯示），以及 NVIDIA 驅動程式是否為最新版本。沒有 GPU 時會以 CPU 模式運作，速度會下降。
  • 偵測選項畫面沒有顯示預覽時：顯示「無法取得影片資訊」時，可能是檔案損毀或格式不受支援。顯示「找不到預覽所需的影片處理檔案」時，請重新啟動應用程式，完成必要檔案的下載。
  • 出現「無法在偵測結果的儲存位置建立專案資料夾」時（在偵測選項畫面中也會顯示相同的訊息）：無法寫入的並非影片的位置，而是偵測結果的儲存位置（專案資料夾）。請重新選取儲存位置（選單的「檔案」→「選取專案資料夾」，或偵測選項畫面的「重新選取專案資料夾」），或按「改回預設位置」。若安全性軟體的資料夾保護阻止了寫入，請允許 Deepmosaic，並確認資料夾的存取權限。若將外接磁碟機或網路資料夾設為儲存位置，請確認連線（專案資料夾）。
  • 選取資料夾後仍出現「找不到可處理的影片」時：子資料夾中的影片不在處理範圍內。請直接重新選取存放影片的資料夾。
  • 無法按下「開始」時：正在確認模型檔案。請稍候，或在顯示錯誤時按「重試」。若已達上限，需要變更方案（未登入時需要登入）。剩餘可偵測時間少於影片全長時，「開始」上方也會顯示原因且無法按下（即使縮小範圍也會以全長計算。偵測選項）。
  • 已偵測卻沒有出現在首頁畫面時：「所有影片」只會顯示位於目前專案資料夾中、由目前登入的帳號建立的影片。儲存在其他專案資料夾中的影片，可從側邊欄的「其他資料夾」列查看（專案資料夾）。
  • 出現「使用高精度模型需要先登入」時：登入後，在搭載 GPU 的電腦上，從下次偵測起即可使用高精度模型（在那之前會以輕量模型偵測）。出現「正在準備高精度模型」時，在取得完成前會以輕量模型偵測。
  • 無法繼續已中斷的偵測時：請確認卡片上顯示的原因。若原始影片已移動或變更、已編輯等，將無法繼續，請按「捨棄」後重新載入（AI 偵測）。

編輯

  • 出現「沒有詳細資料」時：專案資料夾已被移動或刪除。請將它移回原來的位置，或以「刪除專案」從清單中移除後重新載入。
  • 出現「儲存失敗」時：無法寫入專案資料夾。請確認磁碟的可用空間、資料夾的權限，以及是否與雲端同步發生衝突（資料儲存位置）。
  • 臉部的性別偵測結果相反時：可從框的右鍵選單，或在人物圖庫中修正。
  • 手動放置的 ∞ 框中途消失時：∞ 框會在刪除的影格之前結束。請在想要延續的位置再按一次 2 新增。
  • 首頁畫面出現「此專案在上次啟動時發生問題」時：按「檢查」，若沒有問題即可直接開啟。發現問題時，請按「修復」嘗試從上次儲存的內容復原。
  • 出現「有 N 個專案轉換失敗」時：請按「重試」。若重複發生，請聯絡我們。

匯出

  • 出現「GPU 編碼需要 NVIDIA 驅動程式 570 以上版本」時：在更新驅動程式之前，會以 CPU 輸出（需要較長時間，但結果相同）。
  • 匯出顯示「失敗」時：請確認儲存位置的可用空間與權限，以及輸出檔案是否在其他應用程式中開啟。進度視窗的「失敗」下方會顯示錯誤內容。
  • 出現「不會套用任何馬賽克。」時：沒有偵測結果，或所有追蹤軌跡都已排除在馬賽克對象之外。請在編輯頁面中確認。
  • 不小心關閉進度視窗時：可從選單列的「佇列」選取「在另一個視窗開啟進度」重新開啟。

Premiere Pro 整合

  • 出現「在這台 PC 上找不到 Adobe Premiere Pro。」時：請安裝 Premiere Pro 25.3 以上版本。
  • 出現「找不到自動安裝所需的 Creative Cloud 元件」時：請安裝 / 更新 Creative Cloud 桌面應用程式並登入，或從「開啟增效模組資料夾」手動安裝。
  • 傳送顯示「逾時」時：請在 Premiere Pro 中開啟 Deepmosaic 面板後重試。剛安裝增效模組後，需要重新啟動 Premiere Pro。

若仍無法解決，請透過應用程式內的聯絡我們，或聯絡表單與我們聯絡。附上頁尾的版本，以及 %USERPROFILE%\.deepmosaic\logs\app.log（偵測的問題，也請附上存放每次偵測記錄的 %USERPROFILE%\.deepmosaic\logs\runs 中，在該次偵測前後更新的檔案），可加快調查速度。

  • 授權：GNU General Public License version 3（GPL v3）。全文請見 https://www.gnu.org/licenses/gpl-3.0.html
  • 版本與建置：n8.1.3-27-g8dca1586f4。建置來源為 BtbN/FFmpeg-Builds（發行版 autobuild-2026-10-31-12-59，win64-gpl-shared-8.1）。這是以 --enable-gpl --enable-version3 組態的 shared 版，由 ffmpeg.exe / ffprobe.exe，以及它們在執行時載入的 FFmpeg DLL（avcodec-62.dll、avdevice-62.dll、avfilter-11.dll、avformat-62.dll、avutil-60.dll、swresample-6.dll、swscale-9.dll）組成。以 libx264、libx265、libxvid（皆為 GPL v2 或更新版本）為首的程式庫，皆以靜態方式連結至這些 DLL。所連結的程式庫清單及各自的授權，可在應用程式內的「說明 ▸ 授權」（ffmpeg-NOTICE.txt）中查看。
