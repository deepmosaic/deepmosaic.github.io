Microsoft Store 版與安裝程式版的差異

Microsoft Store 版可使用的功能、帳號與方案（包括在應用程式中訂閱方案、變更方案與取消訂閱）都與安裝程式版相同。只有以下幾點不同。

  • 更新：Microsoft Store 版沒有應用程式內的更新對話方塊與「檔案 ▸ 檢查更新」（更新）
  • 隨附的第三方軟體：由於 Microsoft Store 版的套件內容為唯讀且已簽署，因此無法就地替換隨附的 FFmpeg（可以使用依照 GPL 另行取得、修改的 FFmpeg。隨附的第三方軟體與授權）
  • Premiere Pro 整合：要在 Microsoft Store 版中使用 Premiere Pro 整合，需要更新增效模組（0.1.21 以上版本）。執行「匯入至 Premiere Pro」，並依照指示進行更新（Premiere Pro 整合）
  • 解除安裝：確認畫面中沒有核取方塊，設定與登入資訊（%USERPROFILE%\.deepmosaic）以及專案資料夾都會保留。不再需要的資料夾，請在解除安裝後於檔案總管中刪除（請注意，儲存在專案資料夾中的匯出影片也會一併刪除）
