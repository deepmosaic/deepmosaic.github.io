{% include docs-h2.html kicker="Export and integration" title="Export" %}

Use the "Export" button in the edit page header (Ctrl+Enter) to set up the export. Press "Start" to add the job to the queue, and follow its progress in a dedicated window. Any unsaved edits are saved automatically when the export starts.

Format
MP4 (H.264) / MP4 (H.265 / HEVC) / MOV (ProRes 422) / MOV (ProRes 422 HQ) / WebM (VP9) / WebM (AV1) / MKV (H.264) / MKV (H.265) / AVI (H.264; for compatibility with editing software, always exported on the CPU as H.264 without B-frames) / MOV (DV) / MOV (DNxHR SQ) / MOV (DNxHR HQ) / MOV (DNxHR HQX 10bit) / MOV (CineForm)
Resolution
Same as source video / 4K DCI (4096x2160) / 4K UHD (3840x2160) / QHD (2560x1440) / Full HD (1920x1080) / HD (1280x720) / SD (854x480) / SD NTSC (720x480) / SD PAL (720x576) (for DV)
Frame rate
Same as source video / 23.976 (film) / 24 / 25 (PAL) / 29.97 (NTSC) / 30 / 50 / 59.94 / 60 fps
Bitrate
Auto (quality-based, CRF 18) / 50 / 20 / 10 / 5 / 2 Mbps. For DV / DNxHR / CineForm, the bitrate is determined by the format and can't be selected
Timecode
"Burn in timecode" burns the timecode into the video. Use "Settings" to change the text size, position, color, and display format (Timecode settings)
NVENC GPU encoding
Hardware encoding on an NVIDIA GPU. With a driver older than 570, a warning appears and the video is exported on the CPU (libx264). It isn't used for formats the GPU doesn't support, such as ProRes / VP9 / AV1
Save location
By default, the file name is the same as the source video (with the extension of the selected format). To prevent accidental overwrites, you're asked to confirm the folder every time
Previous settings
The format, resolution, frame rate, bitrate, timecode, GPU, and save folder you used last time become the defaults for the next export
Warning
If there is nothing to apply mosaic to (no detections, everything excluded, and so on), "Mosaic will not apply to any area." appears. Check for missed detections before you export
Record timecode
Choose "None" (default), "Carry over the source video timecode", or "Custom value" to record timecode information in the exported file (it isn't drawn on the video). This is a separate setting from "Burn in timecode", which burns the timecode into the video, and you can use both together. Enter a custom value in the format HH:MM:SS:FF. Drop-frame uses the format HH:MM:SS;FF and is available only at 29.97 / 59.94 fps. If the value doesn't match the format, you're notified before the export starts. "Carry over the source video timecode" is available only when the frame rate is "Same as source video". If the source video has no timecode, the timecode starts at 00:00:00:00. If the timeline starts partway through the source video, the timecode starts from the source timecode at that point. In MKV, the timecode is kept only as a tag, and some editing software doesn't read it, so MOV is recommended. This setting applies only to the current export and doesn't become the default for the next one

The mosaic block size is adjusted automatically so that it doesn't fall below the self-regulation standard (the long side divided by 100, minimum 4px) for the export resolution. Even when you export 4K media at Full HD, the output video meets this standard.

Areas covered by an exclusion mask get no mosaic and are exported as the original video, and their edges blend in with the edge feather. For a detection box that runs off the edge of the frame, mosaic is applied to the part inside the frame, based on the shape extended beyond the edge of the frame during detection (the shape isn't squashed at the edge).

"MOV (ProRes 422)" exports in ProRes 422. Its image quality (bitrate) is lower than "MOV (ProRes 422 HQ)", so the files are smaller (roughly 2/3 the size). In earlier versions, choosing "MOV (ProRes 422)" still exported in 422 HQ. If you need the same quality as before, choose "MOV (ProRes 422 HQ)".

"MOV (DV)" can export only 720×480 (29.97 fps) and 720×576 (25 fps). "MOV (DNxHR …)" and "MOV (CineForm)" can export only videos whose width and height are even numbers, and "MOV (CineForm)" also requires a width that is a multiple of 16 and a height of 32 or more (otherwise, the reason is shown when you start). All of these formats use a MOV container, and the files are dozens of times larger than H.264, so keep an eye on the free space at the save location.

{% include docs-h2.html kicker="Export and integration" title="Timecode settings" %}

To open these settings, turn on "Burn in timecode" in the export settings and press "Settings" next to it. Burned-in timecode helps reviewers refer to positions in the video when you export a review copy (for example, to share with others for checking).

Text size (px)
Any number. Default: 64px (actual pixels at the export resolution)
Position
Top left / Top center / Top right / Center / Bottom left / Bottom center / Bottom right. Default: Bottom right
Color
White / Black / Yellow / Green. Default: White
Draw an outline
Adds an outline around the text so it stays readable on bright backgrounds (on by default)
Display format
HH:MM:SS:frames (default) / HH:MM:SS / HH:MM:SS.milliseconds / Frame number

When the setting is on, the timecode also appears with the same look in the edit page preview and in the progress window preview.

{% include docs-h2.html kicker="Export and integration" title="Export progress window" %}

When you start an export, a progress window opens as a separate window for each job. The job continues even if you close it, and you can reopen it at any time with "Open progress in a separate window" in the queue.

Preview
Shows the frame being exported at regular intervals (with the timecode when timecode burn-in is on). Right after the start, "Extracting the first frame…" appears, and while the job is waiting its turn, "Waiting in queue" appears
Progress
The percentage complete, "Frame N / M", "Speed (fps)", and "Time remaining". When the export finishes, "Complete ✓" appears; when it's stopped, "Canceled"; and when it fails, "Failed" with the error details
Output info
The output path, format, and resolution
Pause / Resume
Pauses the export. Useful when you want to lighten the load on your PC while you do other work
Cancel
Stops the export (it can't be resumed). The partially written file is deleted
Close
Only closes the window. The job continues
{% include docs-h2.html kicker="Export and integration" title="Exporting and importing projects" %}

You can package a project (detection results and edit data) into a single zip file and hand it over to another PC or another person. This lets you split the work, for example by running detection on your own PC and asking someone else to review and correct the results.

Export

Choose "Export project" from the video card menu on the home screen, and specify where to save the file. The zip contains the source video (if it's still in the project folder), detection results, edit data, scenes, thumbnails, representative face images, and the media you added in timeline editing (video, audio, and images). If the source video can't be found, a message tells you so, and everything except the video is exported.

Import

Choose "File ▸ Import project" from the menu and select the zip. The imported project is extracted into the current project folder and added to the home screen.

If a project with the same project ID is already on your PC, "Matching project found" appears, and you choose one of the following.

Import edits
Keeps your existing project as is and replaces only the edit data with the contents of the zip. Any timeline media in the zip that you don't already have is added before the replacement (your existing media isn't deleted). The edit data from before the replacement is backed up automatically. Use this to apply the changes when someone you asked to do the work sends the project back
Add as new project
Assigns a new ID and adds it as a separate project. Your existing project doesn't change

While the project is being imported, the progress (extracting, then registering) is shown. On the PC that imported the exported project, you can edit it, export it, and send it to Premiere Pro right away.

{% include docs-h2.html kicker="Export and integration" title="Premiere Pro integration" %}

From the video card menu or the button in the edit page header (Ctrl+Shift+P), you can automatically import the detected mosaic information into an Adobe Premiere Pro project. Before sending, the app automatically checks Premiere Pro itself, the plug-in, and whether Premiere Pro is running, and if anything isn't ready, it guides you through the setup steps. This feature is available only in the Windows app.

Requirements

  • Adobe Premiere Pro 25.3 or later is installed
  • You're signed in to the Creative Cloud desktop app (required to install the plug-in automatically)

First-time setup

  1. Press "Import into Premiere Pro". If the plug-in isn't installed yet, "Download and install" appears. Press it to download and install the Premiere Pro plug-in (UXP) for Deepmosaic
  2. "The plug-in has been installed." appears. If Premiere Pro was already running, restart it and then run the import again
  3. If Premiere Pro isn't running, "Premiere Pro must be started to send the detection results." appears. Press "Start and send"

If the Creative Cloud component can't be found, "The Creative Cloud component needed for automatic installation was not found" appears. Install or update the Creative Cloud desktop app, or install the plug-in manually from "Open plug-in folder".

Sending and results

When you send, the "Premiere Pro integration" widget appears at the bottom right of the screen and moves from "Processing in Premiere Pro…" to "Import into Premiere Pro complete". Premiere Pro then does the following to the sequence in the open project.

  • The original clip is duplicated onto the video track above, and Premiere Pro's standard "Mosaic" effect is applied along with a "Crop" effect keyframed to match the detection boxes (1 clip per detected object)
  • The boxes from the detection results, the block size set by the pixel size, and the overall edge feather value are carried over. Changes made on the edit page (adding, moving, deleting, or reshaping boxes, mosaic exclusions, and exclusion masks, including existing boxes changed into exclusion masks) and "Blur strength" and "By time" in the mosaic settings are not carried over, but they are applied when you export
  • When many objects overlap at the same time, more tracks are added (up to 15 tracks)

If any box in a project has "Invert (apply outside)" turned on in the mosaic settings, the project isn't sent (Premiere Pro can't reproduce inversion, so the outside would be output without being hidden). In that case, "Sending was stopped because N settings use Invert (apply outside). Premiere Pro can't reproduce inversion, so the outside would be exported without being covered. Turn off Invert, or export from this app." appears. Turn off inversion, or export with this app.

After the import, you can adjust the position and block size with normal Premiere Pro editing. If there's no response for a while after sending, "Timed out" appears. Check that the plug-in panel is open in Premiere Pro, then try again.

{% include docs-h2.html kicker="Export and integration" title="Checking for missed detections" %}

AI detection isn't perfect. Before you export, check and correct the results with the following tools. Responsibility for the final check and for how the content is expressed rests with the creator.

  • Jump to missing frames: Press [ and ] to move back and forth between frames where detection drops out. Use this to track down a "Gap" (detections exist before and after but are missing in between). To narrow down the classes while checking (for example, body areas only), use "Filter" in the "Labels" menu on the toolbar
  • Play blank frames only (B): Plays only the frames with no detections, one after another, so you can find places where something is visible but has no box
  • Mosaic preview (M): Review the whole video in a view close to the exported result. You can also hide the overlay (H) to see only the original video
  • Overview on the timeline: Detected segments are shown as bands by class and by tracking ID. If a band for the same ID is broken, that is where tracking was interrupted
  • Person gallery (P): Review face detections grouped by person, and decide for each person whether mosaic is needed
  • Confidence threshold: Temporarily hide low-confidence detections to sort things out, then lower the threshold to pick them up again
  • Safety margin: Use "Size (box expansion)" to scale detection boxes between 0.5x and 2x, so you can leave a margin instead of cutting it close
  • Add and delete manually: Where nothing was detected, add a box with 1 (1 frame) / 2 (all following frames). Delete false detections with a right-click or with the eraser (E+right-drag). To leave parts without mosaic, use an exclusion mask with 3 / 4

The cases AI struggles with (extreme backlighting, heavy motion blur, partial occlusion, compositions that are rare in the training data, and animation / 3DCG) are listed on the home page. If your media falls into any of these cases, review it more carefully.
