{% include docs-h2.html kicker="Maintenance" title="Updates" %}

In the Microsoft Store edition, new versions are delivered by Microsoft Store and installed automatically. AI models are downloaded and replaced automatically at startup when new ones are available. The following describes the installer edition (until December 31, 2026; see Switching).

The installer edition automatically checks for a new version when it starts. If an update is available, a dialog appears, and you choose either "Update now" or "Later".

When it checks automatically
Right after launch, then every hour, and when you return to the window. While detection or export is running, the dialog waits until it finishes
Update now
Downloads and applies the new version, and the app restarts automatically. If a process is running, update after it finishes
Later
No further automatic checks are made during this session. The app checks again the next time it starts
Detection engine
Included in the app and updated together with it
AI models
If newer ones are available at launch, they are downloaded and replaced automatically (the same mechanism as the initial setup)

Checking manually

Select "File ▸ Check for updates" in the menu to see "Current", "Latest", and "Status" for three items: the app, the engine, and models and assets. When "Updates are available" is shown, you can apply them with "Update now" (the app) or "Update models and assets". "Check again" checks once more. If the app can't connect to the network, "Check your network connection, then try again." appears.

{% include docs-h2.html kicker="Maintenance" title="Where data is stored" %}

Deepmosaic does not send your videos or their detection results to a server. Everything is saved in the following locations on your PC.

Project folder
Default: C:\Users\<user name>\deepmosaic. Each video has its own subfolder containing a database that holds the detection results and edit data (project.db), thumbnails, representative face images, and more. Loaded videos themselves are not copied; they are referenced from their original location. Media added in timeline editing (video, audio, and images) is copied to the assets subfolder and is also included when you export the project (Project folder)
%USERPROFILE%\.deepmosaic
Settings (config.json), the catalog of the home list, folders, and tags (catalog.db), encrypted sign-in information, the device ID, and logs (logs\app.log; logs for each detection are in logs\runs). When you contact us, we may ask you to attach the logs
%LOCALAPPDATA%\deepmosaic
AI models, the GPU runtime (PCs with an NVIDIA GPU only), and more (about 10GB in total). Managed automatically by the initial setup and the check at launch. The detection engine and video processing tools are included in the app
Exported videos
The save location you specified when exporting. The app does not manage them

If you put the project folder inside a cloud-synced folder (such as OneDrive), autosave during editing can conflict with syncing and result in "Save failed". We recommend a local folder.

project.db and catalog.db are databases managed by the app. While the app is running, do not open them with other tools or modify their contents (doing so can corrupt your data). Make backups or copies after you quit the app, and if there are files whose names start with project.db (-wal / -shm), copy them as well.

{% include docs-h2.html kicker="Maintenance" title="Uninstall" %}
  1. Open Windows "Settings" > "Apps" > "Installed apps"
  2. Find "Deepmosaic" in the list and select "Uninstall" (administrator privileges are not required)

You can uninstall the Microsoft Store edition in the same way. There is no check box on the confirmation screen, and your settings, sign-in information, and project folders are left on your PC (Differences between the Microsoft Store edition and the installer edition).

When you uninstall the installer edition, the AI models and other data (%LOCALAPPDATA%\deepmosaic, about 10GB) are deleted automatically (if you reinstall, they are downloaded again during the initial setup; from version 2.18, the installer edition doesn't delete them on a PC where the Microsoft Store edition is installed).If you select the "アプリのデータとプロジェクトフォルダを削除する (中の書き出し動画も削除されます)" (Delete app data and project folders; exported videos inside are also deleted. This item appears in Japanese) check box on the uninstall confirmation screen, your settings and sign-in information (%USERPROFILE%\.deepmosaic) and the project folders that Deepmosaic created (detection results and edit data, including any exported videos saved inside those folders) are also deleted. If you leave it unselected, these remain. Original videos and exported videos outside the project folders are not deleted. Nothing is deleted when you update.

To delete the account itself, see Deleting your account.

{% include docs-h2.html kicker="Maintenance" title="How usage time is measured" %}
    {%- assign free_plan = site.data.plans.tiers | where: "code", "free" | first -%}
  • What is measured: The running time of each video whose detection has completed is added to a cumulative total. The remaining time appears in the footer ("Detection time remaining" on the Free plan, "Remaining this month" on paid plans)
  • When time is counted: Time is added when detection completes. Export is not counted. Even if you narrow the detection range, the length of the whole video is counted
  • How limits apply: There are no overage charges. If you use up the included hours of a paid plan, your allowance is restored on the next renewal date. If you need more than that, please ask us about Enterprise, our plan for businesses (custom quote; pricing page)
  • Free period: You can use the Free plan for {{ free_plan.free_window_days }} days from the day you first launch a new version. It ends when you reach the total limit or the number of days, whichever comes first
  • What is not counted: Running detection again on the sample project is not counted. Detecting the same video again is not counted twice
  • When little time remains: Once you have used 80% of the free allowance, "You have used N% of your free available detection time (… left)." appears once each time you launch the app. When it is used up, a dialog appears when you start detection, prompting you to change your plan (or to sign in, if you are not signed in)
  • What is sent: For measuring usage time, the only data sent is usage (seconds of video), file hash values, and the hash value of the device identifier (the device identifier is used to manage the free allowance, and it cannot be used to identify a device or an individual; while you are signed in, it is linked to your account). In addition, to investigate problems and improve the app, we send records of screen navigation and operations (recorded with fixed names; they do not include text you type), records of how the app runs such as processing times and errors, and error diagnostic reports when an error occurs (file names and paths are not sent). File names, video, and the coordinates of detection results are not sent. For details, see the data transmission disclosure and the {% include ja-link.html href="/company/privacy" label="Privacy Policy" %} (Sections 12 and 13)
{% include docs-h2.html kicker="Maintenance" title="System requirements" %}
  • OS: Microsoft Windows 10, 11 (64-bit)
  • Memory: 8GB or more (16GB recommended)
  • GPU: NVIDIA GeForce RTX 3000 series or later (CUDA-capable) + the latest driver. GPUs below the RTX 3000 series have not been tested. The app also runs on the CPU on PCs without a GPU, but processing is much slower, and mosaic refinement (mosaic that follows the shape of the object) is not available. On a PC whose GPU has less than 4 GB of memory, detection uses the lightweight model, and mosaic refinement is not available. Export with NVENC requires driver 570 or later
  • Storage: About 10GB for AI models and other data during the initial setup
  • Internet connection: Required to download the models during the initial setup and for license authentication

Measured processing speeds by GPU, the list of supported formats, and the status of a macOS version are on the system requirements page. For the requirements of the browser version, see Supported browsers and requirements for the Web app.

{% include docs-h2.html kicker="Maintenance" title="Troubleshooting" %}

Setup

  • If downloads keep repeating at startup: Check your connection, then restart the app. Only corrupted data is downloaded again automatically.
  • If "Integrity check failed" keeps appearing: Try "Download again", and if that doesn't help, contact us. If "Self-test failed" or "Missing runtime dependency" appears: Contact us from "Open support form", including the message that was shown (see the list of errors in Initial setup).
  • If "GPU acceleration" at the bottom right of the screen shows "Failed to get the files. Press "Retry", or they will be fetched again the next time the app starts": Check your connection and press "Retry", or restart the app (it fetches the files again automatically the next time it starts). Until the download finishes, you can run detection on the CPU, but it is slower.
  • If "Windows security is temporarily blocking the detection engine from starting" appears: Windows features such as Smart App Control may hold a newly downloaded detection engine for a few minutes until its safety check is complete. The initial setup screen retries automatically every few minutes, so wait without closing it (you can also press "Retry now" to try again). If it still continues after a while, check the status in Windows Security app > App & browser control > Smart App Control settings (you can open the Windows Security app by searching for it from the Start menu), and if that doesn't help, contact us. When an update brings a new detection engine, the app keeps running on the current detection engine until the check is complete, and switches automatically as soon as it is.

Sign-in and plans

  • If the app stays on "Opening the sign-in page…" even though you authenticated in the browser: Close it with "Cancel", then press "Sign in" again.
  • If the confirmation code email doesn't arrive: Check your spam folder. It can take a few minutes to arrive, so wait a little, then resend the code on the sign-in page.
  • If you previously signed in with a password: From "Sign in", enter the confirmation code using the same email address, and you can sign in to the same account as before (Sign-in and license).
  • If "You cannot sign in right now. Try again later." appears: The authentication service is temporarily unreachable. Wait a while, then press "Sign in" again. If it continues, contact us through the contact form.
  • If "Your account is currently signed in on another device" appears: You can use one device at a time. Press "Continue" to switch to this device (Sign-in and license).
  • If an offline banner appears at the top of the screen: Local features keep working as usual. Only when "Sign in again." appears, sign in again from the profile menu.
  • If a plan change isn't reflected in the app: The app checks for changes when you bring its window back to the front (if at least 1 minute has passed since the last check), when you open the detection options, and every 5 minutes while the window is visible, and reflects a change within a few seconds (while detection is running, it is reflected after detection finishes). If it still doesn't change, restart the app.
  • If the remaining time doesn't go down or up: Usage time is added when detection completes. The larger free allowance from signing in takes effect the next time you launch the app after signing in.

Loading and detection

  • If existing mosaic isn't found: Make sure you ran detection with "Mosaic" turned on in the detection options, then check the following in order: whether the blocks are too small (especially in 4K media), whether it is blur or a blacked-out area (only block-style mosaic is supported), whether it is semi-transparent overlaid mosaic or blocks in the same color as the background, and whether you ran detection on a PC without a GPU (the results can differ slightly). For ranges that weren't found, draw additional boxes on the edit page (Finding existing mosaic and reapplying it).
  • If detection is extremely slow: Check that the GPU is recognized (the GPU indicator in the footer) and that your NVIDIA driver is up to date. Without a GPU, the app runs in CPU mode and is slower.
  • If no preview appears on the detection options screen: If "Could not get the video information" is shown, the file may be corrupted or in an unsupported format. If "The video processing files needed for the preview were not found" is shown, restart the app and let it finish downloading the required files.
  • If "Could not create the project folder in the save location for detection results" appears (on the detection options screen, "Can't create the project folder in the save location for detection results" is shown): The problem is not the video's location: the app can't write to the save location for detection results (the project folder). Choose the save location again ("File ▸ Select a project folder" in the menu, or "Choose the project folder again" on the detection options screen), or press "Use the default location". If folder protection in your security software is blocking writes, allow Deepmosaic, and also check the folder's access permissions. If the save location is on an external drive or a network folder, check the connection (Project folder).
  • If "No videos that can be processed were found" appears even though you chose a folder: Videos in subfolders aren't included. Choose the folder that directly contains the videos.
  • If you can't press "Start": The model files are being checked. Wait a while, or press "Retry" if an error is shown. If you have reached your limit, you need to change your plan (or sign in, if you aren't signed in). You also can't press it if your remaining available detection time is shorter than the full length of the video; the reason is shown above "Start" (the full length is counted even if you narrow the range; see Detection options).
  • If a video you ran detection on doesn't appear on the home screen: "All videos" shows only videos in the current project folder that were created with the account you are signed in with. Videos saved in another project folder can be found from the "Other folders" row in the sidebar (Project folder).
  • If "Sign in to use the high-accuracy model" appears: Once you sign in, PCs with a GPU can use the high-accuracy model from the next detection (until then, detection uses the lightweight model). If "Preparing the high-accuracy model" appears, detection uses the lightweight model until the download finishes.
  • If an interrupted detection can't be resumed: Check the reason shown on the card. It can't be resumed if, for example, the original video was moved or changed, or the project has been edited. In that case, "Discard" it, then load the video again (AI detection).

Editing

  • If "No detail data" appears: The project folder has been moved or deleted. Move it back to its original location, or remove the project from the list with "Delete project" and load the video again.
  • If "Save failed" appears: The app can't write to the project folder. Check the free disk space, the folder permissions, and conflicts with cloud sync (Where data is stored).
  • If the gender of a face is detected the wrong way around: You can correct it from the box's right-click menu or in the Person gallery.
  • If an ∞ box you placed manually disappears partway through: An ∞ box ends just before the frame where it was deleted. Add it again with 2 at the position where you want it to continue.
  • If "This project caused a problem the last time the app was launched" appears on the home screen: Press "Check". If no problem is found, you can open the project as usual. If a problem is found, try restoring it from the last saved state with "Repair".
  • If "N projects failed to convert" appears: Press "Retry". If it keeps happening, contact us.

Export

  • If "GPU encoding requires NVIDIA driver 570 or later" appears: Until you update the driver, the video is output using the CPU (it takes longer, but the result is the same).
  • If an export ends in "Failed": Check the free space and permissions of the save location, and whether the output file is open in another app. The error details appear below "Failed" in the progress window.
  • If "Mosaic will not apply to any area." appears: There are no detections, or all tracks have been excluded from mosaic. Check this on the edit page.
  • If you closed the progress window: You can reopen it with "Open progress in a separate window" under "Queue" in the menu bar.

Premiere Pro integration

  • If "Adobe Premiere Pro was not found on this PC." appears: Install Premiere Pro 25.3 or later.
  • If "The Creative Cloud component needed for automatic installation was not found" appears: Install or update the Creative Cloud desktop app and sign in to it, or install the plug-in manually from "Open plug-in folder".
  • If sending ends in "Timed out": Try again with the Deepmosaic panel open in Premiere Pro. Right after you install the plug-in, you need to restart Premiere Pro.

If this doesn't solve the problem, contact us through Contact us in the app or the contact form. Attaching the version shown in the footer and %USERPROFILE%\.deepmosaic\logs\app.log (for detection problems, also the file updated around the time of that detection in %USERPROFILE%\.deepmosaic\logs\runs, where the log of each detection is kept) helps us investigate faster.

{% include docs-h2.html kicker="Maintenance" title="About the Web app (browser version)" %}

There is also a Web app that requires no installation and that you can use with the same account from a browser such as Chrome or Edge. Detection, editing, and export are all processed inside the browser, and your video is not sent to a server. The detection targets and the features of the edit page are the same as in the Desktop app, but there are some differences, such as these: export formats are limited to MP4 (H.264) / WebM (VP9 / AV1), it handles videos up to about 1.9GB and in practice only mp4 / mov, and it has no Premiere Pro integration, project import, resuming of interrupted detections, or regrouping of people.

How to use it, the supported browsers, and a list of differences from the Desktop app are covered in Web app guide.{% if site.data.site.web_app.enabled %} You can open the Web app at app.deepmosaic.co.jp.{% endif %}
