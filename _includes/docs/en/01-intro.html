{% include docs-h2.html kicker="Getting started" title="Introduction" %}

Deepmosaic is a Windows desktop application that automates adding mosaic to videos with AI (deep learning) object detection. Everything from loading a video to AI detection, editing the detection results, and exporting a video with the mosaic burned in happens inside the app. This software is for applying (adding) mosaic. It has no feature for taking off mosaic from footage that already has mosaic applied, or for restoring the original footage.

This page is the guide to the Windows app (Deepmosaic Desktop). For the Web app, which runs in your browser with no installation, see the Web app guide (the differences from the Desktop app are also summarized at the end of this page).

Video guides to the basics

Workflow

  1. Load videos: from a file, a folder, or by drag and drop. Loaded videos appear on the home screen as "projects"
  2. Detect with AI: choose the detection range and targets (body areas / male faces / female faces / existing mosaic) and start. Processing runs in the background, and the queue lets you process multiple videos one after another
  3. Review and correct on the edit page: add or delete detection boxes, adjust how the mosaic looks, and check for missed detections
  4. Export: export a video with the mosaic burned in. You can also hand the detection results over to Premiere Pro

End of the installer edition and switching to the Microsoft Store edition

The installer edition downloaded from our website (shown as the "installer (exe) version" in the app) will stop working after December 31, 2026. You can keep using it until then. Please switch to the Microsoft Store edition soon. Pricing, terms of use, and features stay the same.

  • What carries over: The Microsoft Store edition uses your existing project folders, settings and sign-in information, and AI models and other data as is. Your plan is tied to your account, so you can keep using it
  • From version 2.18 of the installer edition, a notice about switching appears when the app starts (if you close it with "Later", it doesn't appear again until the next launch). If you start it on or after January 1, 2027, a "discontinued" screen appears and you can't use the app
  • Until December 31, 2026, the installer edition still receives in-app updates
  1. Install the Microsoft Store edition (with the button above, or "Download from Microsoft Store" in the app's notice)
  2. Quit the installer edition, then start the Microsoft Store edition and check that your settings and projects have carried over
  3. Once it works properly, uninstall the installer edition (Uninstall). From version 2.18, the installer edition doesn't delete the settings, sign-in information, and AI models and other data shared with the Microsoft Store edition on a PC where the Microsoft Store edition is installed (the check box for deleting data isn't shown either)

If you uninstall an installer edition older than 2.18, do not select the "アプリのデータとプロジェクトフォルダを削除する" (Delete app data and project folders. This item appears in Japanese) check box on the confirmation screen (doing so also deletes the settings, detection results, and project folders shared with the Microsoft Store edition). The AI models and other data are deleted, and the Microsoft Store edition downloads them again the next time it starts. If you first update to 2.18 or later with the in-app update, they aren't deleted.

Agreeing to the End User License Agreement

On first launch, the "Before you start" dialog appears before the initial setup. Review the End User License Agreement and the Terms of Service (you can read the full text from the links in the dialog), select the "I agree to the End User License Agreement and the Terms of Service" check box, and press "Agree and continue" to start the setup. If you choose "Decline (quit)", the app quits. When the End User License Agreement or the Terms of Service is revised, "The End User License Agreement and Terms of Service have been updated" appears when the app starts, so agree to them again.

Downloading data

The detection engine and the lightweight detection model are included in the app. On first launch, the model data needed for AI detection is downloaded automatically ({{ spec_storage.val }}). During the download, the overall progress (%) and the time remaining are shown, and you can't do anything else until it finishes. Depending on your connection speed, it can take anywhere from a few minutes to more than ten minutes.

Some data, such as the high-accuracy model, is fetched in the background after you reach the home screen. Until that finishes, detection uses the lightweight model, and the detection options screen shows "Preparing the high-accuracy model (about N MB left) — the lightweight model will be used for detection this time."

When the download finishes, a test run of detection and export ("Test run in progress…") starts automatically. If a problem is found, only the affected data is downloaded again automatically. When it is done, the app moves to the home screen on its own and shows "Installation complete" (you don't need to press "Continue").

What you can't do during setup

Until the download and the test run finish, all menu items except "File ▸ Quit" and "Help" (other than "Tutorials") are disabled, and closing the window or reloading the screen is also blocked. If you quit partway through, the app fetches only the missing data and resumes the next time it starts.

If an error appears

Integrity check failed
A downloaded file is corrupted. Press "Download again" to fetch only the affected file again (the app retries automatically up to 2 times)
Missing runtime dependency
A Windows component that the detection engine needs was not found. Contact us through "Open support form", and include details of your environment (such as the OS version)
Self-test failed
The download finished, but the test run of the detection engine failed. Contact us through "Open support form", and include the message that was shown and details of your environment (such as the OS version)
Download is stuck
Check your connection and press "Retry", or restart the app. Files that were already downloaded are used as they are, and only the missing ones are downloaded again

Preparing GPU acceleration (PCs with an NVIDIA GPU only)

On PCs with an NVIDIA GPU, the acceleration components (from NVIDIA; about 1.7 GB to download, about 2.4 GB after extraction) are fetched automatically the first time. They are not fetched on PCs without an NVIDIA GPU. Until they are fetched, the app runs on the CPU (the features are the same, but processing is slower). While they are being fetched, the progress appears in "GPU acceleration" at the bottom right of the screen, and once they are fetched, later detections run on the GPU.

If fetching fails, the indicator at the bottom right shows 'Failed to get the files. Press "Retry", or they will be fetched again the next time the app starts'. Check your connection and press "Retry", or restart the app (the files are fetched again automatically the next time it starts). For how these are handled as third-party software, see Bundled third-party software and licenses.

Lets you check and manage the waiting list of detection and export jobs in one place. A badge shows the number of running and waiting jobs (Queue).

Shows the licenses of the bundled third-party software and the third-party software downloaded on first launch. The list shows only the software names; press a row to open its details (Bundled third-party software and licenses). You can also check your version and its distribution type here

Opens this page in your default browser
Tutorials
Opens the list of tutorial videos. Select a card to play that video in the app, and select "Back to list" to go back to the list. You can use it on paid plans too (videos that can't be loaded aren't listed). Not available during the initial setup

"Licenses" and "Documentation" in "Help" are available even during the initial setup. In versions before 2.13 and in 2.14, these two items were also in the profile menu.

Display language

Just below the "Theme" row in the profile menu (top right), there are 3 buttons: Japanese, English, and Traditional Chinese, each written in its own language. When you press one, the screen language switches immediately, and the app also uses the selected language the next time it starts.

{% include docs-h2.html kicker="Getting started" title="Theme (light / dark)" %}

Use "Theme" in the profile menu to switch between "Use OS setting", "Light mode", and "Dark mode". By default, the app follows the OS setting. Your choice is saved, and the app uses the same theme the next time it starts. The video preview and the detection box colors stay the same regardless of the theme.
