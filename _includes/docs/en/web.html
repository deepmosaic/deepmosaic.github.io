{% include docs-h2.html kicker="Web app" title="Introduction" %}

The Web app is a version of Deepmosaic that you use in your browser with no installation. Everything from loading a video through AI detection, editing the detection results, and exporting a video with mosaic burned in is processed entirely inside the browser on your PC. Video, audio, frame images, and detection results are never sent to a server. The only communication is for signing in and checking your plan, downloading the AI models, recording usage (records of screen navigation and actions, and figures such as processing time and the format and length of videos), and reporting errors ({% include ja-link.html href="/company/privacy" label="Privacy Policy" %}).

The Web app is for trials. It can process videos up to {{ site.data.site.web_app.trial_minutes }} minutes each. For longer videos, a large number of videos, or videos over 1.9GB, use the Desktop app (Video length). Accounts on paid plans and organization (Enterprise) accounts don't have this length limit.

Your account, plan, and free allowance hours are shared with the Desktop app. The detection targets (body areas / male faces / female faces) and the features of the edit page are also the same, so for details on each operation, see the Desktop app guide. This page covers the requirements and differences specific to the Web app.

You can open the Web app at app.deepmosaic.co.jp.

{% include docs-h2.html kicker="Web app" title="Supported browsers and requirements" %}

When the Web app starts, it checks your browser's features and shows guidance if anything is missing. If a required feature is missing, you can't use the Web app. If a recommended feature is missing, you can continue in "slow mode".

Browser (required)
A browser that supports WebCodecs: Google Chrome / Microsoft Edge 119 or later, or Safari 17 or later. We recommend the latest version of Chrome or Edge. Firefox is not among the browsers we test, and detection of long videos may fail partway through
In-browser storage (required)
Copies of your videos and the models are saved in the browser (OPFS). Not available in an incognito window (the name of this window differs by browser)
HTTPS (required)
Open the app from a URL that starts with https:// (normally this is already the case)
WebGPU (recommended)
Runs AI detection on the GPU. Starting with 2.6.5, in environments that support WebGPU, detection is about 2.5 times faster than before, and mosaic refinement takes about 20% less time. Without WebGPU, the app runs on the CPU (WebAssembly), but it takes several times to more than ten times as long. WebGPU is normally enabled in Chrome / Edge
Video size
Up to about 1.9GB per video. For a larger video, "This video (N GB) exceeds the limit the browser version can handle (about 1.9 GB). Use the desktop app." appears (N is the size of the video)
Video length
On the Free plan, up to {{ site.data.site.web_app.trial_minutes }} minutes per video (judged by the full length of the video). For a longer video, guidance about the Desktop app appears before detection starts, and the video is not processed. Accounts on paid plans and organization (Enterprise) accounts have no limit
Video format
mp4 / mov / m4v (with a codec the browser can play, usually H.264). For MKV / WebM / AVI / WMV / FLV / TS / MPEG, a message with the name of the format appears, such as "This format (MKV) isn't supported in the browser version. Convert it to mp4 (H.264), or use the desktop app."
Memory
Long and high-resolution videos use a lot of memory. We recommend closing other tabs and heavy apps before you start processing
{% include docs-h2.html kicker="Web app" title="Getting started" %}
  1. Sign in. You must sign in to use the Web app. Open it from "Try it in your browser" on this website's home page, and the sign-in screen appears. Press "Sign in" and enter the 6-digit confirmation code sent to your email (no password is needed; if you're new, a free account is created automatically). If you previously signed in with a password, enter a confirmation code for the same email address, and you sign in to the same account as before. Starting with 2.13, the sign-in screen has two entry points, the same as the Desktop app: "Sign in" and "Have an organization code? (business)" (Sign-in and license)
  2. Get the models the first time. The AI models are downloaded into the browser (the progress is shown). After that, the app uses the models already in the browser
  3. Load a video. Drag and drop it onto the screen, or select it from "File" in the menu. The video is copied into the browser and appears as a project on the home screen. The first time you load a video, a screen asks you to confirm that you agree to the End User License Agreement and the Terms of Service (if you don't agree, loading is canceled). Your agreement is recorded per browser, so you are asked again in a different browser
  4. Set the detection options and start. The detection range, detection targets, pixel size settings, and batch run are the same as in the Desktop app (Detection options). Detection runs in a floating window, and you can do other things in the meantime
  5. Edit and export. The features and shortcuts of the edit page are the same as in the Desktop app (Edit page). For exporting, see Exporting and downloading

The first time you use the person gallery, a screen asks you to confirm an additional download of the face identification model (about 249MB). An estimated time based on your connection speed is shown, and if you stop partway, you can resume from where you left off.

{% include docs-h2.html kicker="Web app" title="Differences from the Desktop app" %}
Detection
Nearly the same (the 3 detection targets and "Mosaic" (mosaic already in the footage), the detection range, pixel size settings (fixed / by size range / proportional by split count), batch run, and automatic scene detection). In the Web app, "Mosaic" can be used together with body areas and faces (in the Desktop app they are mutually exclusive, and turning on "Mosaic" detects only mosaic boxes; see Existing mosaic). Starting with 2.6.1, mosaic refinement is also available in the Web app (with a GPU and browser that support WebGPU shader-f16; a refinement model of about 175 MB is downloaded in addition as a related file). In environments that don't support it, mosaic is applied in rectangular boxes. As a guide, processing speed is less than half that of the Desktop app. Automatic smoothing of detected box motion (trajectory) (AI detection) is available only in the Desktop app and is not part of detection in the Web app. "Import without detection" (importing a video into the edit page without detection; it doesn't use detection time; the Free plan's limit of {{ site.data.site.web_app.trial_minutes }} minutes per video applies, the same as for detection) is also available
Edit page
The same (editing and drawing boxes, adding 1f / ∞ boxes and exclusion masks, the eraser with E+right-drag and its erase mode, shape, and size, carrying shapes over (Shift+→ / Shift+wheel up, and locking by pressing Shift twice), keyframes for ∞ continuous BBoxes (F), placing points and connecting them by tracking (Y / Shift+Y) and the tracking queue, copying and pasting boxes (Ctrl+C / Ctrl+V), showing and filtering labels, the dotted line showing the edge feather range of the selected box, selecting and bending a range of polygon points with Shift+left-drag, "Invert (apply outside)" in the right-click menu, changing existing boxes into exclusion masks ("Make exclusion mask" in the right-click menu and changing a whole class at once on the By class tab), merging IDs ("Merge IDs…" in a box's right-click menu and right-clicking an ID row in the timeline, merging continuous BBoxes, and unmerging), the preview margin and mosaic that extends outside the video, the 5 tabs of the mosaic settings (including "By time"), setting priority (the setting changed last takes priority), and carrying settings over, blur strength, scenes, the person gallery, zoom, shortcuts, "Settings" in the sidebar (moving it by dragging and the setting for showing chips), and timeline editing). "Regroup people" in the person gallery is available only in the Desktop app. Tracking (X) is also available, but tracking in the Web app is "Standard tracking" only ("High-accuracy tracking", which uses the GPU, is available only in the Desktop app). In the Web app, the tracking queue does tracking only and doesn't refine contours (in the Desktop app, contour refinement also runs after tracking on PCs with a GPU). Minimizing the sidebar (Ctrl+Shift+B) conflicts with the browser's shortcut for showing or hiding the bookmarks bar, so if it doesn't work, use the sidebar's minimize button. For differences in timeline editing, see Timeline editing
Organizing projects on the home screen
The same (folders and tags, and the "Other folders" row). Folders and tags are saved in the browser (Organizing projects on the home screen)
Export formats
3 formats: MP4 (H.264) / WebM (VP9) / WebM (AV1). H.265, ProRes, DV, DNxHR, CineForm, MKV, and AVI are available only in the Desktop app. If you select a format the browser doesn't support, it switches to MP4 (H.264)
Resolution / frame rate / bitrate
The same 7 resolutions. The frame rate is "Same as source video" only (it can't be converted). With the bitrate set to "Auto", the bitrate is determined by the resolution
Timecode
The same (burning timecode into the video, and settings for text size, position, color, and display format). Recording timecode in the file is available only in the Desktop app
GPU encoding
If the browser supports it, you can select it as "GPU encoding" (there is no NVIDIA driver requirement)
Save location
Specify it in the browser's save dialog, or save to the browser first and then download (Exporting and downloading)
Premiere Pro integration
Not available (Desktop app only)
Exporting and importing projects
Exporting and importing zip files is not yet available in the Web app (it is in preparation). Instead, you can save the detection results and edit data with "Download detection data" (Exporting and downloading)
Resuming interrupted detection
Not available (Desktop app only). In the Web app, a detection that stopped partway starts over from the beginning. The "Interrupted detections" and "Unused project folders" notices on the home screen are also Desktop app only
Organization management (Enterprise)
The same (invites and permissions, number of accounts, invoices, and usage). For how to join, see Organization management
Updates
There are no automatic update notifications. Reloading the page always gives you the latest version
Running at the same time
Up to 1 detection and 1 export per account (detection and export can run at the same time). Jobs running in the Desktop app also count toward this limit
Offline
Checking your sign-in requires a connection, so when you're offline, the Web app shows "Can't connect to the server" and can't be used. The Desktop app can detect, edit, and export offline after setup
Video length
Because the Web app is for trials, on the Free plan it processes only videos up to {{ site.data.site.web_app.trial_minutes }} minutes each (no limit for accounts on paid plans and organization accounts). The Desktop app has no limit on the length of a video (the free allowance hours are shared). For long videos or a large number of videos, use the Desktop app
{% include docs-h2.html kicker="Web app" title="Organizing projects on the home screen" %}

In the left sidebar of the home screen, you can organize projects with folders and tags. It works the same as in the Desktop app (Loading videos).

  • Folders: Create a folder with "New folder" at the top of the list. You can also create subfolders from a folder's menu. To move a video, use "Move to folder" in the video card's menu (which also opens with a right-click), or drag the card onto a folder in the sidebar. Drop it on "All videos" to remove it from its folder
  • Tags: Add and remove tags in the tag field of the video card's menu. Select a tag under "Filter by tag" in the sidebar to show only the videos with that tag
  • "Other folders": Projects outside the current project folder are grouped in the "Other folders" row in the sidebar (the row isn't shown when there are none). Folders and tags can't be used for these projects, so to organize one, select "Switch to this project folder" in the video card's menu
Where folders and tags are saved
Folders and tags are saved in the project folder in the browser. They are not shared with the Desktop app (or with other browsers / PCs)
Multiple tabs
If you change folders or tags in several tabs of the same browser at the same time, the content of the tab that saved last is kept. Change them in one tab only
Video card menu
"Open project folder", "Premiere Pro", and "Copy project" are not available. Instead, the Web app has "Download detection data" (Exporting and downloading)
{% include docs-h2.html kicker="Web app" title="Timeline editing" %}

Timeline editing on the edit page works the same way as in the Desktop app. Add media and effects from the left sidebar (Media / Text / Watermark / Audio / Fade / Transition), and edit clips (trim, split, reorder, and delete them), gaps between clips, text, and audio (background music). Your edits are reflected in the export as they are (Edit page).

Importing media
Import video, audio, and image media by selecting them from "Import media" in the media panel, or by dragging and dropping files onto the edit page. Media is saved in the project in the browser, and the preview loads it from a temporary URL inside the browser (a Blob URL). Until the media finishes loading, such as right after you open the page, that part of the preview may appear black
Gaps
Gaps placed between clips are exported as a black screen with no sound (the same result as in the Desktop app). Background music keeps playing across gaps
Text, watermark, fade, and transition
The same. On export, the browser burns them into the video. The longer the transition, the more memory is used during export
Audio
The audio of the original video is mixed with audio tracks such as background music and exported (AAC for MP4, Opus for WebM). The audio of imported video clips is not included in the export (the same as in the Desktop app)
Image clips
The same. Image media can be placed on the timeline as clips of any length and are included in the export at that length. In exports from the Web app, the transparent parts of transparent PNGs become black

Mosaic is applied to the sections of the original video that AI detected. Imported media is not a target of detection.

{% include docs-h2.html kicker="Web app" title="Run window and queue" %}

The progress of detection and export and the queue appear in a floating window that sits on top of the screen. You can drag its header to move it. When you minimize it, it stays as a small chip in the bottom-right corner of the screen, and you can click the chip to bring it back. While it is shown, you can keep working on the home screen and the edit page.

Use "Queue" in the menu bar to check and manage the waiting list of detections and exports (reordering, pausing, and canceling work the same as in the Desktop app's Queue). If another tab or the Desktop app is running a job with the same account, a confirmation asking whether to take it over appears when you start a new job.

{% include docs-h2.html kicker="Web app" title="Exporting and downloading" %}
Save with the save dialog
In Chrome / Edge, when an export starts, you specify the file to save to in the browser's save dialog, and the video is exported directly to it
Save in the browser and download
In browsers that don't support the save dialog, the video is first exported to the project in the browser. When it finishes, press "Download" in the export progress window (or in the queue row) to save it as a file
Download detection data
Saves the project's detection results and edit data as a JSON file (as a copy or backup). Media files imported in timeline editing are not included
{% include docs-h2.html kicker="Web app" title="Data storage and automatic deletion" %}

Copies of the videos you load, detection results, edit data, media imported in timeline editing, how projects are organized on the home screen (folders and tags), videos exported to the browser, and AI models are all saved in the browser's storage for this site. They are not saved on a server.

AI models
Models that haven't been used for 7 days are deleted automatically (they are downloaded again the next time you run detection)
Projects
Not deleted automatically. Delete them from the home screen when you no longer need them. If the browser runs out of space, loading fails
Deleting browser data
If you delete the site data in your browser settings, all projects and models are erased. Download anything you want to keep first
Other browsers / PCs
Storage is separate for each browser. To continue working in a different environment, download the exported videos and detection data and move them over

The first time you load a video, the browser may ask for permission for "persistent storage". If you allow it, the browser is less likely to delete the data automatically when it runs low on space.

{% include docs-h2.html kicker="Web app" title="Troubleshooting" %}
  • If "Open this page from a URL that starts with https://." appears: Change the URL in the address bar to https://app.deepmosaic.co.jp/.
  • If a message says your browser is missing features: Update Chrome / Edge to the latest version. Storage can't be used in an incognito window (the name differs by browser), so open the app in a normal window.
  • If "Can't connect to the server" appears: Check your network connection and press "Retry".
  • If detection is extremely slow: WebGPU may be disabled. Update your browser to the latest version and update your graphics driver. Closing other tabs and heavy apps also helps.
  • If you can't load a video: For videos over about 1.9GB, use the Desktop app. For formats other than mp4 / mov / m4v, convert the video to mp4 (H.264), or use the Desktop app.
  • If the save dialog for export doesn't appear: The video is saved in the browser. When the export finishes, press "Download" in the export progress window or in the queue.
  • If the problem isn't solved: Contact us through "Contact us" in the profile menu, and include your browser type and version.
