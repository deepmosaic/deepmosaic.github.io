{% include docs-h2.html kicker="読み込みと検出" title="動画の読み込み" %}

読み込みには3つの方法があります。どの方法でも、読み込むと続けて検出オプション画面が開きます。

動画ファイルを選択
メニューの「ファイル」から。ダイアログで動画を1本選びます
動画フォルダを選択
フォルダ内の動画をまとめて読み込みます。対象は選んだフォルダの直下のみ（サブフォルダは含みません）で、ファイル名の昇順に最大100件まで。100件を超える場合は先頭100件のみ読み込み、その旨が通知されます
ドラッグ&ドロップ
ホーム画面に動画ファイルを直接ドロップします。複数同時にドロップでき、動画以外のファイルは自動的に無視されます

サンプル以外の動画をまだ 1 本も読み込んでいないときは、一覧の下に「動画を追加して始めましょう」の枠が表示されます。動画ファイルをドラッグ&ドロップするか、「動画を選択」から選んでください（メニューの「動画ファイルを選択」と同じです）。

対応形式：mp4 / avi / mkv / mov / wmv / flv / webm / ts / m2ts / m4v / mpg / mpeg（拡張子の大文字・小文字は問いません）。フォルダから読み込む際は、拡張子が一致しても映像として読めないファイルは除外され、除外件数が通知されます。

複数をまとめて読み込んだときは、1本目が検出オプション画面に表示されます。「開始」を押すとその設定が残り全部に適用され、順番に処理されます。ただし検出範囲の指定だけは1本目のみ有効で、2本目以降は動画全体が対象になります。すでに検出処理が動いているときに読み込んだ場合も待ち行列に加わり、実行中の処理が終わり次第、自動で始まります（キュー）。

プロジェクトフォルダ

読み込んだ動画は「プロジェクト」として管理され、検出結果・編集データ・サムネイルは動画ごとのプロジェクトフォルダに保存されます。プロジェクトフォルダの置き場所は初期状態で C:\Users\（ユーザー名）\deepmosaic です（無ければ自動で作成）。メニューの「ファイル ▸ プロジェクトフォルダを選択」で別の場所（外付けドライブなど）に変更でき、変更後に読み込んだ動画は新しい場所に保存されます。

ホーム画面の「すべての動画」には、現在のプロジェクトフォルダにある、ログイン中のアカウントで作成したプロジェクトが並びます。別のプロジェクトフォルダに保存されたプロジェクトがある場合は、左のサイドバーに「他のフォルダ」の行が件数つきで表示され（0 件のときは表示されません）、選ぶと同じ一覧で確認できます。

「他のフォルダ」の動画は別のプロジェクトフォルダの動画のため、フォルダとタグは使えません（サイドバーのフォルダへのドラッグもできません）。分類したい場合は、動画カードのメニュー（右クリックでも開きます）から「このプロジェクトフォルダに切り替える」を選ぶと、その動画が保存されているフォルダが現在のプロジェクトフォルダになります。

サンプルプロジェクト

無料プラン（未ログインを含む）でホーム画面に動画が 1 本も無いときは、サンプルの動画が自動で追加され、「サンプル」バッジ付きのカードとして並びます（「サンプルの動画を追加しました」と表示されます）。サンプルは顔だけを検出した結果で、編集や書き出しをそのまま試せます。編集ページには「このサンプルは顔の検出です。局部の検出はご自身の動画でお試しください」と表示されます。サンプルを再検出しても検出可能時間は減りません。削除すると再び追加されることはありません。有料プランでは追加されません。

基本の使い方のカード

無料プランでは「すべての動画」の先頭に「基本の使い方 (3 分)」のカードが表示されます（大アイコン表示では一覧の最初のマスに入り、サンプルなどの動画はその右に並びます）。クリックするとアプリ内で動画が再生されます（Esc で閉じます）。カードの「表示しない」で非表示にでき、その後は画面右下のアイコンから再生できます（押した直後にアイコンが光って場所を知らせます）。有料プランではカードは表示されません。

表示形式

一覧の右上で表示形式を3つから選べます。選んだ表示形式は次回以降も引き継がれます。

大アイコン
サムネイルを大きく並べる初期表示。内容を絵で見分けたいときに向きます
並べて表示
1件ずつ横長の行にして、状態・解像度・ファイルサイズ・追加日を添えます
詳細
表形式。名前・状態・追加日・長さ・解像度・検出数・タグが列に並び、列見出しをクリックすると並べ替えられます（プロジェクト ID はカードのメニューの「プロジェクトIDをコピー」で取得できます）

動画カードの操作

カードをクリックすると編集ページが開きます。カード右上の {% include icon.html name="Menu" class="inline h-3.5 w-3.5 align-[-2px]" %} メニューには次の項目があります。

編集画面を開く
編集ページを開きます
プロジェクトIDをコピー
お問い合わせなどで使うプロジェクト ID をクリップボードにコピーします
名前を変更
一覧と編集ページに表示する名前を変えます（元の動画のファイル名は変わらず、ファイルも移動しません）
プロジェクトフォルダを開く
この動画のプロジェクトフォルダをエクスプローラーで開きます
PremiereProにインポート
検出結果を Adobe Premiere Pro に送ります（Premiere Pro 連携）
プロジェクトをエクスポート
プロジェクトを 1 つの zip にまとめます（プロジェクトの書き出しと取り込み）
プロジェクトをコピー
検出結果・編集データ・タイムライン素材を含めて複製し、新しいプロジェクト ID を付けます。元動画がプロジェクト外にある場合は同じファイルを参照します（コピーされません）
削除
プロジェクトフォルダごと削除します（確認あり・取り消し不可）。エンコード中のプロジェクトを削除すると、そのエンコードも中止されます。ほかのアプリが使用中で消せなかったフォルダは「N 件のフォルダは使用中のため、次回起動時に削除します」と表示され、次回起動時に削除されます
フォルダへ移動・タグ
サイドバーのフォルダへ移動したり、タグを付け外ししたりできます（「他のフォルダ」の動画では使えません）

まとめて削除するには、一覧上部の「選択モード」を押してカードをクリックで選び（「すべて選択」も可）、「選択を削除」を押します。確認ダイアログの後、選んだプロジェクトがフォルダごと削除されます。

ホーム画面のお知らせ

ホーム画面の一覧の上に、必要なときだけ次のお知らせが表示されます。

  • 「検出結果を新しい保存形式に変換しています (n / N)」: 以前のバージョンで検出したプロジェクトを新しい保存形式（project.db）に変換しています。失敗すると「変換に失敗したプロジェクトが N 件あります」と表示されるので「再試行」を押してください
  • 「使われていないプロジェクトフォルダ N 件 (X GB)」: 検出を中止・失敗したときに残ったフォルダです（ホームには表示されていません）。「一覧を見る」を押すと、検出結果の無いフォルダにだけチェックが入った状態で一覧が開きます（検出結果のあるフォルダは、登録が失われた完了済みのプロジェクトのことがあるので、必要なものだけ自分で選んでください）。「すべてにチェックを入れる」で検出結果のあるフォルダも含めて全件を選び、「すべてのチェックを外す」で選択をすべて外せます。チェックしたフォルダが「削除」で削除されます（「キャンセル」では何も削除しません）。「閉じる」で隠せます
  • 「このプロジェクトは前回の起動で問題を起こしました」: 前回の起動中にアプリが落ちた、またはデータが壊れていたプロジェクトは、開かずに分けてあります。「検査」で問題が無ければ元に戻り、「修復」で直前の保存内容からの復元を試みます
{% include docs-h2.html kicker="読み込みと検出" title="検出オプション" %}

動画を読み込むと検出オプション画面が開きます。ここで「動画のどの区間を」「何を対象に」検出するかを決めて「開始」を押します。

プレビュー
いま指定しているフレームの静止画です。スライダーや数値入力を動かすと、その位置の画が表示されるので、範囲の当たりをつけられます
検出範囲
初期値は動画全体です。スライダーの両端か「開始」「終了」の数値入力でフレーム単位に指定できます。見出しには 00:00:00 (#0) ~ 00:00:10 (#300) のように時刻とフレーム番号が並びます
範囲を追加
離れた複数の区間を指定できます。重なった範囲や連続した範囲は自動で1つにまとめられ、開始と終了が逆でも入れ替えて解釈されます。2つ以上あるときは {% include icon.html name="Trash2" class="inline h-3.5 w-3.5 align-[-2px]" %} で個別に削除でき、すべて削除すると動画全体に戻ります
所要時間の目安
検出範囲の下に「所要時間の目安: 約 N 分（高精度モデル / この PC の実測 N fps）」が表示されます。この PC の動作確認と過去の検出の実測から計算します。実測がまだ無いときは「所要時間の目安は、動作確認または初回の検出が終わると表示されます」、長くかかりそうなときは「長くなりそうです — 検出範囲を絞ると短縮できます」と表示されます。GPU が無い PC では CPU で処理するため、実時間の 10 倍以上かかることがあります。検出可能時間に上限があるプランでは「時間枠は動画全体の長さで消費されます (範囲指定でも同じ)」も併記されます
検出対象
「局部」「男性の顔」「女性の顔」から選びます（初期値は3つともON）。ここでの選択は保存され、次回以降の読み込みでも引き継がれます
ピクセルサイズ自動
モザイクの粒の大きさを対象物のサイズに連動させます（初期値ON）。大きく映るカットでは粒を大きく、小さく映るカットでは細かく自動調整し、カット内・同一の対象内では粒度を一定に保ちます。ON のときはその下の「細かさ（対象物の分割数）」（8〜64、初期値 16）で粒の基準を決めます。対象物の代表サイズをこの数で割った値が粒の 1 辺になるので、大きいほど細かくなります。ここで決めた値は新しい検出の初期値で、検出後に編集ページのモザイク設定からいつでも変更できます
検出後の処理
「検出後そのままエンコードまで一括実行する」を ON にすると、検出の完了後に確認なしで書き出しまで進みます（一括実行）
GPU表示（右上）
検出に使うGPU名です。CUDA対応GPUが認識され、ログインしていれば高精度モデル、それ以外は軽量モデルが自動で選ばれます（手動選択はありません）。GPU 機でも、高精度モデルの取得中は「高精度モデルを準備中 — 今回は軽量モデルで検出します」、未ログインのときは「高精度モデルの利用にはログインが必要です — 今回は軽量モデルで検出します」（「ログイン」ボタンつき）と「開始」の上に表示され、その回は軽量モデルで検出します
モデルの確認
画面を開くとモデルファイルの有無を確認し、不足していれば自動でダウンロードします。確認が終わるまで「開始」は押せません。失敗したときは「再試行」で取り直します
モザイクの精緻化
検出した枠の中で物体の形に沿った輪郭を AI が作り、四角い枠ではなくその形にモザイクをかけます。CUDA 対応の NVIDIA GPU がある環境では標準で有効で、ON / OFF の設定はありません。離れた部位は別々の輪郭になり、編集ページではその形のまま扱えます（四角に戻したいときは編集ページの右クリック「形を変更」）。所要時間は長くなります（GPU 機で動画 1 分あたり約 +107 秒の目安）。CUDA 対応の NVIDIA GPU が無い環境では使えません。その場合は「GPUが利用できない場合は、物体の形状に合わせた検出機能が利用できません」と表示され、四角い枠でモザイクをかけます

検出にかかる時間は処理するフレーム数にほぼ比例します。長尺動画のうち一部だけを処理したい場合は、検出範囲を絞ると待ち時間を短縮できます。なお、検出可能時間（利用枠）は範囲を絞った場合も動画全体の長さで数えます。同じ動画をもう一度検出しても重ねては数えません。

残りの検出可能時間が動画の全長より少ない場合も、検出は開始前に止まります。「開始」ボタンの上に「残り検出可能時間 (1時間30分) では 120分の動画を検出できません。プランをご確認ください」のように表示され、「開始」は押せません。検出範囲を絞っても動画全体の長さで数えるため、範囲の指定では開始できません。残り時間はフッターで確認できます（使用時間の計測）。

ライセンスの期限切れや使用量の上限超過があると、この画面でプラン変更を促すダイアログが表示され、検出を開始できません（プランの変更を参照）。

{% include docs-h2.html kicker="読み込みと検出" title="検出からエンコードまで一括実行" %}

検出オプションの「検出後そのままエンコードまで一括実行する」を ON にして「開始」を押すと、検出の完了後に編集ページを開くことなく、モザイクを焼き込んだ動画の書き出しまで自動で進みます。複数の動画をまとめて読み込んだときは全件に適用されます。

  1. 「開始」を押すと「一括処理の前にご確認ください」が表示されます。自動検出は 100% ではないこと（対象が小さい・速く動く・一部しか映っていない、暗所・逆光・強いボケ、学習データと傾向が異なるアングルなどでは検出されないことがある）を確認し、「理解しました。一括実行する」を押します
  2. 続けてエンコード設定が開きます。保存先フォルダを選ぶと、ファイル名は元動画名から自動で付き、同名のファイルがある場合は末尾に _2, _3 … が付きます。「開始」で検出が始まります
  3. 検出が完了すると、そのままエンコードがキューに入り順に書き出されます。進捗はメニューバーの「キュー」から確認できます

一括実行では編集ページで結果を確認する工程を省くため、出力した動画を公開・配布する前に、必ずご自身で全編をご確認ください。モザイクの初期設定は「ピクセルサイズ自動」と、モザイク設定パネルで「この設定を既定にする」を押した内容が使われます。

{% include docs-h2.html kicker="読み込みと検出" title="AI検出" %}

検出オプションで「開始」を押すと、AIが動画内の対象物体を自動検出します。処理は「準備 → 前処理 → 検出 → 解析 → モザイクの精緻化」の 5 段階（モザイクの精緻化を使わないときは 4 段階）で進み、全体進捗・処理速度（fps）・残り時間が表示されます。使う段は開始した時点から全部表示されます。処理の一時停止・再開・キャンセルができます。複数の動画を読み込んだ場合の待ち行列は、メニューバーの「キュー」で確認できます。

進捗の見方
上部のステップ表示は、完了した段が全面、実行中の段は進み具合のところまで色が付きます。進捗バーは検出全体の割合です。その下に現在のステップ名、処理中のフレーム数、速度（fps）、「経過」（検出を始めてからの時間）、「〇〇の残り」（そのステップの残り時間の目安）、「全体の残り」が並びます。残り時間が出ないステップもあります。「モザイクの精緻化」の段は、対象の枠があるフレームだけを数えて「n / N 対象フレーム」と表示し、全体の進捗もこの段に多くの割合を割り当てて、実際の所要時間に近い速さで進みます
一時停止 / 再開
処理を一時停止します。再開すると続きから処理します
キャンセル
「検出を中止しますか？」の確認後に中止します。進行状況は失われ、その検出のために作られたプロジェクトフォルダも削除されます（後から再開はできません。途中で止めて後で続けたいときは「一時停止」を使ってください）。待機中の動画があるときは「この動画のみ中止」（次の動画へ進む）と「すべて中止」を選べます
バックグラウンドで実行
画面を閉じてホーム画面に戻ります。検出はそのまま続き、進捗はメニューバーの「キュー」で確認できます。画面右上の「_」（縮小）を押した場合は、画面右下に小さな進捗表示（ミニプレイヤー）が残り、クリックで検出画面に戻れます。ミニプレイヤーからも一時停止とキャンセルができます
完了
「処理が完了しました」と表示され、ホーム画面にカードが追加されます。「ホームに戻る」で一覧へ戻ります。ログイン済みの無料プランでは「残り … · プランを見る」も表示されます。一括実行のときは「検出が完了しました」と表示され、エンコードがキューに入ります（「エンコードの進捗を見る」で確認できます）
ログ
画面の右側に検出のログが表示されます（初期状態は折りたたみ）。レベル・ステップ・文字で絞り込めるほか、「表示中の行をコピー」「ログフォルダを開く」が使えます。更新が止まると「N 秒間 応答がありません」と表示されます。完了後やエラーのときは「ステップ別の所要時間」の表が表示されます。不具合のお問い合わせでは、このログを添えていただくと調査が早く進みます

中断した検出の再開と破棄

アプリの終了や PC の停止などで途中で止まった検出は、次回起動時にホーム画面の「すべての動画」の上に「中断した検出」として並び、左のサイドバーにも件数つきの「中断した検出」の行が表示されます。カードには「中断 (DETECT 42 %)」のように止まった段と進み具合が出ます。「再開」を押すと、はじめからではなく止まった位置の近くから検出を続けます。「破棄」を押すと確認の後、検出の途中経過とプロキシ動画を削除します（元の動画は削除しません）。元の動画が見つからない・変わった、編集済み、新しい版のアプリで作られた などの理由で再開できないときは、カードに理由が表示され「再開」は押せません（「エンジンを更新すると再開できます」と出たときはアップデートを適用してください）。

処理中はステップごとの進み具合と所要時間の目安が表示されます。

{% include docs-h2.html kicker="読み込みと検出" title="キュー（検出とエンコードの待ち行列）" %}

検出とエンコードは 1 つの待ち行列（キュー）で管理され、メニューバーの「キュー」から確認・操作できます。ボタンのバッジは実行中と待機中のジョブの合計数です。検出は同時に 1 本ずつ、エンコードも同時に 1 本ずつ処理され、完了すると次のジョブが自動で始まります。

検出（実行中）
ステップ、全体の進捗、速度、残り時間、フレーム数を表示します。「詳細を開く」で検出画面へ、一時停止 / 再開、キャンセルもここから行えます
検出（待機中）
ドラッグ、または「上へ移動」「下へ移動」で順番を入れ替えられます。「キューから削除」で取りやめます
エンコード
実行中の行には速度・残り時間・フレーム数が出ます。並べ替え、「進捗を別ウィンドウで開く」、一時停止 / 再開、キャンセル、完了したジョブの削除ができます（進捗ウィンドウ）
Web 版との同時利用
同じアカウントでWeb 版が処理を実行中のときは「Web 版で処理を実行中のため、新しいジョブは完了を待ってから開始されます」と表示され、Desktop 側のジョブは待機します

ウィンドウを閉じてもキューは残ります。アプリを終了すると実行中の検出は中断され、次回起動時にホーム画面の「中断した検出」から再開できます（AI検出）。キューに残ったエンコードは次回起動時に再開できません（改めて編集ページから開始してください）。
