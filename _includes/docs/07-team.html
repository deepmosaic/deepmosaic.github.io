Enterprise プランでは、1 つの契約を複数のアカウントで共有します。メンバーの追加・削除、アカウント数の変更、請求書の確認、チーム全体の利用量の確認は、アプリ内の「チームの管理」から行います。

「チームの管理」は Enterprise のアカウントにのみ表示されます。プロフィールメニュー（右上）を開くと、Free / Light / Pro では「プランを変更する」「プラン管理」が並ぶ位置に「チームの管理」が表示されます。料金と込み時間は料金ページをご覧ください（最低 {{ ent.min_seats }} アカウントから）。

「チームの管理」を選ぶとダイアログが開き、左側に 権限 / 請求 / 利用量 の 3 つが並びます。右側に選んだ内容が表示されます。「準備中」と表示される場合は、時間をおいてから開き直してください。

権限（オーナーとメンバー）

チームのメンバーには「オーナー」と「メンバー」の 2 つの権限があります。

オーナー
メンバーの招待・再送・取り消し、メンバーの削除と権限の変更、アカウント数の変更、請求書の閲覧、組織コードの確認と再発行ができます
メンバー
メンバーの一覧とチームの利用量を閲覧できます。招待や請求に関する操作はできません
請求名義人
お申し込みをされたオーナーです。一覧に「請求」と表示され、削除やメンバーへの変更はできません。オーナーが 1 人だけのときも、そのオーナーを削除・変更することはできません

メンバーの一覧には、権限・メールアドレス・参加日・最終ログインが並びます。最終ログインが取得できない場合は空欄になります。権限の変更と削除は、一覧の各行から行います。

メンバーを招待する

  1. 「権限」でメールアドレスを入力し、権限（オーナー / メンバー）を選んで「招待」を押します
  2. 相手に招待メールが届きます。メールのリンクから登録（またはログイン）すると、チームに参加した状態でアプリを使い始められます
  3. まだ参加していない招待は一覧に残ります。「再送」で招待メールを送り直し、「取り消し」で無効にできます
招待も 1 アカウント分
アカウント数は「参加済みのメンバー ＋ 未参加の招待」で数えます。空きが無いと招待できないので、不要な招待を取り消すか、「請求」でアカウント数を増やしてください
再送の間隔
短い間隔で続けて送ることはできません。1 分ほど空けてからもう一度お試しください
招待の期限
期限を過ぎた招待は期限切れとして一覧に残ります。「再送」を押すと期限が延長され、同じメールアドレスのまま招待し直せます
届かないとき
迷惑メールフォルダをご確認のうえ、アドレスに誤りがなければ「再送」をお試しください。それでも届かない場合は、次の「組織コードで参加する」をご利用いただけます

組織コードで参加する

招待メールを使わずに、チーム共通の「組織コード」で参加することもできます。人数が多いときや、社内で配布して各自に登録してもらいたいときに使います。

  1. オーナーが「権限」で組織コードを確認します（ABCD-1234-EFGH のように 4 文字ずつ区切って表示されます）。組織コードはオーナーにだけ表示されます
  2. 参加する方は、ログインダイアログの「組織コード」欄にそのコードを入力してからログインします。ブラウザでの認証が終わると、チームに参加した状態でアプリに戻ります
  3. コードを配り直したいときは、「権限」から組織コードを再発行します。再発行すると、それまでのコードは使えなくなります

組織コードが違う場合やアカウント数が足りない場合でも、ログイン自体は成功し、チームへの参加だけが行われません。プロフィールメニューに「チームの管理」が出てこないときは、コードと空きアカウント数をオーナーにご確認ください。組織コードを知っていれば誰でも参加できるため、社外に転送しないようご注意ください。

請求（アカウント数・請求書）

「請求」はオーナーのみが開けます。

アカウント数の変更
アカウント数を入力して保存すると、決済に反映され、当期のプール（下記「利用量」）もすぐに新しいアカウント数で計算し直されます。増減の差額は日割りで次回の請求に載ります
減らせる下限
最低 {{ ent.min_seats }} アカウント、かつ「参加済みのメンバー ＋ 未参加の招待」を下回る数にはできません。先にメンバーの削除や招待の取り消しを行ってください
増やせる上限
上限を超える数を入力すると、そのままでは保存できません。大規模にご利用の場合は導入相談からご連絡ください
請求書の表示 / PDF
請求書の一覧に、請求日・対象期間・金額・支払い状況が並びます。「表示」でブラウザに請求書が開き、「PDF」でファイルとして保存できます
決済ポータル
「請求」からブラウザの決済ポータルを開けます。支払い方法の変更、領収書の確認、解約はこちらで行います（プランの変更と同じポータルです）

請求書払い・銀行振込をご希望の場合は導入相談からご連絡ください。お支払い方法ごとの対応は料金ページに記載しています。

利用量（プールと内訳）

Enterprise の込み時間は、メンバー個人ごとではなくチーム全体で共有するプールです。

  • プールの大きさ: アカウント数 × {{ ent.included_hours }} 時間。アカウント数を変更すると当期のプールもすぐに計算し直されます
  • メンバー別の内訳: 誰がどれだけ消費したかが一覧で表示されます。プールは共有のため、1 人が多く使うと他のメンバーの残りも減ります
  • リセット日: 当期の開始日と終了日が表示されます。終了日を過ぎると次の期間が始まり、消費が 0 に戻ります。使い切らなかった分は翌期に繰り越されません
  • 数え方: 検出が完了した動画の再生時間を加算します。詳細は使用時間の計測をご覧ください

利用量はオーナーとメンバーのどちらからも確認できます。
