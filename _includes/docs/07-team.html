{% include docs-h2.html kicker="組織" title="組織の管理（Enterprise）" %}

Enterprise プランでは、1 つの契約を組織の複数のアカウントで共有します。メンバーの招待・削除、組織コードの確認、組織全体の利用量の確認は、アプリ内の「組織の管理」から行います。請求書はメールでお送りします（アカウント数の変更・解約は導入相談から）。

プロフィールメニューの「組織」は Enterprise の組織に参加しているアカウントにのみ表示されます。プロフィールメニュー（右上）を開くと、Free / Light / Pro では「プランを変更する」「プラン管理」が並ぶ位置に「組織」が表示されます。料金と込み時間は料金ページをご覧ください（{{ ent.min_seats }} アカウントから）。

「組織」を選ぶと「組織の管理」のダイアログが開き、左側に項目が並びます。管理者には 権限 / 請求 / 請求書 / 利用量 の 4 つ、メンバーには 権限 / 利用量 の 2 つが表示され、右側に選んだ内容が表示されます。左上には「管理者として参加中」または「メンバーとして参加中」と表示されます。「準備中」と表示される場合は、時間をおいてから開き直してください。

権限（管理者とメンバー）

組織のメンバーには「管理者」と「メンバー」の 2 つの権限があります。

管理者
メンバーの招待・招待メールの再送・招待の取り消し、メンバーの削除と権限の変更、ご契約の状態の閲覧、組織コードの確認ができます
メンバー
メンバーの一覧と組織の利用量を閲覧できます。招待（招待メールの再送を含む）や請求に関する操作はできません
請求名義人
お申し込みをされた管理者です。一覧に「請求担当」と表示され、削除やメンバーへの変更はできません。管理者が 1 人だけのときも、その管理者を削除・変更することはできません

メンバーの一覧には、名前（またはメールアドレス）・権限・最終ログインの日付が並びます（最終ログインが取得できない場合は参加日を表示します）。一覧の上に「N / M アカウント使用中」と空きの数が表示されます。権限の変更と削除は、一覧の各行から行います。

メンバーを招待する

メンバーの招待と招待メールの再送は、管理者だけが行えます。メンバーの権限では「権限」に招待の欄は表示されず、代わりにその旨の案内が表示されます。新しい方を招待したいときは、組織の管理者にご依頼ください。

  1. 管理者が「権限」で、招待する方のメールアドレスと権限（管理者 / メンバー）を指定して招待します
  2. 相手に招待メールが届きます。招待メールが届いたメールアドレスでログイン（または新規登録）すると、自動で組織に参加した状態でアプリを使い始められます。別のメールアドレスで使う場合は、下記「組織コードで参加する」をご利用ください
  3. まだ参加していない招待は「招待中」の一覧に有効期限（「〇〇 まで有効」）とともに残ります。「再送」で招待メールを送り直し、「取り消す」で無効にできます
招待も 1 アカウント分
アカウント数は「参加済みのメンバー ＋ 未参加の招待」で数えます。空きが無いと招待できないので、不要な招待を取り消すか、導入相談からアカウント数の追加をご連絡ください
再送の間隔
短い間隔で続けて送ることはできません。1 分ほど空けてからもう一度お試しください
招待の期限
期限を過ぎた招待は期限切れとして一覧に残ります。「再送」を押すと期限が延長され、同じメールアドレスのまま招待し直せます
届かないとき
迷惑メールフォルダをご確認のうえ、アドレスに誤りがなければ管理者に「再送」をご依頼ください。それでも届かない場合は、次の「組織コードで参加する」をご利用いただけます

組織コードで参加する

招待メールを使わずに、組織共通の「組織コード」で参加することもできます。人数が多いときや、社内で配布して各自に登録してもらいたいときに使います。組織コードは、ご契約が有効になったときの案内メールでお送りします（下記「導入の流れ」）。

  1. 管理者が「請求」で組織コードを確認します（ABCD-1234-EFGH のように 4 文字ずつ区切って表示され、横のボタンでコピーできます）。組織コードは管理者にだけ表示されます
  2. 参加する方は、ログインダイアログの「組織コードをお持ちの方 (Enterprise)」を開き、「組織コード」欄にそのコードを入力してからログインします。ブラウザでの認証が終わると、組織に参加した状態でアプリに戻ります

参加の入口は、ログインダイアログの「組織コード」欄だけです。ログインした後のメニューからは参加できません。すでにログインしている場合は、いったんログアウトしてから、ログインダイアログの「組織コード」欄に入力してログインし直してください。

組織コードが違う場合やアカウント数が足りない場合でも、ログイン自体は成功し、組織への参加だけが行われません。プロフィールメニューに「組織」が出てこないときは、コードと空きアカウント数を管理者にご確認のうえ、上の手順でログインし直してください。組織コードを知っていれば誰でも参加できるため、社外に転送しないようご注意ください。1 つのアカウントが参加できる組織は 1 つです。すでに別の組織に所属している場合は「すでに別の組織に所属しています。」と表示され、参加できません。

導入の流れ（お見積り・お支払い）

Enterprise はお見積りによるご契約です（{{ ent.min_seats }} アカウントから）。アプリ内から直接お申し込みいただくことはできません。

  1. 導入相談からご連絡ください。ご利用予定のアカウント数とご要望をお伺いします
  2. お見積書をお送りします。会社名・アカウント数・アカウント単価・1 アカウントあたりの検出時間（または無制限）・維持管理費用・月額費用に含まれる範囲・契約形態・支払期日を記載しています。あわせて取引条件書と注文書をお送りします
  3. お見積りの内容でよろしければ、注文書でご注文ください。ご注文を確認のうえ、注文請書をお送りします
  4. ご利用月ごとに、その月の分（1 か月分。日割りはありません）の請求書をお送りします。銀行振込でお支払いください（振込手数料はお客様のご負担です。お支払期日はお見積書と請求書に記載しています）
  5. ご入金を確認できしだいご契約が有効になります。あわせて、組織コードを記した「組織のご利用を開始できます」の案内メールを、お見積りの際にご登録いただいたメールアドレスにお送りします
  6. アプリをインストールし、案内メールが届いたメールアドレスでログインすると、自動で組織の管理者として参加します。他のメンバーの方は、ログインダイアログの「組織コード」欄に案内メールの組織コードを入力してログインすると参加できます（上記「組織コードで参加する」）
  7. 「組織の管理」からメンバーを招待します（上記「メンバーを招待する」）

ご契約の状態（状態・お支払い方法・次回更新）、アカウント数と 1 アカウントあたりの検出時間、組織コードは、アプリ内の「組織の管理」＞「請求」で確認できます。「請求」と「請求書」は管理者のみが開けます。

お支払い方法
当社が発行する請求書による銀行振込です（振込手数料はお客様のご負担です）。振込先は請求書に記載しています
ご請求のサイクル
ご利用月ごとに 1 か月分の請求書を発行します（日割りはありません）。お支払期日はお見積書に記載の日数（標準は発行から 30 日）です。ご入金を確認した月の分だけ、ご利用期間が延長されます。最低利用期間や初期費用はありません
アカウント数の変更
アカウント数の増減は導入相談からご連絡ください。変更後のアカウント数でお見積りし、翌月以降の請求書に反映します（減らせる下限は下記）
減らせる下限
使用中の数未満・1 アカウント未満にはできません（「使用中」はメンバーが使っているアカウント数です。それより減らしたい場合は、先にメンバーを削除してください）
解約
解約・お支払い方法のご相談は導入相談（またはお問い合わせ）からご連絡ください。違約金はありません
お支払いが確認できないとき
お支払いが確認できない状態が続くと、組織全体の Enterprise 機能が停止します（管理者だけでなくメンバー全員が対象です）。ご入金を確認でき次第、再開します

以前にクレジットカードでご契約いただいた組織では、「請求」からアカウント数の変更と決済ポータル（支払い方法の変更・領収書の確認・解約）を、「請求書」から過去のご請求を確認できます。

利用量（プールと内訳）

Enterprise の込み時間は、メンバー個人ごとではなく組織全体で共有するプールです。

  • プールの大きさ: アカウント数 × 1 アカウントあたりの検出時間です。1 アカウントあたりの検出時間はご契約ごとにお見積書で定めます（標準は {{ ent.included_hours }} 時間 / 月）。検出時間が無制限のご契約もあります。管理者は「請求」で「1 アカウントあたりの検出時間: N 時間 / 月 (組織全体で共有)」または「検出時間: 無制限」を確認できます
  • メンバー別の内訳: 誰がどれだけ消費したかが一覧で表示されます。プールは共有のため、1 人が多く使うと他のメンバーの残りも減ります
  • リセット日: 当期の開始日と終了日が表示されます。終了日を過ぎると次の期間が始まり、消費が 0 に戻ります。使い切らなかった分は翌期に繰り越されません
  • 数え方: 検出が完了した動画の再生時間を加算します。詳細は使用時間の計測をご覧ください
  • 表示: 「利用量」に当期の使用時間と上限・残りが表示されます（1 時間未満は分と秒まで）。無制限のご契約では「N 使用 (無制限)」と表示されます。ご契約の手続き前は「当期の枠は未開始です (契約手続き前)」と表示されます

利用量は管理者とメンバーのどちらからも確認できます。
