ホーム画面の動画カードをクリックすると編集ページが開きます。画面は上部の「ヘッダー」、端に縦に並ぶ「サイドバー」（と、その隣に開くドロワー）、中央の「動画プレイヤー（編集ツールバー内蔵）」、下部の「タイムライン」で構成されます。

ヘッダー左
{% include icon.html name="ArrowLeft" class="inline h-3.5 w-3.5 align-[-2px]" %} 戻るボタン、動画タイトル、9桁のプロジェクトIDバッジ（クリックでコピー）
メタ情報
動画の長さ / 総フレーム数 / fps / 解像度 / 追加日
ヘッダー右
フォルダを開く / 人物ギャラリー / Premiere Pro へインポート / マルチウィンドウ / エンコード の各ボタンと保存状態表示。同じプロジェクトを 2 つ以上のウィンドウで開いている間は、「マルチウィンドウ」の右に連動のスイッチも出ます（下の「複数のウィンドウで編集する」）。エンコードの待ち行列はメニューバーの「キュー」で確認します
保存状態
編集は操作の約 1 秒後に自動保存されます。「保存中」「未保存」「保存済」がリアルタイムに表示され、失敗時は「保存失敗」と出ます。エンコードの開始時、編集ページを離れるとき、アプリを閉じるときにも未保存分が保存されます
サイドバー
メディア / テキスト / 透かし / 音声 / フェード / トランジション の 6 項目。押すと隣にドロワーが開き、素材の取り込みやテキスト・BGM などの設定ができます（サイドバーとドロワー）
タイムライン
シーンの帯、テキスト・クリップ・音声のレーン、検出クラスごとの行が並びます。クリップの継ぎ目のはさみを押すと、フェードかつなぎを選べます（プレイヤーとタイムライン / クリップの編集 / フェード）
ツールチップ
ボタンにマウスを乗せると、すぐに（約 0.15 秒で）その機能の説明とショートカットキーがツールチップで表示されます
読み込み中の表示
編集ページを開くと、検出結果がそろうまで「検出結果を読み込んでいます」と進捗が表示され、最初のフレームから枠が載った状態でプレイヤーが表示されます。以前のバージョンで検出したプロジェクトを初めて開いたときは「検出結果を新しい保存形式に変換しています」と表示されます（変換は 1 回だけです）
詳細データがありません
検出結果のファイルが見つからないときに表示されます（プロジェクトフォルダの移動や削除など）。この画面の「プロジェクトを削除」で一覧から取り除けます

複数のウィンドウで編集する

ヘッダーの「マルチウィンドウ」を押すと、同じプロジェクトの編集ページがもう 1 つのウィンドウで開きます（押したウィンドウと同じ再生位置から開きます）。追加したウィンドウでも押せて、開ける数に上限はありません。最初から開いているウィンドウをメインウィンドウと呼びます。

  • どれかのウィンドウで枠・モザイク設定・タイムラインを変えると、操作が確定した時点（マウスを離したときなど、約 0.1 秒後）にほかのウィンドウにも反映されます。ドラッグの途中は反映されません
  • Ctrl+Z（タイムライン編集は Ctrl+Shift+Z）の履歴はすべてのウィンドウで共通です。どのウィンドウで押しても、その履歴の最後の操作（ほかのウィンドウでした操作を含みます）が戻り、すべてのウィンドウに反映されます。後から開いたウィンドウでは、開く前の操作は戻せません
  • 再生位置・ズーム・選択中の枠・プレビュー切替（枠の表示 / モザイク適用プレビュー）・再生速度は、ウィンドウごとに別々です
  • 2 つ以上のウィンドウで開いている間は、「マルチウィンドウ」の右に連動のスイッチ（マウスを乗せると「メインウィンドウと連動」と表示されます）が出ます。スイッチをオンにしたウィンドウどうしは、コマ送り・シーク・ホイールで同じフレームにそろい、Space で再生すると一緒に再生します（音は再生を始めたウィンドウからだけ出ます。再生中は 1〜2 フレームずれることがあり、止めるとそろいます）。スイッチは既定でオフで、オフのウィンドウは動きません。トリムのプレビュー中と追跡モードの間は連動を休みます
  • 2 つのウィンドウの操作がほぼ同時（約 0.1 秒以内）に同じ所にぶつかったときは、後から届いた操作を丸ごと取り消して「別のウィンドウの変更と重なったため、直前の操作を取り消しました」と表示します
  • エンコードは、ほかのウィンドウの直前の編集も含めて書き出します。人物ギャラリーの「人物を再集計」を押すと、ほかのウィンドウは処理が終わるまで操作できなくなり、終わると自動で読み直して元の再生位置に戻ります（どのウィンドウでも Ctrl+Z の履歴は消えます）
  • 追跡は同時に 1 つのウィンドウでだけ動きます。別のウィンドウで追跡を始めると、前のウィンドウの追跡は止まります
  • そのプロジェクトをほかのウィンドウで開いている間は、削除など一部の操作はできません（そのウィンドウを閉じてから行います）
  • 追加したウィンドウにはメニューバーとフッターがありません（アカウント・表示言語・テーマや「キュー」など、メニューバーとプロフィールメニューの操作はメインウィンドウで行います）。追加したウィンドウは × か「戻る」でそのウィンドウだけが閉じます。メインウィンドウでホーム画面に戻っても追加したウィンドウは開いたまま残り、メインウィンドウを閉じるとアプリ全体が終了します（編集は保存されています）。アプリを起動し直しても、追加したウィンドウは開き直しません
{% include docs-h2.html kicker="編集" title="プレイヤーとタイムライン" %}

プレイヤーには検出枠（bbox）がクラス別の色でオーバレイ表示されます。枠はドラッグで位置・サイズを直接編集できます。コマ送り・シークに対応し、下部のタイムラインには検出の分布とシーン（カット）の帯が描画され、クリックで任意のフレームへジャンプできます。

検出クラスは色分けされます: 局部（赤）/ 男性顔（青）/ 女性顔（ピンク）/ ユーザー作成（黄）/ 回避マスク（青緑）/ モザイク（紫、素材にすでにかかっているモザイク。検出オプションの「モザイク」を ON にして検出したプロジェクトだけ）。枠の上のラベル（チップ）には「クラス名 #ID（3 文字のコード） 信頼度%」が表示され、手動で追加した枠は「ユーザー」、回避マスクは「回避」、モザイクの対象から外したトラックには「[モザイク除外]」、モザイク設定で「モザイクを掛ける」をオフにした枠には「[モザイクオフ]」が付きます。チップは既定では表示されません。サイドバーの「設定」の「BBox のラベル (名前・ID・確率) を表示」をオンにすると表示されます（オフでも枠は表示されます。サイドバーとドロワー）。

モザイク（紫）の枠は多角形（最大 255 点）で、ほかの多角形の枠と同じく点を動かして形を直せます（下の「頂点の範囲選択と曲げ」、すでにかかっているモザイクを見つけて、かけ直す）。

再生コントロール

再生 / コマ送り
先頭へ（Home）/ 1 コマ戻る（←）/ 再生・一時停止（Space）/ 1 コマ進む（→）/ 末尾へ（End）。PageUp / PageDown で 10 コマ移動。マウスホイールでもコマ送りでき、Shift+ホイールで 10 コマ移動します。BBox を選択中に Shift+→（または Shift+ホイール上）で進むと、その枠の形を引き継いだまま 1 コマずつ進みます（下の「検出枠の操作」の「形を引き継いでコマ送り」）。ホイールは既定では上に回すと進みます。サイドバーの「設定」の「ホイールを下に回すと進む」をオンにすると、下に回すと進むようになります（Shift の 10 コマ・形の引き継ぎ・追跡モードも同じ向きになり、Ctrl+ホイールのズームは変わりません）。このページの「ホイール上」は既定の向きでの書き方です
シーク
スライダーのドラッグ、タイムラインのクリック / ドラッグ、時刻とフレーム番号（frame N / M）の表示
ミュート（V）
プレビューの音声を消します。書き出しには影響しません
オーバーレイの表示切替（H）
検出枠・ラベル・ID・確率をすべて隠して映像だけを確認します。編集内容は変わりません。編集ページを開いたときは表示されています（サイドバーの「設定」の「検出オーバーレイを表示」をオフにすると、隠れた状態で開きます）
再生速度
ツールバーで 0.25x / 0.5x / 1x / 1.5x / 2x / 4x から選択（, で遅く . で速く）

検出枠の操作

選択
枠をクリックすると太枠と 8 つのハンドルが表示されます。あわせて、エッジぼかしが届く範囲が枠の外側に点線で表示されます（Premiere Pro のマスクの境界のぼかしと同じく、輪郭の外側に設定値の半分の幅。エッジぼかしが 0 のとき、モザイク対象外のトラック、オーバーレイ非表示（H）のときは出ません）
移動 / サイズ変更
枠の内側をドラッグで移動、ハンドルをドラッグでサイズ変更。再生中でもドラッグできます
削除
選択して Delete、枠をダブルクリック、または右クリックメニューの「この BBox を削除」。削除はそのフレームの枠だけに適用されます（同じ ID の他のフレームは残ります）
連続削除（消しゴム）
映像の上で E キーを押しながら右ボタンを押したままドラッグすると消しゴムになります。既定では円に触れた枠をそのフレームから削除します。ツールバーの消しゴムボタンで、消し方（触れた BBox を削除 / 触れた部分だけ削除）、形（円 / 角丸四角）、大きさ（8〜120px）を選べます。「触れた部分だけ削除」では、削った跡が枠の形（多角形）として残り、手動で追加した枠が 2 つに割れたときは片ごとに別の枠になります。押したまま再生したりホイールでコマ送りしたりすると、流れていくフレームの枠も続けて消せます（E を押していない右ドラッグや、右ボタンを動かさずに離したときは、いつもの右クリックメニューが開きます）
ID ごと削除（チップの ✕）
検出した枠のチップの右端にある ✕ を押すと、その ID の枠を全フレームからまとめて削除します。削除するフレーム数を示した確認が出ます。手動で追加した枠のチップには ✕ は出ませんが、右クリックメニューの「この ID をすべて削除」で同じことができます
右クリックメニュー
顔の枠では「男性顔に変更」「女性顔に変更」（検出された性別の修正）。すべての枠で「モザイク対象外にする」「モザイク対象に戻す」（そのトラック全体をモザイクの対象から外す / 戻す）、その下に「反転 (外側にモザイク)」「反転 (外側にぼかし)」（下の「反転」）、「回避マスクにする」（回避マスクの枠では「モザイクに戻す」。回避マスクへの変更）、「この BBox を削除」、「この ID をすべて削除」（検出した枠ではチップの ✕ と同じ。手動で追加した連続 bbox / 1 フレームの枠 / 回避マスクでは、その枠を全フレームからまとめて消します。検出した ID に統合した連続 bbox があれば一緒に消え、確認にその件数が出ます。どちらも Ctrl+Z 1 回で戻せます）。連続 bbox に軌跡があるときは「移動軌跡をクリア」。統合できる ID があるときは「ID を統合…」、統合済みの ID では「統合を解除」（下の「ID の統合」）。「形を変更」では、範囲（この BBox / この ID すべて / すべて）を選んで四角 / 楕円 / 多角形に変えられ、「形を既定に戻す」で元の形に戻せます。「ここからつなぐ」、つなぐ元を選んでいるときは「中間地点にする」「ここへつなぐ」。キーとつなぐ操作は追跡とキーを参照してください
反転（外側にかける）
枠を右クリックして「反転 (外側にモザイク)」または「反転 (外側にぼかし)」を選ぶと、その ID が反転に切り替わります。反転中の枠のメニューは「反転を解除 (内側にかける)」になり、選ぶと元に戻ります。回避マスクには出ません。どこにかかるかと「ID 別」タブでの切り替えは、モザイク設定パネルの「反転 (外側にかける)」をご覧ください
ID の統合
同じ対象なのに別の ID に分かれてしまったときは、残したい方の枠を右クリックして「ID を統合…」を選びます。統合できる ID の一覧（「#XXX に統合する ID」）が近い順に開くので、まとめたい ID を選ぶと、右クリックした ID にまとまります。一覧の各行には #ID とクラス名、区間（フレームと時刻）、何フレーム後 / 前か（または「隣接」）が並び、選択中の枠は先頭に「選択中」と表示されます。↑ / ↓ と Enter でも選べ、Esc で閉じます。8 件を超えると「さらに N 件」で続きを出せます。下のタイムラインで、ID ごとの行を右クリックしても同じ一覧が開きます。統合すると 1 つの ID として扱われ（タイムラインの行、ID 別のモザイク設定、書き出しのすべて）、間に枠の無いフレームがあれば自動で補間されます。統合できるのは同じクラスで、同じ時間に映っていない ID です（同時に映っているものは別の対象です）。統合できる ID が無いときは、一覧に「統合できる ID がありません」と表示されます
連続 BBox の統合
連続 bbox（∞）どうしや、連続 bbox と検出した ID も統合できます。連続 bbox を右クリックして検出した ID を選んだときは、検出した ID の方が残ります（一覧のその行に「検出 ID が本体になります」と表示されます）。連続 bbox どうしで時間が重なるときは、先に始まる方を相手が始まる手前で区切ります（統合を解除すると元に戻ります）。回避マスクは統合できません
統合の取り消しと解除
統合した直後なら Ctrl+Z 1 回で統合する前に戻せます。後から戻すときは、統合先の枠を右クリックして「統合を解除（N 件）」を選ぶか、タイムラインの ID の行を右クリックして一覧の末尾の「統合を解除（N 件）」を選びます
頂点の範囲選択と曲げ（Shift+左ドラッグ）
多角形の枠を選択し、Shift を押しながら左ドラッグで頂点を囲むと、囲んだ頂点をまとめて選べます（つながった区間にまとまります。1 点だけなら 1 点の選択、短いタップか Esc で解除）。選んだ区間の内側の頂点をドラッグすると、区間の両端を固定したまま、中央ほど大きく動くように曲がります。すべての頂点を囲んだときは形を保ったまま動きます。区間の端の頂点をドラッグしたときは、その 1 点だけが動きます。複数の頂点を選んでいる間は Delete で頂点を消せません（1 点ずつ選んで消します）
モザイク除外の注意表示
対象から外したトラックがあると「N トラックをモザイク除外中です」と常時表示されます。「すべてモザイク対象に戻す」で一括で戻せます。除外した箇所は書き出してもモザイクがかかりません
プレビューの余白と枠外
プレビューでは映像の上下左右に余白（各辺およそ 15%、暗いグレー）があり、映像の境目に細い枠線が引かれます。枠は余白へはみ出す位置まで動かしたり広げたりでき、人物が画面の外へ出ていく場面でも楕円などの形を潰さずに置けます。はみ出した部分は書き出されませんが、映像の内側はその形のまま映像の端までモザイクがかかります。新しく描く枠は映像と重なる必要があり、余白だけをドラッグしても描けません
画面の端で切れた検出枠
画面の端にかかって切れた検出枠は、端に触れる前後のフレームの大きさをもとに、画面の外まで自動で補われます。モザイクを描くのは画面の中だけですが、形（楕円など）は補った枠をもとに決まるので、顔が画面の外へ出ていく場面でもモザイクの形が端で潰れません。プレビューと書き出しの両方に反映されます。この補完はバージョン 2.8.1 以降で検出した動画に付きます
枠を描く（左ドラッグ）
映像の空いている所を左ドラッグすると、ツールバーの形の選択で選んでいる形（四角 / 楕円 / 多角形）の枠を描けます。多角形はクリックで点を置き、始点のクリック / Enter / ダブルクリックで閉じます。描いた枠は既定で以降のフレームにも続く連続 bbox で、形の選択メニューの「描いた BBox」で「このフレームのみ」に、「描いた BBox の種類」で「回避マスク」に変えられます。余白だけをドラッグしても枠は描けません（映像と重なるように描きます）。拡大中にフレームを動かすときは Ctrl+左ドラッグ（中ボタンドラッグでも可）です
手動で追加した枠の表示
手動で追加した枠のチップは「ユーザー」と表示され、ID は検出された枠と同じ 3 文字のコード（例: #K7Q）です。タイムラインでは「ユーザー」の行に並びます
モザイク設定の引き継ぎ
検出された枠に重ねて、または近く（隙間が画面の短辺の 5% 以内）に枠を追加すると、その検出枠に効いているモザイク設定（種類・ぼかし・不透明度・粒の大きさ）を写します。粒の大きさは、その検出枠と同じ見た目になるように固定されます。写した設定はモザイク設定の「ID 別」タブでいつでも変えられます
形を引き継いでコマ送り（Shift+→）
枠をクリックして選択し、Shift を押しながら →（またはホイールを上へ）で進むと、Shift を押し始めた時点の位置・大きさ・形のまま 1 コマずつ進み、進んだ先のフレームのその枠を上書きします。引き継ぎ中の枠のチップには「[引き継ぎ中]」と表示されます。Shift を離すまでが 1 つの操作で、Ctrl+Z 1 回でまとめて戻せます。進んだ先にその枠が無いフレームは飛ばし、1 フレームも書けなかったときは「進んだ先のフレームにこの BBox が無く、形を引き継げませんでした」と表示されます。Shift+← は引き継がずに 1 コマ戻ります。再生ボタンでの再生、PageDown の 10 コマ移動、1 フレームのみの手動の枠、取り込んだ素材の区間では引き継ぎません
引き継ぎの固定（Shift ×2）
枠を選択して Shift を素早く 2 回押すと、Shift を離しても引き継ぎが続く「固定」になり、チップに「[引き継ぎ: 固定]」と表示されます。固定中は Shift なしの → やホイール上でも形を引き継いで進みます（PageDown と再生ボタンでは引き継ぎません）。もう一度 Shift を素早く 2 回押すか、Esc で解除します。固定中に別の枠を選び直すと、次に進んだときからその枠の形を引き継ぎます。日本語入力（IME）などのソフトが Shift の単押しを使っている環境では、固定にならないことがあります

検出枠の選択・追加・消しゴムは、再生ヘッドが元の動画（検出元）の区間にあるときだけ使えます。取り込んだ素材の区間は AI 検出の対象外のため、枠はありません。

タイムライン

タイムラインは上から、ツールバー、目盛り、シーン（カット）の帯、テキスト・クリップ・音声のレーン（クリップの編集）、検出クラスごとの行の順に並びます。クラスの行には検出のある区間が帯で描かれ、手動で追加した枠は「ユーザー」、回避マスクは「回避」の行に並びます。行頭の {% include icon.html name="ChevronDown" class="inline h-3.5 w-3.5 align-[-2px]" %} で追跡 ID ごとの行に展開できます。ID の行を右クリックすると、その ID に統合できる ID の一覧が開きます（上の「ID の統合」。統合済みの ID では一覧の末尾に「統合を解除」）。右クリックではその位置へ移動しません。モザイク対象から外したトラックは薄く表示されます。タイムラインは書き出す映像の時間で並ぶので、クリップをトリムしたり動かしたりすると、検出の帯も一緒に動きます。

タイムラインは Ctrl+ホイール、またはツールバー左端の拡大・縮小ボタンで最大 16 倍まで拡大できます。高さの変更と折りたたみはクリップの編集を参照してください。

{% include docs-h2.html kicker="編集" title="拡大・縮小とパン" %}

小さな対象の枠を正確に合わせるために、プレイヤーの映像を最大 8 倍まで拡大できます。拡大中も枠の移動・サイズ変更・追加・削除はそのまま行えます。

拡大 / 縮小
Ctrl+ホイール（カーソル位置を中心に拡大縮小）、+ / - キー、またはプレイヤー右上の {% include icon.html name="Maximize2" class="inline h-3.5 w-3.5 align-[-2px]" %} ボタン。現在の倍率はボタンの間に表示されます
パン（表示位置の移動）
Ctrl+左ドラッグ、または中ボタン（ホイール）ドラッグ。拡大していないとき（等倍）は動きません。空いている所の左ドラッグは枠の描画になります
リセット
0 キー、または「ズームをリセット」ボタンで等倍・中央に戻ります
{% include docs-h2.html kicker="編集" title="検出枠の追加（1f と ∞）" %}

検出されなかった箇所には、ツールバーの「1f」（＋の入った四角に 1f）と「∞」（∞ の入った四角）のボタンで枠を手動で追加できます。追加した枠は現在のフレームの中央に「ユーザー」クラス（黄）で置かれるので、ドラッグで位置と大きさを合わせます。手動の枠にもモザイク設定（ID 別を含む）がそのまま適用されます。

1f（1）
このフレームだけに枠を置きます。前後のフレームには影響しません。数フレームだけ検出が抜けた「中抜け」の補修に向いています
∞ 連続 bbox（2）
置いたフレームから先のすべてのフレームに同じ位置で枠が続きます。動画の最後まで続けたくないときは、終わらせたいフレームで枠を削除してください（削除したフレームの手前までが有効範囲として確定します）
連続 bbox を動かす
再生しながら ∞ の枠をドラッグすると、その動きが軌跡として記録され、被写体の移動に追従させられます。記録した軌跡は右クリックメニューの「移動軌跡をクリア」で消せます。対象を自動で追わせるときは追跡を使います
取り消し
Ctrl+Z は、直前の編集が ID の統合・全削除・形の範囲の書き込み・クラスごとの回避マスクへの変更ならそれだけを戻します（検出枠の操作）。それ以外では、∞ の枠を削除で終わらせた直後ならまず終端の確定を解除し（ショートカットの凡例では「凍結解除」）、それも無ければ「現在のフレームをリセット」と同じく現在のフレームの編集を元に戻します

回避マスク（モザイクをかけない範囲）

重なったモザイクの一部だけを外したいとき（顔の横の手元だけ見せたい、など）は、回避マスクを置きます。回避マスクの内側にはモザイクがかからず、元の映像のまま表示・書き出しされます。追尾はしないので、動く対象には位置をドラッグで合わせてください。

1f 回避マスク（3）
このフレームだけに置きます
∞ 連続 回避マスク（4）
置いたフレームから先のフレームに続けます（終わらせ方は連続 bbox と同じで、終わらせたいフレームで削除します）
形と描画
ツールバーの形の選択で選んだ形（四角 / 楕円 / 多角形）で置かれます。形の選択メニューの「描いた BBox の種類」を「回避マスク」にすると、左ドラッグで回避マスクを描けます
表示
枠とチップは青緑の「回避」で、タイムラインの「回避」の行に並びます。モザイク適用プレビュー（M）で、モザイクが打ち抜かれた見た目を確認できます
縁のぼかし
回避マスクの縁は、手動の枠と同じエッジぼかしの設定でなじませます。サイズ（bbox 拡張率）は効きません
Premiere Pro
回避マスクは Premiere Pro 連携には渡りません

既存の枠を回避マスクに変える

検出した枠や手動で追加した枠も、あとから回避マスクに変えられます。回避マスクに変えた枠の内側には、重なっているほかのモザイクもかかりません。

1 つずつ変える
枠を右クリックして「回避マスクにする」を選びます。検出した枠は、その ID（統合した ID を含む）の全フレームが回避マスクになります。手動で追加した枠は、その枠が回避マスクに変わります。元に戻すときは、回避マスクの枠を右クリックして「モザイクに戻す」を選びます
クラスごとにまとめて変える
モザイク設定（G）の「クラス別」タブでクラスを選び、「このクラスをすべて回避マスクにする」を押します。対象の ID の数を示した確認が出ます。対象は、その時点にある、そのクラスの検出した ID です（男性顔と女性顔は別のクラスで、性別が分からない顔は女性顔に入ります。手動で追加した枠と、あとから増えた ID は含みません。「手動で追加したマスク」を選んでいる間はこのボタンは出ません）。「このクラスをすべてモザイクに戻す」で、まとめてモザイクに戻せます。どちらも Ctrl+Z 1 回で元に戻せます
表示
回避マスクに変えた枠は、ほかの回避マスクと同じく青緑の「回避」で表示され、タイムラインの「回避」の行に並びます。回避マスクに変えた ID は統合できません。統合した後に回避マスクに変えた ID の「統合を解除」をすると、外れた ID はモザイクに戻ります
Premiere Pro と以前のバージョン
回避マスクへの変更は Premiere Pro 連携には渡りません。2.18 より前のバージョンの Deepmosaic でプロジェクトを開いて保存すると、回避マスクに変えた検出の枠はモザイクに戻ります（モザイクがかかる側に戻るので、隠れない箇所はできません）

枠の追加・移動・削除はすべて自動保存され、エンコードに反映されます。Premiere Pro 連携に渡るのは検出結果とエッジのぼかしの値だけで、この画面での枠の編集（移動・形の変更・削除・回避マスクなど）は渡りません。

{% include docs-h2.html kicker="編集" title="追跡とキー" %}

「追跡」は、手で置いた ∞ 連続 bbox を、再生に合わせて対象の動きへ自動で合わせる機能です。操作列のボタンで ON / OFF を切り替えます。「キー」は、手で直したフレームを動きの基準にし、キーとキーの間を自動でつなぐ仕組みです。

追跡

  1. 枠を置きます。∞ 連続 bbox（2）を置くか描いて、対象に合わせます（検出枠の追加）
  2. 追跡モードを ON にします。操作列の追跡ボタン（{% include icon.html name="Crosshair" class="inline h-3.5 w-3.5 align-[-2px]" %}）を押すか、X を押します
  3. 進めます。再生、→、ホイール上のどれかで進むと、枠が対象を追って動きます
追跡モード（X）
ON の間、前へ進む操作（再生 / → / ホイール上）で追跡します。← など戻る操作では追跡しません。もう一度押すと OFF になります
追う枠
今のフレームに見えている ∞ 連続 bbox をすべて追います。枠を選ぶ必要はありません。複数の枠も同時に追え、数の上限はありません。枠が多いほど追跡は遅くなり、そのぶん再生が追跡を待ちます。1f の枠と回避マスクは追いません（「回避マスクは追跡できません」）
再生の速さ
追跡中は等倍以下で再生します。追跡が追いつかないときは、追いつくまで一時停止して待ちます
止まるとき
対象を見失った、画面の外に出た、シーンが切り替わった などのときは追跡を止め、理由を表示します（例:「ここで対象を見失ったため、追跡を止めました」）。このとき ∞ 枠は最後に追えたフレームで終わり、その先には続きません。動画の端まで追えたときは「動画の端まで追跡しました」と表示されます
取り消し（Ctrl+Z）
1 回の追跡の結果は、複数の枠を同時に追ったときも、Ctrl+Z 1 回でまとめて追跡を始める前に戻せます（枠の終わりも元に戻ります）
追い終わった枠
一度追い終わった枠は、もう一度再生しても追い直しません。追跡モードを ON にしたまま枠を手で直すと、直したフレームから先（次に手で直したフレームの手前まで）を追い直します。最初から追い直すときは、枠を削除して置き直します
追跡の種類
GPU のある PC では「高精度の追跡」、それ以外では「標準の追跡」が自動で選ばれます。検出の実行中は標準の追跡を使います。追跡を始めた後に追跡ボタンへマウスを乗せると、使っている追跡が「使用中: 高精度の追跡 (GPU)」のように表示されます
新しい検出エンジンが必要
「追跡には新しい検出エンジンが必要です」と表示されたときは、アップデートを適用してください

キー

∞ 連続 bbox を直したとき
追跡していない ∞ 枠は、手で直したフレームが「キー」になり、前のキーとの間が自動でなめらかにつながります。追跡した ∞ 枠を追跡モード OFF のまま直したときは、直したフレームだけが変わります
キー（F）
選択中の枠の今の位置を、動かさずにキーにします
AI の枠を直したとき
直したフレームだけが変わります

つなぐ

離れたフレームの枠を地点にして、その間を対象の動きに合わせて動く ∞ 連続 bbox を 1 本作ります。開始と終了のほかに、途中の地点（中間地点）を何か所でも置けます。

  1. 開始の地点を置きます。始めのフレームで枠を選び、Y を押します（または枠の右クリックメニューの「ここからつなぐ」）。プレイヤーの左下に「つなぐ元: #K7Q @ 3」のような表示と、次の操作の案内が出ます
  2. 必要なら中間地点を置きます。途中のフレームへ移り、対象に合わせた枠を選んで Shift+Y を押します（または右クリックメニューの「中間地点にする」）。何か所でも置けます。同じフレームにもう一度置くと置き換わります（「同じフレームの地点を置き換えました」）
  3. 終了の地点でつなぎます。終わりのフレームで枠を選び、Y を押します（または右クリックメニューの「ここへつなぐ」）。その場で地点の間がなめらかな補間でつながり、「BBox をつなぎました (#K7Q → #K7Q、31 フレーム)」のように表示されます。中間地点を置いたときはその数も表示されます
  4. 追跡が順番に進みます。つないだ区間は「トラッキングキュー」に入り、地点の間の枠が対象の動きに合わせて直されます（下の「トラッキングキュー」）。終わるのを待たずに、次のつなぐ操作やほかの編集を続けられます
つなげる枠
地点の枠は AI の枠でも、手動で追加した枠でもかまいません。同じシーンの中の、別のフレームの枠どうしをつなげます（中間地点も同じです）
追えなかったとき
追跡で対象を見失ったときは、追えた所までを反映し、残りはなめらかな補間のまま残します（トラッキングキューの行に「f120 で対象を見失いました」のように表示されます）。開始の地点が回避マスクのときや、隣り合うフレームどうしをつないだときは、補間だけでつなぎ、トラッキングキューには入りません。追跡を使えないときも補間だけでつなぎ、「対象を追えないため、なめらかな補間でつなぎました」と表示されます
連続 bbox を地点にしたとき
開始・中間の地点の枠が ∞ 連続 bbox のときは、地点にした時点でそのフレームだけの枠に変わります（そのフレームに置いた枠ならその枠が 1 フレームだけの枠になり、前のフレームから続く枠ならその手前で終わって、このフレームに 1 フレームの枠ができます）。終了の地点の枠が ∞ 連続 bbox のときは、その枠は地点の手前で終わり（そのフレームに置いた枠なら消え）、つないだ枠に置き換わります
元の枠
元の AI の枠は消えずに残り、間のフレームではつないだ枠と重なります。地点にした 1 フレームだけの枠は消えます。つないだ枠は、終了の地点のフレームで終わります
途中を直す
追跡でつないだ枠は、追跡済みの枠として扱います。追跡モード（X）が ON の状態で途中のフレームを直すと、そこから次の地点の手前まで追い直します。OFF のときは、直したフレームだけが変わります。全体をなめらかな補間でつないだ枠は、一時停止中に途中のフレームで直すと、そこがキーになり、前後がなめらかにつながり直します（上の「キー」）
取り消し（Ctrl+Z）
つないだ直後は Ctrl+Z 1 回で、つなぐ前に戻ります（連続 bbox を地点にしていたときは、元の連続 bbox まで戻ります。トラッキングキューの追跡が終わった後でも、ほかの編集をしていなければ同じです）。途中を直した後は Ctrl+Z でつなぐ前には戻らないので、作り直すときは枠の右クリックメニューの「この ID をすべて削除」で消します
やめる（Esc）
地点を置いた後にやめるときは Esc を押します。地点の枠を 1 フレームだけの枠に変えていたときは、そのまま残ります（Esc の直後に Ctrl+Z を押すと、変えた枠がすべて元の連続 bbox に戻ります。間に別の編集をすると戻せません）
追跡の前に区間を直したとき
トラッキングキューで待っている間や追跡中に、その区間の枠を手で直すと、そのつなぐ処理はキューから外れ、枠は補間のまま残ります（「区間の枠を手で直したため、トラッキングを取り消しました。枠は補間のまま残ります。」）
つなげないとき
次のときはつながらず、理由が表示されます: 同じフレームの枠どうし（「つなげません: 同じフレームです」）、シーンをまたぐ枠（「つなげません: 場面をまたぐ BBox はつなげません」）、間に回避マスクがある（「つなげません: 間に回避マスクがあります」）、BBox と回避マスクの組（「つなげません: BBox と回避マスクで種類が違うためです」）

トラッキングキュー

つないだ区間の追跡は「トラッキングキュー」に入り、1 件ずつ順番に進みます。GPU のある PC では、追跡の後に輪郭の精緻化（モザイクの精緻化と同じく、枠を物体の形に沿わせる処理）も続けて行います。終わると、地点の間の補間の枠が、追跡（と精緻化）の結果に置き換わります。手で置いた地点のフレームの枠は変わりません。

パネルと表示
つないだ区間があると、プレイヤーの上に「トラッキング 45% · 待機 2」のような小さい表示（進み具合のバー付き）が出ます。押すと「トラッキングキュー」のパネルが開き、パネルの「—」で小さい表示に戻ります。パネルと小さい表示はドラッグで動かせ、位置と開閉は次に編集ページを開いたときも引き継がれます。画面下のステータスバーにも「● トラッキング 45% (3件)」のように進み具合が表示され、押すとパネルを開閉できます（何も無いときは「トラッキング: 待機なし」、対象を見失った区間などがあるときは「● トラッキング エラーあり」）
パネルの見方
上から、実行中の 1 件（状態「追跡中」「精緻化中」「一時停止」、ID、地点 A・B のフレーム、進み具合の %、速さ、残りの目安）、「待機中 · N」の一覧、「完了 · N」の一覧の順に並びます。パネルの下には「全体の残り 約2分10秒」のように全体の残りの目安が表示され、すべて終わると「すべて処理済み」になります
一時停止 / 中止
実行中の行の「一時停止」で止め、「再開」で続きから進めます。✕（「中止」）でその処理をやめると、枠は補間のまま残ります
並べ替え / 削除
待機中の行の ↑（「優先する」）で 1 つ前と順番を入れ替えます。✕（「キューから削除」）で外すと、その区間の枠は補間のまま残ります
確認 / 再試行
完了した行の「確認」を押すと、その区間の先頭へ移動して結果の枠を選びます。対象を見失った行は赤で「f120 で対象を見失いました」のように表示され、見失うまでに追えた所は反映され、残りは補間のままです。「再試行」で待機中に戻せます。追跡が途中で止まったときは「追跡を完了できませんでした」と表示されます。「完了を消去」で、終わった行を一覧からまとめて消せます
ほかの操作との関係
追跡モード（X）や、枠を手で直したときの追い直しが優先されます。その間、キューの処理は一時停止し、終わると自動で再開します。検出の実行中は輪郭の精緻化を行わず、追跡の結果だけを反映します（「検出の実行中のため、輪郭の精緻化を省いて追跡の結果だけを反映しました。」）
精緻化を行わない PC
GPU の無い PC、GPU のメモリが 4 GB 未満の PC、モザイクの精緻化の AI モデルを取得していないときは、輪郭の精緻化を行わず、追跡だけで完了します
編集ページを離れるとき
トラッキングキューは編集ページを開いている間だけ働きます。終わっていない処理があるまま、編集ページを離れる・エンコードする・Premiere Pro へ送るときは、「トラッキングが終わっていません」と確認が出ます。そのまま進むと、終わっていない区間は補間のままになります
シークバーの帯
シークバーの上に、キューにある区間が帯で表示されます（実行中は進み具合、完了は緑）。サイドバーの「設定」の「シークバーにトラッキングの区間を表示」で表示しないようにできます

区間をまとめて直す

AI の枠を手で直すと、変わるのはそのフレームだけです。数秒〜数分の区間をまとめて直すときは、場面に合わせて次の操作を使います。

対象が動く
始めと終わり（と途中）のフレームの枠を地点にして、つなぐ（Y / Shift+Y）で追跡でつなぎます（上の「つなぐ」）。手で直すときは、一時停止し、追跡モードが OFF の状態で、区間の始めに ∞ 連続 bbox（2）を置いて対象に合わせ、途中と終わりのフレームで位置と大きさを直します。直したフレームの間は自動でなめらかにつながります（上の「キー」）。動きが複雑なときは追跡（X）で対象を追わせ、ずれたフレームだけを直します（上の「追跡」）
対象があまり動かない
直した枠を選んで Shift を素早く 2 回押し、→ で進むと、同じ位置・大きさ・形が先のフレームへ書かれます（引き継ぎの固定）。Esc で解除します
区間の枠を一律に広げる・狭める
モザイク設定（G）の「時間別」タブで「範囲を追加」を押し、開始・終了を区間に合わせて「サイズ (bbox 拡張率)」を変えます。範囲の中のすべての枠（手動で追加した枠を含みます）に効きます。シーンの単位で変えるときは「シーン別」タブで「対象シーン:」にそのシーンを選びます（区間の始めと終わりで Ctrl+K を押すと区切れます。シーン）。特定の対象だけを変えるときは「ID 別」タブを使います（その ID の全フレームに効きます）

次の点に注意してください。

  • 手動で追加した枠は AI の枠に重なり、AI の枠は残ります。AI の枠が大きすぎる・ずれている区間は、消しゴム（E+右ドラッグを押したまま再生）で続けて消すか、枠の右クリックメニューの「モザイク対象外にする」でその ID 全体をモザイクの対象から外します（検出枠の操作）
  • キーの間の補間は、一時停止中に追跡モードが OFF の状態で直したときだけ働きます。追跡モードが ON の間と、再生中のドラッグ（軌跡の記録）では補間されません
  • ∞ 連続 bbox は、削除するまで先のフレームに同じ位置で出続けます（シーンが切り替わっても止まりません）。終わらせたいフレームで枠を選んで Delete を押すか、右クリックメニューの「この BBox を削除」を選ぶと、そのフレームから先が消えます
  • つなぐ操作は、同じシーンの中の枠どうしだけです
  • 手動で追加した枠（∞ 連続 bbox・つないだ枠）は、作ったときのサイズを「ID 別」の設定として持ちます。その後に「全て」「シーン別」「時間別」などで設定した値は、手動で追加した枠にも効きます（最後に設定したものが優先されます。モザイク設定パネル）
  • モザイクがかかる範囲は、プレビューをモザイク適用プレビュー（M）にすると確かめられます
{% include docs-h2.html kicker="編集" title="シーン（カット）" %}

検出時に映像のカット（場面の切り替わり）が自動で判定され、タイムラインの上部にシーンの帯として表示されます。シーンは「ピクセルサイズ自動」が ON のときに粒度を一定に保つ単位であり、モザイク設定をシーンごとに変える単位でもあります。

シーンへ移動
帯をクリックすると、そのシーンの先頭フレームへジャンプします。帯には番号（#1, #2 …）が表示され、マウスオーバーで区間が確認できます
分割（Ctrl+K）
タイムラインのツールバー（拡大・縮小ボタンの右）の {% include icon.html name="Scissors" class="inline h-3.5 w-3.5 align-[-2px]" %} ボタン、または Ctrl+K で、現在のフレームを境にシーンを 2 つに分けます。自動判定が見逃したカットや、同じカット内で設定を変えたい箇所に使います
境界の調整
帯の境目をドラッグすると、前後のシーンの開始・終了が同時に動きます
削除
帯にマウスを乗せると出る ✕（このシーンを削除）で、隣のシーンと結合します

シーンの変更は編集データとして保存され、検出結果そのものは変わりません。「全編集リセット」で自動判定の状態に戻ります。シーンの分割は書き出す映像を切りません。映像そのものを切り分けるときは、クリップの分割（Ctrl+Shift+K、クリップの編集）を使います。

プレイヤーの下の操作列には、左から再生コントロール（先頭へ / 1 コマ戻る / 再生 / 1 コマ進む / 末尾へ / 空白のみ再生 / 欠落フレームジャンプ / ミュート）、編集ツールバー、時刻の順に並びます。編集ツールバーは縦線で区切った次のまとまりです: 形の選択 / bbox 追加 / 回避マスク追加 / 消しゴム / 現在のフレームをリセット ｜ オーバーレイの表示切替 / プレビュー切替 / 追跡 ｜ モザイク設定 ｜ 全編集リセット ｜ ラベル ｜ 再生速度 ｜ ショートカット一覧。追跡のボタンはアイコンだけです。幅が足りないときはツールバーと時刻が 2 段目に折り返します。各ボタンにマウスを乗せるとショートカットキーが表示されます。

空白のみ再生（B）
再生コントロールの「末尾へ」の右。検出枠を含むフレームを自動でスキップし、bboxの無いフレームだけを連続再生します。見落としの確認に便利です
欠落フレームジャンプ
「空白のみ再生」の右の 2 つのボタンで、検出が無いフレームへ前後にジャンプします（ショートカット: [ / ]）。対象のクラスは、ツールバーの「ラベル」メニューの下段「絞り込み」で選んだクラスです
プレビュー切替（M）
オーバーレイの表示切替の右。bbox枠表示とモザイク適用プレビューを切り替えます。モザイク表示では書き出し結果に近い見た目をその場で確認できます
形の選択
ツールバーの先頭。追加する / 描く枠の形（四角 / 楕円 / 多角形）を選びます（W で楕円、O で多角形、もう一度押すと四角）。メニューの「描いた BBox」で、描いた枠を「以降も」続けるか「このフレームのみ」にするかを、「描いた BBox の種類」で「モザイク」か「回避マスク」かを選べます。ここで切り替えた値はこの編集中だけ効き、起動時の初期値はサイドバーの「設定」で選びます（サイドバーとドロワー）
bbox追加（1f / ∞）
現在のフレーム中央に、形の選択で選んでいる形の枠を追加します。「1f」（＋の四角に 1f）はこのフレームのみ、「∞」（∞ の入った四角）は以降のフレームすべてに連続表示。画面の幅が狭いときはアイコンだけになります。追加後はドラッグで調整（検出枠の追加）。ショートカット: 1 / 2
回避マスク追加（1f / ∞）
bbox 追加の右の点線の四角のボタン。現在のフレーム中央に、形の選択で選んでいる形の回避マスク（モザイクをかけない範囲）を置きます。「1f」はこのフレームのみ、「∞」（∞ の入った点線の四角）は以降のフレームに連続（回避マスク）。ショートカット: 3 / 4
消しゴム
E+右ドラッグの消しゴムの設定（消し方: 触れた BBox を削除 / 触れた部分だけ削除、形: 円 / 角丸四角、大きさ: 8〜120px）。ボタンを押しても消しゴムにはならず、消すのは常に E+右ドラッグです
モザイク設定（G）
モザイク設定パネルを開きます（次章）
{% include icon.html name="Crosshair" class="inline h-3.5 w-3.5 align-[-2px]" %} 追跡（X）
プレビュー切替の右。追跡モードの ON / OFF。ON の間、再生 / → / ホイール上で進むと ∞ 連続 bbox が対象を追います（追跡とキー）。編集ページを開いたときは OFF です（サイドバーの「設定」で ON にしておけます）
現在のフレームをリセット
現在のフレームの編集（枠の追加・移動・削除）を検出結果の状態に戻します。ショートカット: Ctrl+Z（直前の編集によっては、先にそちらを戻します。取り消し）
全編集リセット
枠の編集・モザイク設定・シーン・人物の統合などすべての編集を破棄します（確認ダイアログ付き・取り消し不可）
ラベル（C）
ボタンには選択の要約（例:「全 2 ラベル」「顔 · 男性顔」）が表示されます。メニューの上段「表示する（書き出しにも効く）」は局部 / 顔のチェックで、外したラベルはプレビューにも書き出しにも出ません（例: 局部だけを書き出す）。下段「絞り込み（表示と欠落ジャンプのみ）」は全クラス / 局部 / 男性顔 / 女性顔から選び、プレビューとタイムラインに表示する枠と欠落フレームジャンプの対象を絞ります（書き出しには影響しません）。素材にすでにかかっているモザイクの枠があるプロジェクトでは、上段と下段の両方に「モザイク」も表示されます。上段の「モザイク」は検出の後に ON になっていて、書き出しでその範囲にモザイクを上からかけ直します。外すとプレビューにも書き出しにも出ず、開き直しても外したままです
再生速度
0.25x / 0.5x / 1x / 1.5x / 2x / 4x から選択

{% include docs-h2.html kicker="編集" title="モザイク設定パネル" %}

モザイクの見た目を 5 つの適用範囲（タブ）で設定できます。同じ枠・同じフレームに複数の設定が当たるときは、最後に設定したものが優先されます（下の「設定の優先」）。パネルはヘッダーをドラッグで自由な位置に移動でき、右下の角をドラッグすると大きさを変えられます（角を選んで矢印キーでも調整、ダブルクリックで既定の大きさ）。開いたまま編集を続けられます。値を変えると、モザイク適用プレビュー（M）にその場で反映されます。

適用範囲タブ
全て（グローバル既定）/ クラス別（「対象クラス:」で 局部 / 男性顔 / 女性顔 / 手動で追加したマスク から選びます。すでにかかっているモザイクの枠があるプロジェクトでは「モザイク」も出ます。性別が分からない顔は女性顔の設定が使われ、人物ギャラリーで性別を変えると変えた性別の設定が使われます。「手動で追加したマスク」は自分で追加した枠に効きます）/ ID別（追跡された個々の対象）/ シーン別（カット単位）/ 時間別（時間の範囲。下の「時間別」）。ID 別・シーン別・時間別では対象をプルダウンで選びます。オーバライド中の範囲には「オーバライド中」と表示され、「クリア」で個別に解除できます。「クラス別」タブには「このクラスをすべて回避マスクにする」「このクラスをすべてモザイクに戻す」もあります（既存の枠を回避マスクに変える）
信頼度しきい値
指定した信頼度以上の検出だけを表示・モザイク対象にします（0〜100%、タブに依らないグローバル設定）
種類
モザイク（ブロック状）/ ぼかし（ガウスぼかし）。既定: モザイク
サイズ（bbox拡張率）
検出枠を中心から拡大・縮小してモザイク範囲を調整（0.50x〜2.00x）。既定: 1.05x。ギリギリを避けたいときは大きめに
不透明度
モザイク/ぼかしをどれだけ強く合成するか（0〜100%）。既定の 100% で対象を完全に覆います。値を下げるほど隠蔽が弱くなるため、通常は 100% のまま使います
エッジぼかし
モザイク領域のふちをぼかして背景となじませます（0〜64px）。既定: 6px。Premiere Pro のマスクの「マスクの境界のぼかし」と同じ意味で、輪郭を中心に内側と外側へ半分ずつぼかします（値は内外を合わせた幅です）。プレイヤーで枠を選択すると、ぼかしが届く外側の範囲が点線で表示されます。回避マスクの縁も同じ値でなじませます
ぼかしの強さ
種類が「ぼかし」のときだけ表示されます。数値（2〜64）が大きいほど強くぼかします。動かすまでは「自動 (n)」と表示され、エッジぼかしの幅に合わせて決まります（今までと同じ見た目です）。動かした後は、エッジぼかしを変えてもぼかしの強さは変わりません。戻すボタン（「自動に戻す」）で「自動」に戻ります。種類を「モザイク」に戻しても値は残ります。Premiere Pro 連携には渡りません
ピクセルサイズ
「ピクセルサイズを設定」ボタンで設定画面を開きます。ボタンの下に現在の設定（例: 固定 幅に 53 粒、大きさの範囲ごと 幅に 42〜96 粒、分割数で比例 ÷16）が表示されます。粒の大きさは画面の幅に並ぶ粒の数で表し（数が多いほど細かい）、動画の解像度が違っても同じ見た目になります。種類が「モザイク」のときだけ表示され、「ID 別」「シーン別」「時間別」のタブでは対象を選ぶと押せます。「適用」を押すと開いているタブ（全て / クラス別 / ID 別 / シーン別 / 時間別）に反映され、「キャンセル」では何も変わりません。新しく検出した動画の初期値は検出オプションで決めます（既定は固定）
設定画面の見方
左はプレビューとグラフです。プレビューの楕円の枠はドラッグで移動、右下のハンドルで大きさを変えられ、枠の中に実際の粒でモザイクがかかります。プレビュー画像は人物・テストパターンから選ぶほか、自分の画像に差し替えられます。グラフは対象の大きさ（横軸、画面幅に対する割合）と粒の数（縦軸、上ほど細かい）の関係で、線やハンドルをドラッグして変更できます。右上の結果には、いまの枠に対する粒の数（例: 幅に 53 粒）と、決め手（範囲・分割数・下限・上限など）が表示されます。自主規制の最小モザイク（長辺 400px 以上は長辺÷100、最小 4px）が常に優先されるため、それより細かい粒の数は選べません
固定
「ピクセルサイズ自動」が OFF のときの設定です。全フレーム・すべての対象で同じ大きさの粒にします。「幅に並ぶ粒の数」で指定します（既定は幅に 53 粒。少ないほど粗く、多いほど細かくなります）
大きさの範囲ごと
「ピクセルサイズ自動」を ON にして選びます。対象の大きさ（カット × ID ごとの枠の代表サイズ。画面幅に対する割合で表します）の範囲ごとに、幅に並ぶ粒の数を決めます。範囲は 1〜6 個で、追加・削除・既定に戻すことができます。同じカット・同じ ID の中では粒は一定で、フレームごとにちらつきません
分割数で比例
「ピクセルサイズ自動」を ON にして選びます。対象の大きさを「細かさ（対象物の分割数）」（8〜64、既定 16）で割った値を粒の 1 辺にします。大きく映る対象ほど粒も大きくなり、値を上げるほど細かくなります。「最も粗い粒」（幅に N 粒以上）で粗さの限度を付けられます（制限なしも選べます）。同じカット・同じ ID の中では粒は一定です
以前のプロジェクト
以前の設定は開いたときに新しい設定へ変換されます。自動（対象物基準）と固定（解像度基準）の見た目は変わりません。手動（分割数）は「分割数で比例」に変換され、枠の幅ではなく対象の大きさを基準に分割するため、同じ分割数でも粒の大きさが変わることがあります（縦長の対象では粗く、横長の対象では細かくなります）。変換したときは設定画面に「以前の手動設定 (分割数 N) を変換しました」と表示されます
シャープカラー
粒の色を領域平均でなく1点サンプリングにします（Premiere ProのSharp Colors相当、既定OFF）
モザイクを掛ける
各タブの先頭のスイッチです（既定はオン）。オフにすると、そのタブで選んだ対象（全て / クラス / ID / シーン / 時間の範囲）には、プレビューでも書き出しでもモザイクが掛かりません。枠は残り、いつでもオンに戻せます。「ID 別」「シーン別」「時間別」のタブでは対象を選ぶと押せます。オフの枠のラベル（チップ）には「[モザイクオフ]」が付きます。オフの設定がある間は、編集ページの上に「モザイクを掛けない設定が N 件あります。この状態で書き出すと、該当箇所にはモザイクが掛かりません。」と「すべてオンに戻す」ボタンが表示され、エンコードの設定にも「モザイクを掛けない設定が N 件あります。該当箇所にはモザイクが掛かりません。」と表示されます。ほかの項目と同じく、最後に設定したものが優先されます（下の「設定の優先」）
反転 (外側にかける)
「ID 別」タブで検出した対象か追加した枠を選んだときだけ表示されます（回避マスクと「全て」「クラス別」「シーン別」「時間別」のタブにはありません。既定 OFF）。ON にすると、その枠の内側は元の映像のまま残し、枠の外側（背景）にモザイク / ぼかし（その枠の種類・粒・ぼかしの設定）をかけます。モザイク適用プレビュー（M）と書き出しの両方に効きます。反転した枠が同じ画面に複数あるときは、どれかの枠の内側に入る所を残します。「この設定を既定にする」には含まれず、枠を追加したときの設定の自動引き継ぎでも引き継ぎません（消しゴムで分けた片は、元の枠の設定ごと引き継ぎます）。枠の右クリックメニューの「反転 (外側にモザイク)」「反転 (外側にぼかし)」と同じ設定です（検出枠の操作）。反転した枠のあるプロジェクトは Premiere Pro へは送れません（Premiere Pro 連携）

各項目は右端の {% include icon.html name="RotateCcw" class="inline h-3.5 w-3.5 align-[-2px]" %} ボタンで既定値に戻せます。「全て」タブの「この設定を既定にする」を押すと、その内容が次に検出する動画の初期設定になります（この動画の設定は変わりません）。

時間別

「時間別」タブでは、動画の時間の範囲ごとにモザイクの見た目を変えられます。

  1. 再生ヘッドを範囲の始めに合わせて「範囲を追加」を押します。再生ヘッドの位置から 5 秒の範囲ができ、選ばれた状態になります（中身は「全て」と同じ設定です）
  2. 「開始」「終了」を合わせます。欄に「分:秒:フレーム」の形（例 1:05:12）で入力するか、再生ヘッドを動かして「現在位置を使う」を押します
  3. 種類・サイズ・不透明度などを、ほかのタブと同じように変えます
範囲の選択と削除
「対象の範囲」で範囲を選びます。「この範囲を削除」で消せます。開始が終了より後のときは「開始は終了より前にしてください」と表示されます
タイムラインの帯
時間別の範囲は、タイムラインのシーンの帯の下に帯で表示されます。帯をクリックすると、その範囲を選んだ状態で「時間別」タブが開きます。効いていない範囲（後から「全て」を変えたときなど。下の「設定の優先」）の帯は薄く表示されます
クリップの編集との関係
範囲は元の動画の時間で持つので、クリップを分割・トリム・移動しても、元の動画の同じ場面に効きます（同じ場面を 2 回使ったクリップでは 2 か所に効きます）。取り込んだ素材や空白だけの範囲には設定できません（「この範囲には元の動画の区間がありません (素材や空白だけの範囲には設定できません)」）
効く枠
範囲の中の、検出した枠と手動で追加した枠の両方に効きます（「反転 (外側にかける)」を ON にした ID を除きます）

設定の優先

同じ枠・同じフレームに「全て」「クラス別」「ID 別」「シーン別」「時間別」の設定が重なるときは、最後に設定したものが優先され、その設定の全項目がそのまま使われます（項目ごとに混ぜることはありません）。

  • 「設定した」に数えるのは、パネルで値を実際に変えたとき（{% include icon.html name="RotateCcw" class="inline h-3.5 w-3.5 align-[-2px]" %} で既定値に戻したときを含みます）と、時間別の範囲を追加・変更したときです。同じ値を選び直しても順番は変わりません
  • 後から「全て」を変えると、それより前に設定したクラス別・ID 別・シーン別・時間別の設定は効かなくなり、すべての項目が「全て」の値になります。値を元に戻しても、順番は戻りません
  • 効いていない設定をタブで開くと、「「全て」を後から変更したため、この設定は効いていません」のように表示されます。「この設定を優先する」を押すと、値を変えずにその設定が最後に設定したものになり、また効くようになります
  • 設定を変えたことでほかの設定が効かなくなったときは、「この変更で、ほかの設定 2 件が効かなくなりました」のように通知が出ます。通知の「取り消す」を押すと、その変更の前の値と順番に戻ります（直前の 1 回だけです。間に別の編集をしたときは「取り消せませんでした (ほかの編集のあとです)」と表示されます）
  • 枠を追加・貼り付けたときやつないだときに自動で付く ID 別の設定（モザイク設定の引き継ぎ）は、「設定した」に数えません。作った直後は今までと同じ見た目で、その後に設定したものが優先されます
  • 「反転 (外側にかける)」を ON にした ID は、順番に関係なくその ID の設定が使われます。すでにかかっているモザイクの枠の ID 別の設定（検出で入った粒を含む）も、順番に関係なく使われます。モザイク除外・回避マスク・信頼度しきい値も、順番に関係なく効きます
  • 2.18 より前に作ったプロジェクトは、開いても今までと同じ見た目です（順番の記録が無い設定は、今までどおり ID 別・クラス別・シーン別・全ての順で優先されます）
  • 2.18 より前のバージョンの Deepmosaic でプロジェクトを開くと、時間別の設定と順番は無視され、今までの順で優先されます（そのバージョンで保存すると、時間別の設定と順番は失われます）
  • 時間別の設定は Premiere Pro 連携には渡りません
{% include docs-h2.html kicker="編集" title="人物ギャラリー" %}

ヘッダーの「人物ギャラリー」（P）を開くと、検出された顔が人物ごとにまとめて表示されます（顔らしさが低い検出は人物に含めず「その他」に回します）。人物単位でモザイクの ON / OFF や性別の修正ができ、同じ人物が別々に検出されている場合は 1 つに統合できます。パネルはドラッグで移動できます。

人物カード
代表画像、性別バッジ、トラック数、出現時間、初出時刻。カードをクリックすると初出フレームへジャンプします
性別の修正
性別バッジをクリックして「男性顔にする」「女性顔にする」「検出結果に戻す」。クラス別のモザイク設定（男性顔 / 女性顔）の適用先が変わります
モザイクの ON / OFF
「モザイクを OFF にする」でその人物のすべてのトラックをモザイク対象から外します（例: 出演者以外の顔にはモザイクをかけない、など）。「モザイクを ON に戻す」で戻ります
人物の統合
カードを別のカード（「その他」のカードを含む）にドラッグ&ドロップすると同一人物として統合されます。統合したカードには「統合を解除」が表示されます。タイムラインや右クリックメニューで統合した追跡 ID も、人物ギャラリーでは 1 人として表示されます
その他
人物としてまとめられなかった顔のトラックは「その他 N 件（短い出現 a・小さい顔 b・顔らしさが低い c・判定不能 d）」に折りたたまれます。押すと理由ごとに並び、60 件ずつ「さらに表示」で続きを出せます。ここでも 1 件ずつモザイクの ON / OFF を切り替えられ、別のカードへドラッグ&ドロップして統合できます
人物を再集計
長い動画などで同じ人物がまとまっていないときは、パネルの「人物を再集計」で動画の顔をもう一度まとめ直せます。数分かかることがあり、その間は「人物を再集計しています」と進捗が表示されます（途中で閉じることはできません）。2 回目以降は動画を読み直さないため、短い時間で終わります。人物にまとまっていない顔が多いときは「長い動画では人物にまとまっていないことがあります」と案内が出ます。ボタンは、対応した検出エンジン（2.7.2 以降）で扱えるプロジェクトのときだけ表示されます（Web 版にはありません）

旧バージョンで検出したプロジェクトでは「この動画は旧バージョンで検出されています。人物一覧を使うには再検出してください。」と表示されます。その場合は動画を読み込み直して検出してください。

タイムラインの「クリップレーン」には、書き出す映像の並びが帯（クリップ）で表示されます。最初は元の動画（検出元）1 本だけのクリップで、トリム・分割・削除で不要な部分を切り詰めたり、取り込んだ素材を前後に足したりできます。クリップレーンの上にはテキスト、下には音声のレーンがあり、どのレーンも書き出す映像の時間で並びます。

編集した内容はプレビューにそのまま反映され、エンコードで書き出されます。モザイクは元の動画の区間にかかります。

選択
帯をクリックすると選択され、帯の右上に削除の ✕ が出ます
トリム
帯の左右の端をドラッグして、クリップの開始・終了を詰めます（最短 1 フレーム）。シーンの境界や再生ヘッドに近づくと吸着します。取り込んだ動画は素材の長さまで、画像のクリップは好きな長さまで伸ばせます
分割（Ctrl+K / Ctrl+Shift+K）
タイムラインのズームボタンの右にある {% include icon.html name="Scissors" class="inline h-3.5 w-3.5 align-[-2px]" %} ボタン、または Ctrl+K（タイムラインにフォーカスがあるときは Ctrl+Shift+K）で、再生ヘッドの位置でクリップを 2 つに分け、同時にシーンも分けます。分けた瞬間にクリップの帯が 2 つになり、継ぎ目にカットの印（斜線とはさみ）、シーンの帯に新しい番号が付きます。後半が選択されるので、続けてトリムや削除ができます。「元に戻す」1 回でクリップとシーンの両方が戻ります
削除
選択して帯の ✕、Backspace / Delete キー、または右クリックメニューの「削除」。後ろのクリップは前に詰まります（リップル削除）
並べ替え・移動
帯をつかんで左右にドラッグすると、置いた位置に応じて並べ替えられます。他のクリップの端・シーンの境界・再生ヘッドに吸着します。今の終わりより右へ運ぶこともできます。Ctrl+← / Ctrl+→ で選択中のクリップを 1 フレームずつ動かせます
空白
前のクリップから離して置くと、その間が空白（黒い画面・無音）になり、斜線の帯に「空白 N フレーム」と表示されます。書き出してもそのまま黒い画面・無音になります。空白を詰めるときは、クリップを前のクリップの端までドラッグします（端に吸着します）
継ぎ目
クリップの継ぎ目には {% include icon.html name="Scissors" class="inline h-3.5 w-3.5 align-[-2px]" %} のバッジ（はさみ）が出ます。バッジを押すと「フェード」「つなぎ」を選ぶ小さなメニューが開き、選ぶとサイドバーの該当のタブ（フェード / トランジション）がその継ぎ目にフォーカスした状態で開きます。秒数や種類はそこで設定します
フィルムストリップ
動画のクリップの帯には、中身のサムネイルが並びます（フィルムストリップ）。画像のクリップには画像そのものが表示されます。サムネイルの読み込みが終わるまでは無地で表示されます

右クリックメニューとクリップボード

クリップ・テキスト・音声トラックの帯を右クリックすると「複製」「コピー」「ペースト」「削除」のメニューが出ます。レーンの何もない所を右クリックしたときは「ペースト」だけが出ます。メニューとショートカットは同じ動作です。

複製（Ctrl+D）
クリップはすぐ後ろに、テキストは帯のすぐ後ろに、音声トラックは同じ位置に複製します
コピー / ペースト（Ctrl+C / Ctrl+V）
コピーした要素を貼り付けます。テキストと音声トラックは再生ヘッドの位置に、クリップは選択中のクリップ（選択していなければ再生ヘッドのあるクリップ）のすぐ後ろに入ります。クリップボードに入るのは直前にコピーした 1 つだけで、パソコンのクリップボードとは別です（編集ページの中でだけ使えます）
削除（Delete）
選択中の要素を削除します。プレイヤーを最後に操作していたときの Delete は検出枠の削除になります（ショートカット）

取り消しと履歴

タイムラインの編集（クリップ・テキスト・音声・透かし・フェード・トランジション・素材の追加）は、検出枠の編集とは別の履歴に記録されます。タイムラインのズームボタンの右にある「元に戻す」（Ctrl+Shift+Z）/「やり直す」（Ctrl+Shift+Y）で 1 手ずつ、{% include icon.html name="History" class="inline h-3.5 w-3.5 align-[-2px]" %} 履歴ボタンの一覧から選ぶと、その操作までまとめて戻せます。一覧には「分割」「トリム」「移動」「テキスト追加」などの操作名と時刻が新しい順に並び、最大 100 件まで残ります。履歴は動画を開き直すと空になります。

タイムラインの高さと折りたたみ

高さの変更
タイムラインの上端をドラッグすると、220〜720px の範囲で高さを変えられます（プレイヤーには常に 200px 以上が残ります）。上端を選んで ↑ / ↓ キーでも 16px ずつ調整でき、ダブルクリックで既定の 400px に戻ります
折りたたみ（Ctrl+Shift+T）
ツールバー右端の {% include icon.html name="ChevronDown" class="inline h-3.5 w-3.5 align-[-2px]" %} ボタンで、タイムラインをツールバー 1 行だけに折りたたみ、プレイヤーを大きく使えます。もう一度押すと展開します

高さと折りたたみの状態は、次に編集ページを開いたときも引き継がれます。

{% include docs-h2.html kicker="タイムライン編集" title="メディア（素材の取り込み）" %}

サイドバーの「メディア」（A）で開くメディアパネルで、タイムラインに使う動画・音声・画像の素材を取り込みます。取り込んだ素材はプロジェクトフォルダの中にコピーされるため、元のファイルを動かしても使い続けられます（プロジェクトの書き出しの zip にも入ります）。

取り込み
「メディアをインポート」で種類（動画 / 音声 / 画像）を選んでファイルを選ぶか、エクスプローラーからファイルを編集ページにドラッグ&ドロップします
対応形式と上限
動画: 動画の読み込みと同じ形式（1 ファイル 2GB まで）/ 音声: MP3・WAV・AAC・M4A・FLAC・OGG・Opus（200MB まで）/ 画像: PNG・JPEG・WebP・BMP（50MB まで）
タイムラインに追加
素材の行の「タイムラインに追加」で、動画はクリップとして末尾に、音声は音声トラックとして再生ヘッドの位置に置かれます。素材をレーンへドラッグして好きな位置に置くこともできます（動画・画像はクリップレーン、音声は音声レーン）
画像
「タイムラインに追加」で 5 秒の画像クリップとして置かれ、帯の端をドラッグすると好きな長さに伸縮できます。「透かしに設定」を選ぶと、全編に重ねるロゴとして使えます（透かし）
動画の音声
取り込んだ動画をクリップとして置いた区間は、書き出しではその動画の音声が入らず無音になります（音声トラックの BGM などは流れます）。取り込んだ動画の音声を使いたいときは、同じ素材を音声レーンにもドロップします
素材の削除
行の削除ボタンで、素材をプロジェクトから削除します。ファイルの実体も消えるため取り消せません（タイムラインの取り消しでも戻りません）。タイムラインで使っている素材は削除できません

取り込んだ素材は AI 検出の対象外です。素材の区間にはモザイクがかからず、検出枠の追加や消しゴムも使えません。モザイクが必要な映像は、先に動画として読み込んで検出・書き出ししたものを取り込んでください。

{% include docs-h2.html kicker="タイムライン編集" title="テキスト" %}

サイドバーの「テキスト」で、映像に文字を焼き込みます。テキストはいくつでも追加でき、それぞれに表示する区間・位置・書式を設定できます。表示する区間は、書き出す映像のフレーム番号で指定します。

追加
「テキストを追加」で、全編に表示される「テキスト」が下中央に追加されます。一覧から選んで編集します
表示する区間
開始・終了のフレーム番号を入れます。「現在位置に」で再生ヘッドの位置が入ります。「最後まで表示」にチェックすると映像の最後まで表示します
位置
プレビュー上の文字をドラッグすると、好きな位置へ自由に動かせます。数値では「位置 X / Y (%)」（左上からの位置）で指定します。「配置プリセット」（左上〜右下の 9 か所）を選ぶと、端から 2% の余白で寄せます
大きさ
文字の高さを、映像の高さに対する割合で指定します（2〜50%、既定 6%）
フォントと太字
フォントは 5 種類: ゴシック（既定）/ 游ゴシック / 明朝 / MS ゴシック / BIZ UDゴシック。「太字」にもできます。パソコンに入っていないフォントは同じ系統のフォント、それも無ければゴシックで焼き込まれます。太字の無いフォント（MS ゴシックなど）は通常の太さになります
色・縁取り・不透明度
文字の色（既定: 白）、縁取りの太さ（文字の高さの 0〜25%、既定 8%）と色（既定: 黒）、不透明度（既定 100%）

テキストレーン

タイムラインのクリップレーンの上に、テキストごとに 1 段ずつ、表示する区間の帯が並びます（テキストレーン）。帯をドラッグすると表示する区間ごと動き、両端をドラッグすると開始・終了を変えられます。帯を選ぶと、テキストパネルでも同じテキストが選ばれます。右クリックで複製・コピー・ペースト・削除ができます。

{% include docs-h2.html kicker="タイムライン編集" title="透かし" %}

サイドバーの「透かし」で、ロゴなどの画像 1 枚を書き出す映像の全編に重ねます。先にメディアパネルで画像を取り込んでおきます（メディアパネルの画像の「透かしに設定」からも設定できます）。

画像
取り込んだ画像から選びます。「なし」で透かしを外します
位置
左上〜右下の 9 か所から選びます（既定: 右下）
大きさ
画像の幅を、映像の幅に対する割合で指定します（1〜100%、既定 15%）。縦横比は保たれます
不透明度
0〜100%（既定 80%）
横の余白 / 縦の余白
映像の端からの距離を、映像の幅・高さに対する割合で指定します（0〜50%、既定 2%）

文字の透かしを入れたいときは、全編に表示するテキストを使います。

{% include docs-h2.html kicker="タイムライン編集" title="音声と BGM" %}

サイドバーの「音声」で、元の動画の音声と、BGM などの音声トラックを調整します。書き出しでは、元の動画の音声とすべての音声トラックが重ねて（ミックスして）出力されます。

検出元の音声
元の動画の音量（-40〜+12dB）とミュート
音声トラックの追加
メディアパネルの音声素材の「タイムラインに追加」（再生ヘッドの位置に置かれます）、または音声素材を音声レーンへドラッグします。動画素材を音声レーンに置くと、その動画の音声だけを使えます
音量 / ミュート
トラックごとに -40〜+12dB。ミュートでそのトラックだけを一時的に消します
フェードイン / フェードアウト
トラックごとに、鳴り始めと終わりを 0〜20 秒でフェードさせます

音声レーンと波形

タイムラインのクリップレーンの下に、音声トラックごとに 1 段ずつ帯が並びます（音声レーン）。帯には BGM の波形が描かれ、曲の盛り上がりや無音の位置を見ながら合わせられます。帯をドラッグすると位置が動き、両端をドラッグすると使う範囲（曲の頭と終わり）を詰められます。BGM はクリップの間の空白をまたいで流れ続けます。長さの分からない音声は、帯の代わりに「長さ不明」と表示されます。

{% include docs-h2.html kicker="タイムライン編集" title="フェード" %}

書き出す映像を黒からフェードイン、黒へフェードアウトさせます。映像全体の先頭と末尾にかける「全体のフェード」と、クリップごとの先頭と末尾にかける「クリップのフェード」があります。全体のフェードはサイドバーの「フェード」で秒数を入れます。クリップのフェードは、継ぎ目のはさみから「フェード」を選んで開く「選択中の継ぎ目」の節か、クリップを選んだときに出る「選択中のクリップ」の節で入れます。秒数はサイドバーだけで入力します（タイムラインの上では秒数を入力しません）。

はさみから選ぶ
クリップの継ぎ目の {% include icon.html name="Scissors" class="inline h-3.5 w-3.5 align-[-2px]" %} のバッジ（はさみ）を押すと（選んで Enter / Space でも可）、「フェード」「つなぎ」の 2 項目のメニューが開きます。↑ / ↓ で項目を移り、Esc かメニューの外のクリックで閉じます。「フェード」を選ぶと、サイドバーの「フェード」がその継ぎ目にフォーカスした状態で開きます（「つなぎ」はトランジション）
全体のフェード
サイドバーの「フェード」で、映像全体のフェードインとフェードアウトの秒数を入れます。入れるとルーラーの端にその長さのランプ（三角の印）が出ます
クリップのフェード
「選択中の継ぎ目」の節では、継ぎ目の前のクリップのフェードアウトと後ろのクリップのフェードインを入れます。映像の最初のクリップの先頭や最後のクリップの末尾は、クリップを選んで「選択中のクリップ」の節で入れます。入れると帯の下端にランプが出ます。フェードするのはそのクリップの映像だけで（元の動画のクリップは音声も）、透かしとテキストは暗くなりません
秒数の調整
秒で指定し（0〜20 秒、0 秒でフェードなし）、秒数の横に実際にフェードするフレーム数が表示されます。ランプをクリック（選んで Enter でも可）してもサイドバーの「フェード」が開き、クリップのランプから開いたときはそのクリップが選ばれます。「外す」で選択中のフェードを両方とも外します
置けない所
トランジションのある継ぎ目の側の端にはクリップのフェードを入れられず、サイドバーの入力欄が押せなくなって理由が出ます。トランジションを外すと設定できます
先頭へ / 末尾へ
サイドバーの「フェード」のボタンで、再生ヘッドを映像の先頭 / 末尾へ動かします。全体のフェードは両端にだけかかるので、プレビューで効き具合を確認するときに使います

フェードは書き出しと同じようにプレビューにも反映されます。全体のフェードとクリップのフェードが重なるフレームには両方がかかります。音声トラックごとのフェードは音声と BGMで、クリップの継ぎ目の切り替えはトランジションで設定します。

{% include docs-h2.html kicker="タイムライン編集" title="トランジション" %}

隣り合うクリップの継ぎ目に、切り替えの効果（トランジション）を付けます。継ぎ目のはさみを押して「つなぎ」を選ぶと、サイドバーの「つなぎ」（ドロワーの見出しは「トランジション」）がその継ぎ目にフォーカスして開くので、種類と長さを選びます。種類と長さはサイドバーだけで入力します（タイムラインの上では入力しません）。クリップが 1 つだけのときは継ぎ目がないため置けません。トランジションのある継ぎ目の側の端には、クリップのフェードを置けません。

種類
フェード / ディゾルブ / ワイプ（左へ・右へ）/ スライド（左へ・右へ）/ 黒フェード / 白フェード の 8 種類
置き方
タイムラインの継ぎ目の {% include icon.html name="Scissors" class="inline h-3.5 w-3.5 align-[-2px]" %} のバッジ（はさみ）を押し、メニューから「つなぎ」を選びます。サイドバーの継ぎ目の一覧（「前のクリップ → 次のクリップ」）でその継ぎ目の行が選ばれるので、種類を選び（「なし」で外れます）、長さを 0.1〜5 秒で指定します。置くと継ぎ目に前後のクリップが重なる長さの斜線の帯が出ます。前後のクリップがその長さだけ重なるため、映像全体はその分短くなります
帯とバッジ
斜線の帯をクリック（選んで Enter でも可）すると、メニューを経ずにサイドバーの「つなぎ」が開きます。バッジにマウスを乗せると、今の種類と秒数が表示されます
空白のある継ぎ目
空白（黒い画面）を挟んだ継ぎ目には置けません。サイドバーのその継ぎ目の行に理由が表示されます（空白は自動では詰めません）。設定した後で間に空白を作るとトランジションは効かなくなり、空白を詰めると元に戻ります
クリップのフェード
クリップのフェードが入っている継ぎ目では、行に「つなぎを置くとこの継ぎ目のフェードは書き出しで無視されます」と注記が出ます。フェードは自動では消えません
プレビュー
重なりのあいだは、前後のクリップを書き出しと同じ種類の切り替えで合成して表示します。後ろのクリップの側には、プレビューではモザイクが表示されません（書き出しではかかります）
