{% include docs-h2.html kicker="編集" title="編集ページ" %}

ホーム画面の動画カードをクリックすると編集ページが開きます。画面は上部の「ヘッダー」、端に縦に並ぶ「サイドバー」（と、その隣に開くドロワー）、中央の「動画プレイヤー（編集ツールバー内蔵）」、下部の「タイムライン」で構成されます。

ヘッダー左
{% include icon.html name="ArrowLeft" class="inline h-3.5 w-3.5 align-[-2px]" %} 戻るボタン、動画タイトル、9桁のプロジェクトIDバッジ（クリックでコピー）
メタ情報
動画の長さ / 総フレーム数 / fps / 解像度 / 追加日
ヘッダー右
フォルダを開く / 人物ギャラリー / Premiere Pro へインポート / エンコード の各ボタンと保存状態表示。エンコードの待ち行列はメニューバーの「キュー」で確認します
保存状態
編集は操作の約 1 秒後に自動保存されます。「保存中」「未保存」「保存済」がリアルタイムに表示され、失敗時は「保存失敗」と出ます。エンコードの開始時にも未保存分が保存されます
サイドバー
メディア / テキスト / 透かし / 音声 / フェード / トランジション の 6 項目。押すと隣にドロワーが開き、素材の取り込みやテキスト・BGM などの設定ができます（サイドバーとドロワー）

シーンの帯、テキスト・クリップ・音声のレーン、検出クラスごとの行が並びます。ツールバーのすぐ下には、フェードとトランジションのチップを並べた「効果」のパレットがあります（プレイヤーとタイムライン / クリップの編集 / フェード）
ツールチップ
ボタンにマウスを乗せると、すぐに（約 0.15 秒で）その機能の説明とショートカットキーがツールチップで表示されます
詳細データがありません
検出結果のファイルが見つからないときに表示されます（プロジェクトフォルダの移動や削除など）。この画面の「プロジェクトを削除」で一覧から取り除けます
{% include docs-h2.html kicker="編集" title="プレイヤーとタイムライン" %}

プレイヤーには検出枠（bbox）がクラス別の色でオーバレイ表示されます。枠はドラッグで位置・サイズを直接編集できます。コマ送り・シークに対応し、下部のタイムラインには検出の分布とシーン（カット）の帯が描画され、クリックで任意のフレームへジャンプできます。

検出クラスは色分けされます: 局部（赤）/ 男性顔（青）/ 女性顔（ピンク）/ ユーザ作成（黄）。枠の上のラベル（チップ）には「クラス名 #ID（3 文字のコード） 信頼度%」が表示され、手動で追加した枠は「ユーザ」、モザイクの対象から外したトラックには「[モザイク除外]」が付きます。

再生コントロール

再生 / コマ送り
先頭へ（Home）/ 1 コマ戻る（←）/ 再生・一時停止（Space）/ 1 コマ進む（→）/ 末尾へ（End）。Shift を押しながらの矢印で 10 コマ移動。マウスホイールでもコマ送りできます
シーク
スライダーのドラッグ、タイムラインのクリック / ドラッグ、時刻とフレーム番号（frame N / M）の表示
ミュート（V）
プレビューの音声を消します。書き出しには影響しません
オーバーレイの表示切替（H）
検出枠・ラベル・ID・確率をすべて隠して映像だけを確認します。編集内容は変わりません
再生速度
ツールバーで 0.25x / 0.5x / 1x / 1.5x / 2x / 4x から選択（, で遅く . で速く）

検出枠の操作

選択
枠をクリックすると太枠と 8 つのハンドルが表示されます
移動 / サイズ変更
枠の内側をドラッグで移動、ハンドルをドラッグでサイズ変更。再生中でもドラッグできます
削除
選択して Delete、枠をダブルクリック、または右クリックメニューの「この BBox を削除」。削除はそのフレームの枠だけに適用されます（同じ ID の他のフレームは残ります）
連続削除（消しゴム）
映像の上で右ボタンを押したままドラッグすると、カーソルが円形の消しゴムになり、円に触れた枠を削除します。押したまま再生したりホイールでコマ送りしたりすると、流れていくフレームの枠も続けて消せます（右ボタンを動かさずに離したときは、いつもの右クリックメニューが開きます）
ID ごと削除（チップの ✕）
検出した枠のチップの右端にある ✕ を押すと、その ID の枠を全フレームからまとめて削除します。削除するフレーム数を示した確認が出ます。手動で追加した枠のチップには ✕ は出ません
右クリックメニュー
顔の枠では「男性顔に変更」「女性顔に変更」（検出された性別の修正）。すべての枠で「モザイク対象外にする」「モザイク対象に戻す」（そのトラック全体をモザイクの対象から外す / 戻す）、「この BBox を削除」、検出した枠では「この ID をすべて削除」（チップの ✕ と同じ）。連続 bbox に軌跡があるときは「移動軌跡をクリア」
追跡 ID の統合
同じ対象なのに別の ID に分かれてしまったときは、片方の枠をクリックして選択し、もう片方の枠を右クリックして「選択中の #XXX に統合」を選びます。統合すると 1 つの ID として扱われ（タイムラインの行、ID 別のモザイク設定、書き出しのすべて）、間に枠の無いフレームがあれば連続 BBox で自動的に補間されます。統合できるのは同じクラスで時間が重ならない 2 つだけです（同時に映っているものは別の対象です）。元に戻すには統合先の枠を右クリックして「統合を解除」を選びます。
モザイク除外の注意表示
対象から外したトラックがあると「N トラックをモザイク除外中です」と常時表示されます。「すべてモザイク対象に戻す」で一括で戻せます。除外した箇所は書き出してもモザイクがかかりません

検出枠の選択・追加・消しゴムは、再生ヘッドが元の動画（検出元）の区間にあるときだけ使えます。取り込んだ素材の区間は AI 検出の対象外のため、枠はありません。

タイムライン

タイムラインは上から、ツールバー、目盛り、シーン（カット）の帯、テキスト・クリップ・音声のレーン（クリップの編集）、検出クラスごとの行の順に並びます。クラスの行には検出のある区間が帯で描かれ、行頭の {% include icon.html name="ChevronDown" class="inline h-3.5 w-3.5 align-[-2px]" %} で追跡 ID ごとの行に展開できます。モザイク対象から外したトラックは薄く表示されます。タイムラインは書き出す映像の時間で並ぶので、クリップをトリムしたり動かしたりすると、検出の帯も一緒に動きます。

タイムラインは Ctrl+ホイール、またはツールバー左端の拡大・縮小ボタンで最大 16 倍まで拡大できます。高さの変更と折りたたみはクリップの編集を参照してください。

{% include docs-h2.html kicker="編集" title="拡大・縮小とパン" %}

小さな対象の枠を正確に合わせるために、プレイヤーの映像を最大 8 倍まで拡大できます。拡大中も枠の移動・サイズ変更・追加・削除はそのまま行えます。

拡大 / 縮小
Ctrl+ホイール（カーソル位置を中心に拡大縮小）、+ / - キー、またはプレイヤー右上の {% include icon.html name="Maximize2" class="inline h-3.5 w-3.5 align-[-2px]" %} ボタン。現在の倍率はボタンの間に表示されます
パン（表示位置の移動）
中ボタン（ホイール）ドラッグ。拡大中は枠の無い余白の左ドラッグでも動かせます
リセット
0 キー、または「ズームをリセット」ボタンで等倍・中央に戻ります
{% include docs-h2.html kicker="編集" title="検出枠の追加（1f と ∞）" %}

検出されなかった箇所には、ツールバーの「1f」「∞」で枠を手動で追加できます。追加した枠は現在のフレームの中央に「ユーザ」クラス（黄）で置かれるので、ドラッグで位置と大きさを合わせます。手動の枠にもモザイク設定（ID 別を含む）がそのまま適用されます。

1f（1）
このフレームだけに枠を置きます。前後のフレームには影響しません。数フレームだけ検出が抜けた「中抜け」の補修に向いています
∞ 連続 bbox（2）
置いたフレームから先のすべてのフレームに同じ位置で枠が続きます。動画の最後まで続けたくないときは、終わらせたいフレームで枠を削除してください（削除したフレームの手前までが有効範囲として確定します）
連続 bbox を動かす
再生しながら ∞ の枠をドラッグすると、その動きが軌跡として記録され、被写体の移動に追従させられます。記録した軌跡は右クリックメニューの「移動軌跡をクリア」で消せます
取り消し
「現在のフレームをリセット」（Ctrl+Z）は現在のフレームの編集を元に戻します。∞ の枠を削除で終わらせた直後に押すと、まず終端の確定が解除されます

枠の追加・移動・削除はすべて自動保存され、エンコードと Premiere Pro 連携の両方に反映されます。

{% include docs-h2.html kicker="編集" title="シーン（カット）" %}

検出時に映像のカット（場面の切り替わり）が自動で判定され、タイムラインの上部にシーンの帯として表示されます。シーンは「ピクセルサイズ自動」の粒度を一定に保つ単位であり、モザイク設定をシーンごとに変える単位でもあります。

シーンへ移動
帯をクリックすると、そのシーンの先頭フレームへジャンプします。帯には番号（#1, #2 …）が表示され、マウスオーバーで区間が確認できます
分割（Ctrl+K）
タイムラインのツールバー（拡大・縮小ボタンの右）の {% include icon.html name="Scissors" class="inline h-3.5 w-3.5 align-[-2px]" %} ボタン、または Ctrl+K で、現在のフレームを境にシーンを 2 つに分けます。自動判定が見逃したカットや、同じカット内で設定を変えたい箇所に使います
境界の調整
帯の境目をドラッグすると、前後のシーンの開始・終了が同時に動きます
削除
帯にマウスを乗せると出る ✕（このシーンを削除）で、隣のシーンと結合します

シーンの変更は編集データとして保存され、検出結果そのものは変わりません。「全編集リセット」で自動判定の状態に戻ります。シーンの分割は書き出す映像を切りません。映像そのものを切り分けるときは、クリップの分割（Ctrl+Shift+K、クリップの編集）を使います。

{% include docs-h2.html kicker="編集" title="編集ツールバー" %}

プレイヤーと再生コントロールの間にあるツールバーに、編集機能が集約されています。各ボタンにマウスを乗せるとショートカットキーが表示されます。

欠落フレームジャンプ
検出が無いフレームへ前後にジャンプ。対象クラス（全クラス / 局部 / 男性顔 / 女性顔）を選んで絞り込めます。ショートカット: [ / ]
bbox追加（1f / ∞）
現在のフレーム中央に検出枠を追加します。「1f」はこのフレームのみ、「∞」は以降のフレームすべてに連続表示。追加後はドラッグで調整（検出枠の追加）。ショートカット: 1 / 2
空白のみ再生（B）
検出枠を含むフレームを自動でスキップし、bboxの無いフレームだけを連続再生します。見落としの確認に便利です
プレビュー切替（B / M）
bbox枠表示とモザイク適用プレビューを切り替えます。モザイク表示では書き出し結果に近い見た目をその場で確認できます。ショートカット: M
モザイク設定（G）
モザイク設定パネルを開きます（次章）
現在のフレームをリセット
現在のフレームの編集（枠の追加・移動・削除）を検出結果の状態に戻します。ショートカット: Ctrl+Z
全編集リセット
枠の編集・モザイク設定・シーン・人物の統合などすべての編集を破棄します（確認ダイアログ付き・取り消し不可）
クラス表示（C）
表示する検出クラスをドロップダウンで絞り込みます（例: 局部のみ表示）。表示を消したクラスもモザイクの対象からは外れません
再生速度
0.25x / 0.5x / 1x / 1.5x / 2x / 4x から選択
{% include icon.html name="HelpCircle" class="inline h-3.5 w-3.5 align-[-2px]" %} ショートカット一覧
マウスを乗せるとキーボードショートカットの凡例が表示されます
{% include docs-h2.html kicker="編集" title="モザイク設定パネル" %}

モザイクの見た目を4つの適用範囲（タブ）で設定できます。優先順位は ID別 > クラス別 > シーン別 > 全て で、狭い範囲の設定が優先されます。パネルはヘッダーをドラッグで自由な位置に移動でき、開いたまま編集を続けられます。値を変えると、モザイク適用プレビュー（M）にその場で反映されます。

適用範囲タブ
全て（グローバル既定）/ クラス別（局部・顔など）/ ID別（追跡された個々の対象）/ シーン別（カット単位）。ID 別とシーン別では対象をプルダウンで選びます。オーバライド中の範囲には「オーバライド中」と表示され、「クリア」で個別に解除できます
信頼度しきい値
指定した信頼度以上の検出だけを表示・モザイク対象にします（0〜100%、タブに依らないグローバル設定）
種類
モザイク（ブロック状）/ ぼかし（ガウスぼかし）。既定: モザイク
サイズ（bbox拡張率）
検出枠を中心から拡大・縮小してモザイク範囲を調整（0.50x〜2.00x）。既定: 1.05x。ギリギリを避けたいときは大きめに
不透明度
{%- comment -%} TICKET-SITE-30: 旧文面は「下げると元の映像が透けます」。意味は 正しいが、**単独で抜粋されると「モザイクを透かせる機能」と誤読され得る** サイト内で唯一の表現だった。意味を保ったまま「隠蔽が弱くなる」に 言い換え、既存の確定語彙 (隠蔽率) に寄せた。 {%- endcomment -%}
モザイク/ぼかしをどれだけ強く合成するか（0〜100%）。既定の 100% で対象を完全に覆います。値を下げるほど隠蔽が弱くなるため、通常は 100% のまま使います
エッジぼかし
モザイク領域のふちをぼかして背景となじませます（0〜64px）。既定: 6px。Premiere Pro のフェザーに相当します
ピクセルサイズ自動
対象物のサイズに連動してモザイクの粒を自動計算（既定ON）。シーン内・同一ID内で粒度は一定に保たれ、フレームごとにちらつきません。「細かさ」（対象物の分割数 8〜64、既定 16）と最小セル（2〜32px、既定 8px）/ 最大セル（8〜128px、既定 64px）で調整できます
ブロック分割数
自動OFF時（と「ぼかし」のとき）、領域を縦横に何分割するかで粗さを固定します（8〜64、既定 16、Premiere Proと同方式）
シャープカラー
粒の色を領域平均でなく1点サンプリングにします（Premiere ProのSharp Colors相当、既定OFF）
最小モザイクの注記
パネル上部に、書き出し解像度での最小モザイク（自主規制基準: 長辺÷100、最小 4px）が表示されます。これより細かい設定にしても、書き出し時に自動でこの粒度へ丸められます。ぼかしは対象外です

各項目は右端の {% include icon.html name="RotateCcw" class="inline h-3.5 w-3.5 align-[-2px]" %} ボタンで既定値に戻せます。「全て」タブの「この設定を既定にする」を押すと、その内容が次に検出する動画の初期設定になります（この動画の設定は変わりません）。

{% include docs-h2.html kicker="編集" title="人物ギャラリー" %}

ヘッダーの「人物ギャラリー」（P）を開くと、検出された顔が人物ごとにまとめて表示されます。人物単位でモザイクの ON / OFF や性別の修正ができ、同じ人物が別々に検出されている場合は 1 つに統合できます。パネルはドラッグで移動できます。

人物カード
代表画像、性別バッジ、トラック数、出現時間、初出時刻。カードをクリックすると初出フレームへジャンプします
性別の修正
性別バッジをクリックして「男性顔にする」「女性顔にする」「検出結果に戻す」。クラス別のモザイク設定（男性顔 / 女性顔）の適用先が変わります
モザイクの ON / OFF
「モザイクを OFF にする」でその人物のすべてのトラックをモザイク対象から外します（例: 出演者以外の顔にはモザイクをかけない、など）。「モザイクを ON に戻す」で戻ります
人物の統合
カードを別のカードにドラッグ&ドロップすると同一人物として統合されます。統合したカードには「統合を解除」が表示されます
その他（小さい顔など）
人物としてまとめられなかった顔のトラックが並びます。ここでも 1 件ずつモザイクの ON / OFF を切り替えられます

旧バージョンで検出したプロジェクトでは「この動画は旧バージョンで検出されています。人物一覧を使うには再検出してください。」と表示されます。その場合は動画を読み込み直して検出してください。

{% include docs-h2.html kicker="タイムライン編集" title="クリップの編集" %}

タイムラインの「クリップレーン」には、書き出す映像の並びが帯（クリップ）で表示されます。最初は元の動画（検出元）1 本だけのクリップで、トリム・分割・削除で不要な部分を切り詰めたり、取り込んだ素材を前後に足したりできます。クリップレーンの上にはテキスト、下には音声のレーンがあり、どのレーンも書き出す映像の時間で並びます。

編集した内容はプレビューにそのまま反映され、エンコードで書き出されます。モザイクは元の動画の区間にかかります。

選択
帯をクリックすると選択され、帯の右上に削除の ✕ が出ます
トリム
帯の左右の端をドラッグして、クリップの開始・終了を詰めます（最短 1 フレーム）。シーンの境界や再生ヘッドに近づくと吸着します。取り込んだ動画は素材の長さまで、画像のクリップは好きな長さまで伸ばせます
分割（Ctrl+Shift+K）
ツールバー右側の {% include icon.html name="SquareSplitHorizontal" class="inline h-3.5 w-3.5 align-[-2px]" %} ボタン、または Ctrl+Shift+K で、再生ヘッドの位置でクリップを 2 つに分けます。キーで分割したときは後半が選択されるので、続けてトリムや削除ができます。分割した継ぎ目にはカットの印（斜線とはさみ）が付きます
削除
選択して帯の ✕、Backspace / Delete キー、または右クリックメニューの「削除」。後ろのクリップは前に詰まります（リップル削除）
並べ替え・移動
帯をつかんで左右にドラッグすると、置いた位置に応じて並べ替えられます。他のクリップの端・シーンの境界・再生ヘッドに吸着します。今の終わりより右へ運ぶこともできます。Ctrl+← / Ctrl+→ で選択中のクリップを 1 フレームずつ動かせます
空白
前のクリップから離して置くと、その間が空白（黒い画面・無音）になり、斜線の帯に「空白 N フレーム」と表示されます。書き出してもそのまま黒い画面・無音になります。空白を詰めるときは、クリップを前のクリップの端までドラッグします（端に吸着します）
継ぎ目
クリップの継ぎ目には {% include icon.html name="Scissors" class="inline h-3.5 w-3.5 align-[-2px]" %} のバッジが出ます。タイムライン上部の「効果」から「つなぎ」のチップをバッジへドラッグするとトランジションを置けます。バッジを押すとサイドバーの「つなぎ」が開き、種類と長さを変えられます
フィルムストリップ
動画のクリップの帯には、中身のサムネイルが並びます（フィルムストリップ）。画像のクリップには画像そのものが表示されます。サムネイルの読み込みが終わるまでは無地で表示されます

右クリックメニューとクリップボード

クリップ・テキスト・音声トラックの帯を右クリックすると「複製」「コピー」「ペースト」「削除」のメニューが出ます。レーンの何もない所を右クリックしたときは「ペースト」だけが出ます。メニューとショートカットは同じ動作です。

複製（Ctrl+D）
クリップはすぐ後ろに、テキストは帯のすぐ後ろに、音声トラックは同じ位置に複製します
コピー / ペースト（Ctrl+C / Ctrl+V）
コピーした要素を貼り付けます。テキストと音声トラックは再生ヘッドの位置に、クリップは選択中のクリップ（選択していなければ再生ヘッドのあるクリップ）のすぐ後ろに入ります。クリップボードに入るのは直前にコピーした 1 つだけで、パソコンのクリップボードとは別です（編集ページの中でだけ使えます）
削除（Delete）
選択中の要素を削除します。プレイヤーを最後に操作していたときの Delete は検出枠の削除になります（ショートカット）

取り消しと履歴

タイムラインの編集（クリップ・テキスト・音声・透かし・フェード・トランジション・素材の追加）は、検出枠の編集とは別の履歴に記録されます。ツールバー右側の「元に戻す」（Ctrl+Shift+Z）/「やり直す」（Ctrl+Shift+Y）で 1 手ずつ、{% include icon.html name="History" class="inline h-3.5 w-3.5 align-[-2px]" %} 履歴ボタンの一覧から選ぶと、その操作までまとめて戻せます。一覧には「分割」「トリム」「移動」「テキスト追加」などの操作名と時刻が新しい順に並び、最大 100 件まで残ります。履歴は動画を開き直すと空になります。

タイムラインの高さと折りたたみ

高さの変更
タイムラインの上端をドラッグすると、220〜720px の範囲で高さを変えられます（プレイヤーには常に 200px 以上が残ります）。上端を選んで ↑ / ↓ キーでも 16px ずつ調整でき、ダブルクリックで既定の 400px に戻ります
折りたたみ（Ctrl+Shift+T）
ツールバー右端の {% include icon.html name="ChevronDown" class="inline h-3.5 w-3.5 align-[-2px]" %} ボタンで、タイムラインをツールバー 1 行だけに折りたたみ、プレイヤーを大きく使えます。もう一度押すと展開します

高さと折りたたみの状態は、次に編集ページを開いたときも引き継がれます。

{% include docs-h2.html kicker="タイムライン編集" title="メディア（素材の取り込み）" %}

サイドバーの「メディア」（A）で開くメディアパネルで、タイムラインに使う動画・音声・画像の素材を取り込みます。取り込んだ素材はプロジェクトフォルダの中にコピーされるため、元のファイルを動かしても使い続けられます（プロジェクトの書き出しの zip にも入ります）。

取り込み
「メディアをインポート」で種類（動画 / 音声 / 画像）を選んでファイルを選ぶか、エクスプローラーからファイルを編集ページにドラッグ&ドロップします
対応形式と上限
動画: 動画の読み込みと同じ形式（1 ファイル 2GB まで）/ 音声: MP3・WAV・AAC・M4A・FLAC・OGG・Opus（200MB まで）/ 画像: PNG・JPEG・WebP・BMP（50MB まで）
タイムラインに追加
素材の行の「タイムラインに追加」で、動画はクリップとして末尾に、音声は音声トラックとして再生ヘッドの位置に置かれます。素材をレーンへドラッグして好きな位置に置くこともできます（動画・画像はクリップレーン、音声は音声レーン）
画像
「タイムラインに追加」で 5 秒の画像クリップとして置かれ、帯の端をドラッグすると好きな長さに伸縮できます。「透かしに設定」を選ぶと、全編に重ねるロゴとして使えます（透かし）
動画の音声
取り込んだ動画をクリップとして置いた区間は、書き出しではその動画の音声が入らず無音になります（音声トラックの BGM などは流れます）。取り込んだ動画の音声を使いたいときは、同じ素材を音声レーンにもドロップします
素材の削除
行の削除ボタンで、素材をプロジェクトから削除します。ファイルの実体も消えるため取り消せません（タイムラインの取り消しでも戻りません）。タイムラインで使っている素材は削除できません

取り込んだ素材は AI 検出の対象外です。素材の区間にはモザイクがかからず、検出枠の追加や消しゴムも使えません。モザイクが必要な映像は、先に動画として読み込んで検出・書き出ししたものを取り込んでください。

{% include docs-h2.html kicker="タイムライン編集" title="テキスト" %}

サイドバーの「テキスト」で、映像に文字を焼き込みます。テキストはいくつでも追加でき、それぞれに表示する区間・位置・書式を設定できます。表示する区間は、書き出す映像のフレーム番号で指定します。

追加
「テキストを追加」で、全編に表示される「テキスト」が下中央に追加されます。一覧から選んで編集します
表示する区間
開始・終了のフレーム番号を入れます。「現在位置に」で再生ヘッドの位置が入ります。「最後まで表示」にチェックすると映像の最後まで表示します
位置
プレビュー上の文字をドラッグすると、好きな位置へ自由に動かせます。数値では「位置 X / Y (%)」（左上からの位置）で指定します。「配置プリセット」（左上〜右下の 9 か所）を選ぶと、端から 2% の余白で寄せます
大きさ
文字の高さを、映像の高さに対する割合で指定します（2〜50%、既定 6%）
フォントと太字
フォントは 5 種類: ゴシック（既定）/ 游ゴシック / 明朝 / MS ゴシック / BIZ UDゴシック。「太字」にもできます。パソコンに入っていないフォントは同じ系統のフォント、それも無ければゴシックで焼き込まれます。太字の無いフォント（MS ゴシックなど）は通常の太さになります
色・縁取り・不透明度
文字の色（既定: 白）、縁取りの太さ（文字の高さの 0〜25%、既定 8%）と色（既定: 黒）、不透明度（既定 100%）

テキストレーン

タイムラインのクリップレーンの上に、テキストごとに 1 段ずつ、表示する区間の帯が並びます（テキストレーン）。帯をドラッグすると表示する区間ごと動き、両端をドラッグすると開始・終了を変えられます。帯を選ぶと、テキストパネルでも同じテキストが選ばれます。右クリックで複製・コピー・ペースト・削除ができます。

{% include docs-h2.html kicker="タイムライン編集" title="透かし" %}

サイドバーの「透かし」で、ロゴなどの画像 1 枚を書き出す映像の全編に重ねます。先にメディアパネルで画像を取り込んでおきます（メディアパネルの画像の「透かしに設定」からも設定できます）。

画像
取り込んだ画像から選びます。「なし」で透かしを外します
位置
左上〜右下の 9 か所から選びます（既定: 右下）
大きさ
画像の幅を、映像の幅に対する割合で指定します（1〜100%、既定 15%）。縦横比は保たれます
不透明度
0〜100%（既定 80%）
横の余白 / 縦の余白
映像の端からの距離を、映像の幅・高さに対する割合で指定します（0〜50%、既定 2%）

文字の透かしを入れたいときは、全編に表示するテキストを使います。

{% include docs-h2.html kicker="タイムライン編集" title="音声と BGM" %}

サイドバーの「音声」で、元の動画の音声と、BGM などの音声トラックを調整します。書き出しでは、元の動画の音声とすべての音声トラックが重ねて（ミックスして）出力されます。

検出元の音声
元の動画の音量（-40〜+12dB）とミュート
音声トラックの追加
メディアパネルの音声素材の「タイムラインに追加」（再生ヘッドの位置に置かれます）、または音声素材を音声レーンへドラッグします。動画素材を音声レーンに置くと、その動画の音声だけを使えます
音量 / ミュート
トラックごとに -40〜+12dB。ミュートでそのトラックだけを一時的に消します
フェードイン / フェードアウト
トラックごとに、鳴り始めと終わりを 0〜20 秒でフェードさせます

音声レーンと波形

タイムラインのクリップレーンの下に、音声トラックごとに 1 段ずつ帯が並びます（音声レーン）。帯には BGM の波形が描かれ、曲の盛り上がりや無音の位置を見ながら合わせられます。帯をドラッグすると位置が動き、両端をドラッグすると使う範囲（曲の頭と終わり）を詰められます。BGM はクリップの間の空白をまたいで流れ続けます。長さの分からない音声は、帯の代わりに「長さ不明」と表示されます。

{% include docs-h2.html kicker="タイムライン編集" title="フェード" %}

書き出す映像を黒からフェードイン、黒へフェードアウトさせます。映像全体の先頭と末尾にかける「全体のフェード」と、クリップごとの先頭と末尾にかける「クリップのフェード」があります。どちらもタイムライン上部の「効果」のパレットからチップをドラッグして置き、秒数はサイドバーの「フェード」で調整します（タイムラインの上では秒数を入力しません）。

「効果」のパレット
タイムラインのツールバーのすぐ下に、「フェード」（フェードイン / フェードアウト）と「つなぎ」（トランジションの 8 種類）のチップが並びます。タイムラインを折りたたんでいる間は表示されません。チップにマウスを乗せると、置ける場所が表示されます
全体のフェード
「フェードイン」のチップをルーラーの先頭へ、「フェードアウト」のチップをルーラーの末尾へドラッグします。ドラッグを始めると、ルーラーの両端に落とし先が現れます。置くと 1 秒のフェードになり、ルーラーの端にその長さのランプ（三角の印）が出ます
クリップのフェード
チップをクリップの帯の左端（フェードイン）/ 右端（フェードアウト）へドラッグします。置くと 1 秒のフェードになり、帯の下端にランプが出ます。フェードするのはそのクリップの映像だけで（元の動画のクリップは音声も）、透かしとテキストは暗くなりません
秒数の調整
ランプをクリック（選んで Enter でも可）すると、サイドバーの「フェード」が開きます。クリップのランプから開いたときはそのクリップが選ばれ、「選択中のクリップ」の欄にその秒数が出ます。秒で指定し（0〜20 秒、0 秒でフェードなし）、秒数の横に実際にフェードするフレーム数が表示されます。「外す」で選択中のクリップのフェードを両方とも外します
キーボードで置く
チップを選んで Enter / Space を押すと、選択中のクリップの端に 1 秒のフェードを置きます。クリップを選んでいなければ全体のフェードになります
置けない所
フェードインのチップを末尾側（ルーラーの末尾 / クリップの右端）へ、フェードアウトのチップを先頭側へ落としたときは、何も変えずに理由を表示します。トランジションのある継ぎ目の側の端にもクリップのフェードは置けず、サイドバーの入力欄も押せなくなって理由が出ます。トランジションを外すと設定できます
先頭へ / 末尾へ
サイドバーの「フェード」のボタンで、再生ヘッドを映像の先頭 / 末尾へ動かします。全体のフェードは両端にだけかかるので、プレビューで効き具合を確認するときに使います

フェードは書き出しと同じようにプレビューにも反映されます。全体のフェードとクリップのフェードが重なるフレームには両方がかかります。音声トラックごとのフェードは音声と BGMで、クリップの継ぎ目の切り替えはトランジションで設定します。

{% include docs-h2.html kicker="タイムライン編集" title="トランジション" %}

隣り合うクリップの継ぎ目に、切り替えの効果（トランジション）を付けます。タイムライン上部の「効果」のパレットからチップを継ぎ目へドラッグして置き、種類と長さはサイドバーの「つなぎ」（ドロワーの見出しは「トランジション」）で変えます。クリップが 1 つだけのときは継ぎ目がないため置けません。トランジションのある継ぎ目の側の端には、クリップのフェードを置けません。

種類
フェード / ディゾルブ / ワイプ（左へ・右へ）/ スライド（左へ・右へ）/ 黒フェード / 白フェード の 8 種類
置き方
「効果」の「つなぎ」のチップを、タイムラインの継ぎ目（{% include icon.html name="Scissors" class="inline h-3.5 w-3.5 align-[-2px]" %} のバッジ）へドラッグします。置くと 0.5 秒のトランジションになり、継ぎ目に前後のクリップが重なる長さの斜線の帯が出ます。バッジにマウスを乗せると、今の種類と秒数が表示されます
キーボードで置く
クリップを選んだ状態でチップを選び、Enter / Space を押すと、選んだクリップの後ろの継ぎ目に置きます。クリップを選んでいないときは何も変えずに案内が出ます
種類と長さの変更
継ぎ目のバッジか斜線の帯をクリック（選んで Enter でも可）すると、サイドバーの「つなぎ」が開きます。継ぎ目の一覧（「前のクリップ → 次のクリップ」）で種類を選び（「なし」で外れます）、長さを 0.1〜5 秒で指定します。前後のクリップがその長さだけ重なるため、映像全体はその分短くなります
空白のある継ぎ目
空白（黒い画面）を挟んだ継ぎ目には置けません。チップを持って近づけるとバッジが置けない表示に変わり、落としても何も変えずに理由が表示されます（空白は自動では詰めません）。設定した後で間に空白を作るとトランジションは効かなくなり、空白を詰めると元に戻ります
プレビュー
重なりのあいだは、前後のクリップを書き出しと同じ種類の切り替えで合成して表示します。後ろのクリップの側には、プレビューではモザイクが表示されません（書き出しではかかります）
