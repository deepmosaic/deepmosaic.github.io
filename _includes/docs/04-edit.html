編集編集ページ

ホーム画面の動画カードをクリックすると編集ページが開きます。画面は上から「ヘッダー」「動画プレイヤー（編集ツールバー内蔵）」「タイムライン」で構成されます。

ヘッダー左
{% include icon.html name="ArrowLeft" class="inline h-3.5 w-3.5 align-[-2px]" %} 戻るボタン、動画タイトル、9桁のプロジェクトIDバッジ（クリックでコピー）
メタ情報
動画の長さ / 総フレーム数 / fps / 解像度 / 追加日
ヘッダー右
フォルダを開く / Premiere Proへインポート / エンコード / エンコードジョブ一覧 の各ボタンと保存状態表示
保存状態
編集は自動保存されます。「保存中」「未保存」「保存済」がリアルタイムに表示され、失敗時は「保存失敗」と出ます

編集プレイヤーとタイムライン

プレイヤーには検出枠（bbox）がクラス別の色でオーバレイ表示されます。枠はドラッグで位置・サイズを直接編集できます。コマ送り・シークに対応し、下部のタイムラインには検出の分布とシーン（カット）の帯が描画され、クリックで任意のフレームへジャンプできます。

検出クラスは色分けされます: 局部（赤）/ 男性顔（青）/ 女性顔（ピンク）/ ユーザ作成（黄）。

編集編集ツールバー

プレイヤーと再生コントロールの間にあるツールバーに、編集機能が集約されています。

欠落フレームジャンプ
検出が無いフレームへ前後にジャンプ。対象クラス（全クラス / 局部 / 男性顔 / 女性顔）を選んで絞り込めます。ショートカット: [ / ]
bbox追加（1f / ∞）
現在のフレーム中央に検出枠を追加します。「1f」はこのフレームのみ、「∞」は以降のフレームすべてに連続表示。追加後はドラッグで調整。ショートカット: 1 / 2
空白のみ再生
検出枠を含むフレームを自動でスキップし、bboxの無いフレームだけを連続再生します。見落としの確認に便利です
プレビュー切替（B / M）
bbox枠表示とモザイク適用プレビューを切り替えます。ショートカット: M
モザイク設定
モザイク設定パネルを開きます（詳細は次章）
現フレーム初期化
現在のフレームの編集をリセットします。ショートカット: Ctrl+Z
全編集リセット
すべての編集を破棄します（確認ダイアログ付き・取り消し不可）
クラス表示
表示する検出クラスをドロップダウンで絞り込みます（例: 局部のみ表示）
再生速度
0.25x / 0.5x / 1x / 1.5x / 2x / 4x から選択

編集モザイク設定パネル

モザイクの見た目を4つの適用範囲（タブ）で設定できます。優先順位は ID別 > クラス別 > シーン別 > 全て で、狭い範囲の設定が優先されます。パネルはドラッグで自由な位置に移動でき、開いたまま編集を続けられます。

適用範囲タブ
全て（グローバル既定）/ クラス別（局部・顔など）/ ID別（追跡された個々の対象）/ シーン別（カット単位）。オーバライド中の範囲には表示が出て、個別にクリアできます
信頼度しきい値
指定した信頼度以上の検出だけを表示・モザイク対象にします（0〜100%、タブに依らないグローバル設定）
種類
モザイク（ブロック状）/ ぼかし（ガウスぼかし）
サイズ（bbox拡張率）
検出枠を中心から拡大・縮小してモザイク範囲を調整（0.5x〜2x）
不透明度

モザイク/ぼかしをどれだけ強く合成するか（0〜100%）。既定の 100% で対象を完全に覆います。値を下げるほど隠蔽が弱くなるため、通常は 100% のまま使います
エッジぼかし
モザイク領域のふちをぼかして背景となじませます（0〜64px）
ピクセルサイズ自動
対象物のサイズに連動してモザイクの粒を自動計算（既定ON）。カット内・同一ID内で粒度は一定。「細かさ」と最小/最大セル(px)で調整できます
ブロック分割数
自動OFF時、領域を縦横に何分割するかで粗さを固定します（8〜64、Premiere Proと同方式）
シャープカラー
粒の色を領域平均でなく1点サンプリングにします（Premiere ProのSharp Colors相当、既定OFF）

各項目は右端の {% include icon.html name="RotateCcw" class="inline h-3.5 w-3.5 align-[-2px]" %} ボタンで既定値に戻せます。
