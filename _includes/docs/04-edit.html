{% include docs-h2.html kicker="編集" title="編集ページ" %}

ホーム画面の動画カードをクリックすると編集ページが開きます。画面は上部の「ヘッダー」、端に縦に並ぶ「サイドバー」（と、その隣に開くドロワー）、中央の「動画プレイヤー（編集ツールバー内蔵）」、下部の「タイムライン」で構成されます。

ヘッダー左
{% include icon.html name="ArrowLeft" class="inline h-3.5 w-3.5 align-[-2px]" %} 戻るボタン、動画タイトル、9桁のプロジェクトIDバッジ（クリックでコピー）
メタ情報
動画の長さ / 総フレーム数 / fps / 解像度 / 追加日
ヘッダー右
フォルダを開く / 人物ギャラリー / Premiere Pro へインポート / エンコード の各ボタンと保存状態表示。エンコードの待ち行列はメニューバーの「キュー」で確認します
保存状態
編集は操作の約 1 秒後に自動保存されます。「保存中」「未保存」「保存済」がリアルタイムに表示され、失敗時は「保存失敗」と出ます。エンコードの開始時、編集ページを離れるとき、アプリを閉じるときにも未保存分が保存されます
サイドバー
メディア / テキスト / 透かし / 音声 / フェード / トランジション の 6 項目。押すと隣にドロワーが開き、素材の取り込みやテキスト・BGM などの設定ができます（サイドバーとドロワー）
タイムライン
シーンの帯、テキスト・クリップ・音声のレーン、検出クラスごとの行が並びます。クリップの継ぎ目のはさみを押すと、フェードかつなぎを選べます（プレイヤーとタイムライン / クリップの編集 / フェード）
ツールチップ
ボタンにマウスを乗せると、すぐに（約 0.15 秒で）その機能の説明とショートカットキーがツールチップで表示されます
読み込み中の表示
編集ページを開くと、検出結果がそろうまで「検出結果を読み込んでいます」と進捗が表示され、最初のフレームから枠が載った状態でプレイヤーが表示されます。以前のバージョンで検出したプロジェクトを初めて開いたときは「検出結果を新しい保存形式に変換しています」と表示されます（変換は 1 回だけです）
詳細データがありません
検出結果のファイルが見つからないときに表示されます（プロジェクトフォルダの移動や削除など）。この画面の「プロジェクトを削除」で一覧から取り除けます
{% include docs-h2.html kicker="編集" title="プレイヤーとタイムライン" %}

プレイヤーには検出枠（bbox）がクラス別の色でオーバレイ表示されます。枠はドラッグで位置・サイズを直接編集できます。コマ送り・シークに対応し、下部のタイムラインには検出の分布とシーン（カット）の帯が描画され、クリックで任意のフレームへジャンプできます。

検出クラスは色分けされます: 局部（赤）/ 男性顔（青）/ 女性顔（ピンク）/ ユーザー作成（黄）/ 回避マスク（青緑）/ 既存モザイク（紫、検出オプションの「既存のモザイク」を ON にして検出したプロジェクトだけ）。枠の上のラベル（チップ）には「クラス名 #ID（3 文字のコード） 信頼度%」が表示され、手動で追加した枠は「ユーザー」、回避マスクは「回避」、モザイクの対象から外したトラックには「[モザイク除外]」が付きます。

再生コントロール

再生 / コマ送り
先頭へ（Home）/ 1 コマ戻る（←）/ 再生・一時停止（Space）/ 1 コマ進む（→）/ 末尾へ（End）。PageUp / PageDown で 10 コマ移動。マウスホイールでもコマ送りでき、Shift+ホイールで 10 コマ移動します。BBox を選択中に Shift+→（または Shift+ホイール上）で進むと、その枠の形を引き継いだまま 1 コマずつ進みます（下の「検出枠の操作」の「形を引き継いでコマ送り」）
シーク
スライダーのドラッグ、タイムラインのクリック / ドラッグ、時刻とフレーム番号（frame N / M）の表示
ミュート（V）
プレビューの音声を消します。書き出しには影響しません
オーバーレイの表示切替（H）
検出枠・ラベル・ID・確率をすべて隠して映像だけを確認します。編集内容は変わりません
再生速度
ツールバーで 0.25x / 0.5x / 1x / 1.5x / 2x / 4x から選択（, で遅く . で速く）

検出枠の操作

選択
枠をクリックすると太枠と 8 つのハンドルが表示されます。あわせて、エッジぼかしが届く範囲が枠の外側に点線で表示されます（Premiere Pro のマスクの境界のぼかしと同じく、輪郭の外側に設定値の半分の幅。エッジぼかしが 0 のとき、モザイク対象外のトラック、オーバーレイ非表示（H）のときは出ません）
移動 / サイズ変更
枠の内側をドラッグで移動、ハンドルをドラッグでサイズ変更。再生中でもドラッグできます
削除
選択して Delete、枠をダブルクリック、または右クリックメニューの「この BBox を削除」。削除はそのフレームの枠だけに適用されます（同じ ID の他のフレームは残ります）
連続削除（消しゴム）
映像の上で E キーを押しながら右ボタンを押したままドラッグすると消しゴムになります。既定では円に触れた枠をそのフレームから削除します。ツールバーの消しゴムボタンで、消し方（触れた BBox を削除 / 触れた部分だけ削除）、形（円 / 角丸四角）、大きさ（8〜120px）を選べます。「触れた部分だけ削除」では、削った跡が枠の形（多角形）として残り、手動で追加した枠が 2 つに割れたときは片ごとに別の枠になります。押したまま再生したりホイールでコマ送りしたりすると、流れていくフレームの枠も続けて消せます（E を押していない右ドラッグや、右ボタンを動かさずに離したときは、いつもの右クリックメニューが開きます）
ID ごと削除（チップの ✕）
検出した枠のチップの右端にある ✕ を押すと、その ID の枠を全フレームからまとめて削除します。削除するフレーム数を示した確認が出ます。手動で追加した枠のチップには ✕ は出ません
右クリックメニュー
顔の枠では「男性顔に変更」「女性顔に変更」（検出された性別の修正）。すべての枠で「モザイク対象外にする」「モザイク対象に戻す」（そのトラック全体をモザイクの対象から外す / 戻す）、「この BBox を削除」、検出した枠では「この ID をすべて削除」（チップの ✕ と同じ）。連続 bbox に軌跡があるときは「移動軌跡をクリア」。「形を変更」では、範囲（この BBox / この ID すべて / すべて）を選んで四角 / 楕円 / 多角形に変えられ、「形を既定に戻す」で元の形に戻せます
追跡 ID の統合
同じ対象なのに別の ID に分かれてしまったときは、片方の枠をクリックして選択し、もう片方の枠を右クリックして「選択中の #XXX に統合」を選びます。統合すると 1 つの ID として扱われ（タイムラインの行、ID 別のモザイク設定、書き出しのすべて）、間に枠の無いフレームがあれば連続 BBox で自動的に補間されます。統合できるのは同じクラスで時間が重ならない 2 つだけです（同時に映っているものは別の対象です）。元に戻すには統合先の枠を右クリックして「統合を解除」を選びます。
モザイク除外の注意表示
対象から外したトラックがあると「N トラックをモザイク除外中です」と常時表示されます。「すべてモザイク対象に戻す」で一括で戻せます。除外した箇所は書き出してもモザイクがかかりません
プレビューの余白と枠外
プレビューでは映像の上下左右に余白（各辺およそ 15%、暗いグレー）があり、映像の境目に細い枠線が引かれます。枠は余白へはみ出す位置まで動かしたり広げたりでき、人物が画面の外へ出ていく場面でも楕円などの形を潰さずに置けます。はみ出した部分は書き出されませんが、映像の内側はその形のまま映像の端までモザイクがかかります。新しく描く枠は映像と重なる必要があり、余白だけをドラッグしても描けません
画面の端で切れた検出枠
画面の端にかかって切れた検出枠は、端に触れる前後のフレームの大きさをもとに枠の外まで自動で補われます。顔が画面の外へ出ていく場面でも、モザイクの形（楕円など）が端で潰れず、プレビューと書き出しの両方に反映されます。この補完はバージョン 2.8.1 以降で検出した動画に付きます
枠を描く（左ドラッグ）
映像の空いている所を左ドラッグすると、ツールバーの形の選択で選んでいる形（四角 / 楕円 / 多角形）の枠を描けます。多角形はクリックで点を置き、始点のクリック / Enter / ダブルクリックで閉じます。描いた枠は既定で以降のフレームにも続く連続 bbox で、形の選択メニューの「描いた BBox」で「このフレームのみ」に、「描いた BBox の種類」で「回避マスク」に変えられます。余白だけをドラッグしても枠は描けません（映像と重なるように描きます）。拡大中にフレームを動かすときは Ctrl+左ドラッグ（中ボタンドラッグでも可）です
手動で追加した枠の表示
手動で追加した枠のチップは「ユーザー」と表示され、ID は検出された枠と同じ 3 文字のコード（例: #K7Q）です。タイムラインでは「ユーザー」の行に並びます
モザイク設定の引き継ぎ
検出された枠に重ねて、または近く（隙間が画面の短辺の 5% 以内）に枠を追加すると、その検出枠に効いているモザイク設定（種類・ぼかし・不透明度・粒の大きさ）を写します。粒の大きさは、その検出枠と同じ見た目になるように固定されます。写した設定はモザイク設定の「ID 別」タブでいつでも変えられます
形を引き継いでコマ送り（Shift+→）
枠をクリックして選択し、Shift を押しながら →（またはホイールを上へ）で進むと、Shift を押し始めた時点の位置・大きさ・形のまま 1 コマずつ進み、進んだ先のフレームのその枠を上書きします。引き継ぎ中の枠のチップには「[引き継ぎ中]」と表示されます。Shift を離すまでが 1 つの操作で、Ctrl+Z 1 回でまとめて戻せます。進んだ先にその枠が無いフレームは飛ばし、1 フレームも書けなかったときは「進んだ先のフレームにこの BBox が無く、形を引き継げませんでした」と表示されます。Shift+← は引き継がずに 1 コマ戻ります。再生ボタンでの再生、PageDown の 10 コマ移動、1 フレームのみの手動の枠、取り込んだ素材の区間では引き継ぎません
引き継ぎの固定（Shift ×2）
枠を選択して Shift を素早く 2 回押すと、Shift を離しても引き継ぎが続く「固定」になり、チップに「[引き継ぎ: 固定]」と表示されます。固定中は Shift なしの → やホイール上でも形を引き継いで進みます（PageDown と再生ボタンでは引き継ぎません）。もう一度 Shift を素早く 2 回押すか、Esc で解除します。固定中に別の枠を選び直すと、次に進んだときからその枠の形を引き継ぎます。日本語入力（IME）などのソフトが Shift の単押しを使っている環境では、固定にならないことがあります

検出枠の選択・追加・消しゴムは、再生ヘッドが元の動画（検出元）の区間にあるときだけ使えます。取り込んだ素材の区間は AI 検出の対象外のため、枠はありません。

タイムライン

タイムラインは上から、ツールバー、目盛り、シーン（カット）の帯、テキスト・クリップ・音声のレーン（クリップの編集）、検出クラスごとの行の順に並びます。クラスの行には検出のある区間が帯で描かれ、手動で追加した枠は「ユーザー」、回避マスクは「回避」の行に並びます。行頭の {% include icon.html name="ChevronDown" class="inline h-3.5 w-3.5 align-[-2px]" %} で追跡 ID ごとの行に展開できます。モザイク対象から外したトラックは薄く表示されます。タイムラインは書き出す映像の時間で並ぶので、クリップをトリムしたり動かしたりすると、検出の帯も一緒に動きます。

タイムラインは Ctrl+ホイール、またはツールバー左端の拡大・縮小ボタンで最大 16 倍まで拡大できます。高さの変更と折りたたみはクリップの編集を参照してください。

{% include docs-h2.html kicker="編集" title="拡大・縮小とパン" %}

小さな対象の枠を正確に合わせるために、プレイヤーの映像を最大 8 倍まで拡大できます。拡大中も枠の移動・サイズ変更・追加・削除はそのまま行えます。

拡大 / 縮小
Ctrl+ホイール（カーソル位置を中心に拡大縮小）、+ / - キー、またはプレイヤー右上の {% include icon.html name="Maximize2" class="inline h-3.5 w-3.5 align-[-2px]" %} ボタン。現在の倍率はボタンの間に表示されます
パン（表示位置の移動）
Ctrl+左ドラッグ、または中ボタン（ホイール）ドラッグ。拡大していないとき（等倍）は動きません。空いている所の左ドラッグは枠の描画になります
リセット
0 キー、または「ズームをリセット」ボタンで等倍・中央に戻ります
{% include docs-h2.html kicker="編集" title="検出枠の追加（1f と ∞）" %}

検出されなかった箇所には、ツールバーの「1f」（＋の入った四角に 1f）と「∞」（∞ の入った四角）のボタンで枠を手動で追加できます。追加した枠は現在のフレームの中央に「ユーザー」クラス（黄）で置かれるので、ドラッグで位置と大きさを合わせます。手動の枠にもモザイク設定（ID 別を含む）がそのまま適用されます。

1f（1）
このフレームだけに枠を置きます。前後のフレームには影響しません。数フレームだけ検出が抜けた「中抜け」の補修に向いています
∞ 連続 bbox（2）
置いたフレームから先のすべてのフレームに同じ位置で枠が続きます。動画の最後まで続けたくないときは、終わらせたいフレームで枠を削除してください（削除したフレームの手前までが有効範囲として確定します）
連続 bbox を動かす
再生しながら ∞ の枠をドラッグすると、その動きが軌跡として記録され、被写体の移動に追従させられます。記録した軌跡は右クリックメニューの「移動軌跡をクリア」で消せます
取り消し
「現在のフレームをリセット」（Ctrl+Z）は現在のフレームの編集を元に戻します。∞ の枠を削除で終わらせた直後に押すと、まず終端の確定が解除されます

回避マスク（モザイクをかけない範囲）

重なったモザイクの一部だけを外したいとき（顔の横の手元だけ見せたい、など）は、回避マスクを置きます。回避マスクの内側にはモザイクがかからず、元の映像のまま表示・書き出しされます。追尾はしないので、動く対象には位置をドラッグで合わせてください。

1f 回避マスク（3）
このフレームだけに置きます
∞ 連続 回避マスク（4）
置いたフレームから先のフレームに続けます（終わらせ方は連続 bbox と同じで、終わらせたいフレームで削除します）
形と描画
ツールバーの形の選択で選んだ形（四角 / 楕円 / 多角形）で置かれます。形の選択メニューの「描いた BBox の種類」を「回避マスク」にすると、左ドラッグで回避マスクを描けます
表示
枠とチップは青緑の「回避」で、タイムラインの「回避」の行に並びます。モザイク適用プレビュー（M）で、モザイクが打ち抜かれた見た目を確認できます
縁のぼかし
回避マスクの縁は、手動の枠と同じエッジぼかしの設定でなじませます。サイズ（bbox 拡張率）は効きません
Premiere Pro
回避マスクは Premiere Pro 連携には渡りません

枠の追加・移動・削除はすべて自動保存され、エンコードに反映されます。Premiere Pro 連携に渡るのは検出結果とエッジのぼかしの値だけで、この画面での枠の編集（移動・形の変更・削除・回避マスクなど）は渡りません。

{% include docs-h2.html kicker="編集" title="シーン（カット）" %}

検出時に映像のカット（場面の切り替わり）が自動で判定され、タイムラインの上部にシーンの帯として表示されます。シーンは「ピクセルサイズ自動」の粒度を一定に保つ単位であり、モザイク設定をシーンごとに変える単位でもあります。

シーンへ移動
帯をクリックすると、そのシーンの先頭フレームへジャンプします。帯には番号（#1, #2 …）が表示され、マウスオーバーで区間が確認できます
分割（Ctrl+K）
タイムラインのツールバー（拡大・縮小ボタンの右）の {% include icon.html name="Scissors" class="inline h-3.5 w-3.5 align-[-2px]" %} ボタン、または Ctrl+K で、現在のフレームを境にシーンを 2 つに分けます。自動判定が見逃したカットや、同じカット内で設定を変えたい箇所に使います
境界の調整
帯の境目をドラッグすると、前後のシーンの開始・終了が同時に動きます
削除
帯にマウスを乗せると出る ✕（このシーンを削除）で、隣のシーンと結合します

プレビュー切替（M）

{% include docs-h2.html kicker="編集" title="モザイク設定パネル" %}

モザイクの見た目を4つの適用範囲（タブ）で設定できます。優先順位は ID別 > クラス別 > シーン別 > 全て で、狭い範囲の設定が優先されます。パネルはヘッダーをドラッグで自由な位置に移動でき、右下の角をドラッグすると大きさを変えられます（角を選んで矢印キーでも調整、ダブルクリックで既定の大きさ）。開いたまま編集を続けられます。値を変えると、モザイク適用プレビュー（M）にその場で反映されます。

適用範囲タブ
全て（グローバル既定）/ クラス別（局部・顔など）/ ID別（追跡された個々の対象）/ シーン別（カット単位）。ID 別とシーン別では対象をプルダウンで選びます。オーバライド中の範囲には「オーバライド中」と表示され、「クリア」で個別に解除できます
信頼度しきい値
指定した信頼度以上の検出だけを表示・モザイク対象にします（0〜100%、タブに依らないグローバル設定）
種類
モザイク（ブロック状）/ ぼかし（ガウスぼかし）。既定: モザイク
サイズ（bbox拡張率）
検出枠を中心から拡大・縮小してモザイク範囲を調整（0.50x〜2.00x）。既定: 1.05x。ギリギリを避けたいときは大きめに
不透明度
{%- comment -%} TICKET-SITE-30: 旧文面は「下げると元の映像が透けます」。意味は 正しいが、**単独で抜粋されると「モザイクを透かせる機能」と誤読され得る** サイト内で唯一の表現だった。意味を保ったまま「隠蔽が弱くなる」に 言い換え、既存の確定語彙 (隠蔽率) に寄せた。 {%- endcomment -%}
モザイク/ぼかしをどれだけ強く合成するか（0〜100%）。既定の 100% で対象を完全に覆います。値を下げるほど隠蔽が弱くなるため、通常は 100% のまま使います
エッジぼかし
モザイク領域のふちをぼかして背景となじませます（0〜64px）。既定: 6px。Premiere Pro のマスクの「マスクの境界のぼかし」と同じ意味で、輪郭を中心に内側と外側へ半分ずつぼかします（値は内外を合わせた幅です）。プレイヤーで枠を選択すると、ぼかしが届く外側の範囲が点線で表示されます。回避マスクの縁も同じ値でなじませます
ピクセルサイズ自動
対象物のサイズに連動してモザイクの粒を自動計算（既定ON）。仕組みは、カット（シーン）× ID ごとに枠の代表サイズ（√(幅×高さ) の中央値）を取り、それを「細かさ（対象物の分割数）」（8〜64、既定 16）で割った値を粒の 1 辺にします。粒は最小セル（2〜32px、既定 8px）と最大セル（8〜128px、既定 64px）の範囲に収め、同じカット・同じ ID の中では一定でフレームごとにちらつきません。大きく映る対象ほど粒も大きくなり、細かさの値を上げるほど粒は細かくなります。自主規制の最小モザイク（長辺 400px 以上は長辺÷100、最小 4px）が優先されるため、細かさを上げても粒がそれ以上細かくならないことがあります。新しい検出の初期値は検出オプションの「細かさ」で決めます
ブロック分割数
自動OFF時（と「ぼかし」のとき）、領域を縦横に何分割するかで粗さを固定します（8〜64、既定 16、Premiere Proと同方式）
シャープカラー
粒の色を領域平均でなく1点サンプリングにします（Premiere ProのSharp Colors相当、既定OFF）
最小モザイクの注記
パネル上部に、書き出し解像度での最小モザイク（自主規制基準: 長辺÷100、最小 4px）が表示されます。これより細かい設定にしても、書き出し時に自動でこの粒度へ丸められます。ぼかしは対象外です
反転 (外側にかける)
「ID 別」タブで検出した対象か追加した枠を選んだときだけ表示されます（回避マスクと「全て」「クラス別」「シーン別」のタブにはありません。既定 OFF）。ON にすると、その枠の内側は元の映像のまま残し、枠の外側（背景）にモザイク / ぼかし（その枠の種類・粒・ぼかしの設定）をかけます。モザイク適用プレビュー（M）と書き出しの両方に効きます。反転した枠が同じ画面に複数あるときは、どれかの枠の内側に入る所を残します。「この設定を既定にする」には含まれず、枠を追加したときの設定の自動引き継ぎでも引き継ぎません（消しゴムで分けた片は、元の枠の設定ごと引き継ぎます）。反転した枠のあるプロジェクトは Premiere Pro へは送れません（Premiere Pro 連携）

各項目は右端の {% include icon.html name="RotateCcw" class="inline h-3.5 w-3.5 align-[-2px]" %} ボタンで既定値に戻せます。「全て」タブの「この設定を既定にする」を押すと、その内容が次に検出する動画の初期設定になります（この動画の設定は変わりません）。

{% include docs-h2.html kicker="編集" title="人物ギャラリー" %}

ヘッダーの「人物ギャラリー」（P）を開くと、検出された顔が人物ごとにまとめて表示されます（顔らしさが低い検出は人物に含めず「その他」に回します）。人物単位でモザイクの ON / OFF や性別の修正ができ、同じ人物が別々に検出されている場合は 1 つに統合できます。パネルはドラッグで移動できます。

人物カード
代表画像、性別バッジ、トラック数、出現時間、初出時刻。カードをクリックすると初出フレームへジャンプします
性別の修正
性別バッジをクリックして「男性顔にする」「女性顔にする」「検出結果に戻す」。クラス別のモザイク設定（男性顔 / 女性顔）の適用先が変わります
モザイクの ON / OFF
「モザイクを OFF にする」でその人物のすべてのトラックをモザイク対象から外します（例: 出演者以外の顔にはモザイクをかけない、など）。「モザイクを ON に戻す」で戻ります
人物の統合
カードを別のカード（「その他」のカードを含む）にドラッグ&ドロップすると同一人物として統合されます。統合したカードには「統合を解除」が表示されます。タイムラインや右クリックメニューで統合した追跡 ID も、人物ギャラリーでは 1 人として表示されます
その他
人物としてまとめられなかった顔のトラックは「その他 N 件（短い出現 a・小さい顔 b・顔らしさが低い c・判定不能 d）」に折りたたまれます。押すと理由ごとに並び、60 件ずつ「さらに表示」で続きを出せます。ここでも 1 件ずつモザイクの ON / OFF を切り替えられ、別のカードへドラッグ&ドロップして統合できます
人物を再集計
長い動画などで同じ人物がまとまっていないときは、パネルの「人物を再集計」で動画の顔をもう一度まとめ直せます。数分かかることがあり、その間は「人物を再集計しています」と進捗が表示されます（途中で閉じることはできません）。2 回目以降は動画を読み直さないため、短い時間で終わります。人物にまとまっていない顔が多いときは「長い動画では人物にまとまっていないことがあります」と案内が出ます。ボタンは、対応した検出エンジン（2.7.2 以降）で扱えるプロジェクトのときだけ表示されます（Web 版にはありません）

旧バージョンで検出したプロジェクトでは「この動画は旧バージョンで検出されています。人物一覧を使うには再検出してください。」と表示されます。その場合は動画を読み込み直して検出してください。

{% include docs-h2.html kicker="タイムライン編集" title="クリップの編集" %}

タイムラインの「クリップレーン」には、書き出す映像の並びが帯（クリップ）で表示されます。最初は元の動画（検出元）1 本だけのクリップで、トリム・分割・削除で不要な部分を切り詰めたり、取り込んだ素材を前後に足したりできます。クリップレーンの上にはテキスト、下には音声のレーンがあり、どのレーンも書き出す映像の時間で並びます。

編集した内容はプレビューにそのまま反映され、エンコードで書き出されます。モザイクは元の動画の区間にかかります。

選択
帯をクリックすると選択され、帯の右上に削除の ✕ が出ます
トリム
帯の左右の端をドラッグして、クリップの開始・終了を詰めます（最短 1 フレーム）。シーンの境界や再生ヘッドに近づくと吸着します。取り込んだ動画は素材の長さまで、画像のクリップは好きな長さまで伸ばせます
分割（Ctrl+K / Ctrl+Shift+K）
タイムラインのズームボタンの右にある {% include icon.html name="Scissors" class="inline h-3.5 w-3.5 align-[-2px]" %} ボタン、または Ctrl+K（タイムラインにフォーカスがあるときは Ctrl+Shift+K）で、再生ヘッドの位置でクリップを 2 つに分け、同時にシーンも分けます。分けた瞬間にクリップの帯が 2 つになり、継ぎ目にカットの印（斜線とはさみ）、シーンの帯に新しい番号が付きます。後半が選択されるので、続けてトリムや削除ができます。「元に戻す」1 回でクリップとシーンの両方が戻ります
削除
選択して帯の ✕、Backspace / Delete キー、または右クリックメニューの「削除」。後ろのクリップは前に詰まります（リップル削除）
並べ替え・移動
帯をつかんで左右にドラッグすると、置いた位置に応じて並べ替えられます。他のクリップの端・シーンの境界・再生ヘッドに吸着します。今の終わりより右へ運ぶこともできます。Ctrl+← / Ctrl+→ で選択中のクリップを 1 フレームずつ動かせます
空白
前のクリップから離して置くと、その間が空白（黒い画面・無音）になり、斜線の帯に「空白 N フレーム」と表示されます。書き出してもそのまま黒い画面・無音になります。空白を詰めるときは、クリップを前のクリップの端までドラッグします（端に吸着します）
継ぎ目
クリップの継ぎ目には {% include icon.html name="Scissors" class="inline h-3.5 w-3.5 align-[-2px]" %} のバッジ（はさみ）が出ます。バッジを押すと「フェード」「つなぎ」を選ぶ小さなメニューが開き、選ぶとサイドバーの該当のタブ（フェード / トランジション）がその継ぎ目にフォーカスした状態で開きます。秒数や種類はそこで設定します
フィルムストリップ
動画のクリップの帯には、中身のサムネイルが並びます（フィルムストリップ）。画像のクリップには画像そのものが表示されます。サムネイルの読み込みが終わるまでは無地で表示されます

右クリックメニューとクリップボード

クリップ・テキスト・音声トラックの帯を右クリックすると「複製」「コピー」「ペースト」「削除」のメニューが出ます。レーンの何もない所を右クリックしたときは「ペースト」だけが出ます。メニューとショートカットは同じ動作です。

複製（Ctrl+D）
クリップはすぐ後ろに、テキストは帯のすぐ後ろに、音声トラックは同じ位置に複製します
コピー / ペースト（Ctrl+C / Ctrl+V）
コピーした要素を貼り付けます。テキストと音声トラックは再生ヘッドの位置に、クリップは選択中のクリップ（選択していなければ再生ヘッドのあるクリップ）のすぐ後ろに入ります。クリップボードに入るのは直前にコピーした 1 つだけで、パソコンのクリップボードとは別です（編集ページの中でだけ使えます）
削除（Delete）
選択中の要素を削除します。プレイヤーを最後に操作していたときの Delete は検出枠の削除になります（ショートカット）

取り消しと履歴

タイムラインの編集（クリップ・テキスト・音声・透かし・フェード・トランジション・素材の追加）は、検出枠の編集とは別の履歴に記録されます。タイムラインのズームボタンの右にある「元に戻す」（Ctrl+Shift+Z）/「やり直す」（Ctrl+Shift+Y）で 1 手ずつ、{% include icon.html name="History" class="inline h-3.5 w-3.5 align-[-2px]" %} 履歴ボタンの一覧から選ぶと、その操作までまとめて戻せます。一覧には「分割」「トリム」「移動」「テキスト追加」などの操作名と時刻が新しい順に並び、最大 100 件まで残ります。履歴は動画を開き直すと空になります。

タイムラインの高さと折りたたみ

高さの変更
タイムラインの上端をドラッグすると、220〜720px の範囲で高さを変えられます（プレイヤーには常に 200px 以上が残ります）。上端を選んで ↑ / ↓ キーでも 16px ずつ調整でき、ダブルクリックで既定の 400px に戻ります
折りたたみ（Ctrl+Shift+T）
ツールバー右端の {% include icon.html name="ChevronDown" class="inline h-3.5 w-3.5 align-[-2px]" %} ボタンで、タイムラインをツールバー 1 行だけに折りたたみ、プレイヤーを大きく使えます。もう一度押すと展開します

高さと折りたたみの状態は、次に編集ページを開いたときも引き継がれます。

{% include docs-h2.html kicker="タイムライン編集" title="メディア（素材の取り込み）" %}

サイドバーの「メディア」（A）で開くメディアパネルで、タイムラインに使う動画・音声・画像の素材を取り込みます。取り込んだ素材はプロジェクトフォルダの中にコピーされるため、元のファイルを動かしても使い続けられます（プロジェクトの書き出しの zip にも入ります）。

取り込み
「メディアをインポート」で種類（動画 / 音声 / 画像）を選んでファイルを選ぶか、エクスプローラーからファイルを編集ページにドラッグ&ドロップします
対応形式と上限
動画: 動画の読み込みと同じ形式（1 ファイル 2GB まで）/ 音声: MP3・WAV・AAC・M4A・FLAC・OGG・Opus（200MB まで）/ 画像: PNG・JPEG・WebP・BMP（50MB まで）
タイムラインに追加
素材の行の「タイムラインに追加」で、動画はクリップとして末尾に、音声は音声トラックとして再生ヘッドの位置に置かれます。素材をレーンへドラッグして好きな位置に置くこともできます（動画・画像はクリップレーン、音声は音声レーン）
画像
「タイムラインに追加」で 5 秒の画像クリップとして置かれ、帯の端をドラッグすると好きな長さに伸縮できます。「透かしに設定」を選ぶと、全編に重ねるロゴとして使えます（透かし）
動画の音声
取り込んだ動画をクリップとして置いた区間は、書き出しではその動画の音声が入らず無音になります（音声トラックの BGM などは流れます）。取り込んだ動画の音声を使いたいときは、同じ素材を音声レーンにもドロップします
素材の削除
行の削除ボタンで、素材をプロジェクトから削除します。ファイルの実体も消えるため取り消せません（タイムラインの取り消しでも戻りません）。タイムラインで使っている素材は削除できません

取り込んだ素材は AI 検出の対象外です。素材の区間にはモザイクがかからず、検出枠の追加や消しゴムも使えません。モザイクが必要な映像は、先に動画として読み込んで検出・書き出ししたものを取り込んでください。

{% include docs-h2.html kicker="タイムライン編集" title="テキスト" %}

サイドバーの「テキスト」で、映像に文字を焼き込みます。テキストはいくつでも追加でき、それぞれに表示する区間・位置・書式を設定できます。表示する区間は、書き出す映像のフレーム番号で指定します。

追加
「テキストを追加」で、全編に表示される「テキスト」が下中央に追加されます。一覧から選んで編集します
表示する区間
開始・終了のフレーム番号を入れます。「現在位置に」で再生ヘッドの位置が入ります。「最後まで表示」にチェックすると映像の最後まで表示します
位置
プレビュー上の文字をドラッグすると、好きな位置へ自由に動かせます。数値では「位置 X / Y (%)」（左上からの位置）で指定します。「配置プリセット」（左上〜右下の 9 か所）を選ぶと、端から 2% の余白で寄せます
大きさ
文字の高さを、映像の高さに対する割合で指定します（2〜50%、既定 6%）
フォントと太字
フォントは 5 種類: ゴシック（既定）/ 游ゴシック / 明朝 / MS ゴシック / BIZ UDゴシック。「太字」にもできます。パソコンに入っていないフォントは同じ系統のフォント、それも無ければゴシックで焼き込まれます。太字の無いフォント（MS ゴシックなど）は通常の太さになります
色・縁取り・不透明度
文字の色（既定: 白）、縁取りの太さ（文字の高さの 0〜25%、既定 8%）と色（既定: 黒）、不透明度（既定 100%）

テキストレーン

タイムラインのクリップレーンの上に、テキストごとに 1 段ずつ、表示する区間の帯が並びます（テキストレーン）。帯をドラッグすると表示する区間ごと動き、両端をドラッグすると開始・終了を変えられます。帯を選ぶと、テキストパネルでも同じテキストが選ばれます。右クリックで複製・コピー・ペースト・削除ができます。

{% include docs-h2.html kicker="タイムライン編集" title="透かし" %}

サイドバーの「透かし」で、ロゴなどの画像 1 枚を書き出す映像の全編に重ねます。先にメディアパネルで画像を取り込んでおきます（メディアパネルの画像の「透かしに設定」からも設定できます）。

画像
取り込んだ画像から選びます。「なし」で透かしを外します
位置
左上〜右下の 9 か所から選びます（既定: 右下）
大きさ
画像の幅を、映像の幅に対する割合で指定します（1〜100%、既定 15%）。縦横比は保たれます
不透明度
0〜100%（既定 80%）
横の余白 / 縦の余白
映像の端からの距離を、映像の幅・高さに対する割合で指定します（0〜50%、既定 2%）

文字の透かしを入れたいときは、全編に表示するテキストを使います。

{% include docs-h2.html kicker="タイムライン編集" title="音声と BGM" %}

サイドバーの「音声」で、元の動画の音声と、BGM などの音声トラックを調整します。書き出しでは、元の動画の音声とすべての音声トラックが重ねて（ミックスして）出力されます。

検出元の音声
元の動画の音量（-40〜+12dB）とミュート
音声トラックの追加
メディアパネルの音声素材の「タイムラインに追加」（再生ヘッドの位置に置かれます）、または音声素材を音声レーンへドラッグします。動画素材を音声レーンに置くと、その動画の音声だけを使えます
音量 / ミュート
トラックごとに -40〜+12dB。ミュートでそのトラックだけを一時的に消します
フェードイン / フェードアウト
トラックごとに、鳴り始めと終わりを 0〜20 秒でフェードさせます

音声レーンと波形

タイムラインのクリップレーンの下に、音声トラックごとに 1 段ずつ帯が並びます（音声レーン）。帯には BGM の波形が描かれ、曲の盛り上がりや無音の位置を見ながら合わせられます。帯をドラッグすると位置が動き、両端をドラッグすると使う範囲（曲の頭と終わり）を詰められます。BGM はクリップの間の空白をまたいで流れ続けます。長さの分からない音声は、帯の代わりに「長さ不明」と表示されます。

{% include docs-h2.html kicker="タイムライン編集" title="フェード" %}

書き出す映像を黒からフェードイン、黒へフェードアウトさせます。映像全体の先頭と末尾にかける「全体のフェード」と、クリップごとの先頭と末尾にかける「クリップのフェード」があります。全体のフェードはサイドバーの「フェード」で秒数を入れます。クリップのフェードは、継ぎ目のはさみから「フェード」を選んで開く「選択中の継ぎ目」の節か、クリップを選んだときに出る「選択中のクリップ」の節で入れます。秒数はサイドバーだけで入力します（タイムラインの上では秒数を入力しません）。

はさみから選ぶ
クリップの継ぎ目の {% include icon.html name="Scissors" class="inline h-3.5 w-3.5 align-[-2px]" %} のバッジ（はさみ）を押すと（選んで Enter / Space でも可）、「フェード」「つなぎ」の 2 項目のメニューが開きます。↑ / ↓ で項目を移り、Esc かメニューの外のクリックで閉じます。「フェード」を選ぶと、サイドバーの「フェード」がその継ぎ目にフォーカスした状態で開きます（「つなぎ」はトランジション）
全体のフェード
サイドバーの「フェード」で、映像全体のフェードインとフェードアウトの秒数を入れます。入れるとルーラーの端にその長さのランプ（三角の印）が出ます
クリップのフェード
「選択中の継ぎ目」の節では、継ぎ目の前のクリップのフェードアウトと後ろのクリップのフェードインを入れます。映像の最初のクリップの先頭や最後のクリップの末尾は、クリップを選んで「選択中のクリップ」の節で入れます。入れると帯の下端にランプが出ます。フェードするのはそのクリップの映像だけで（元の動画のクリップは音声も）、透かしとテキストは暗くなりません
秒数の調整
秒で指定し（0〜20 秒、0 秒でフェードなし）、秒数の横に実際にフェードするフレーム数が表示されます。ランプをクリック（選んで Enter でも可）してもサイドバーの「フェード」が開き、クリップのランプから開いたときはそのクリップが選ばれます。「外す」で選択中のフェードを両方とも外します
置けない所
トランジションのある継ぎ目の側の端にはクリップのフェードを入れられず、サイドバーの入力欄が押せなくなって理由が出ます。トランジションを外すと設定できます
先頭へ / 末尾へ
サイドバーの「フェード」のボタンで、再生ヘッドを映像の先頭 / 末尾へ動かします。全体のフェードは両端にだけかかるので、プレビューで効き具合を確認するときに使います

フェードは書き出しと同じようにプレビューにも反映されます。全体のフェードとクリップのフェードが重なるフレームには両方がかかります。音声トラックごとのフェードは音声と BGMで、クリップの継ぎ目の切り替えはトランジションで設定します。

{% include docs-h2.html kicker="タイムライン編集" title="トランジション" %}

隣り合うクリップの継ぎ目に、切り替えの効果（トランジション）を付けます。継ぎ目のはさみを押して「つなぎ」を選ぶと、サイドバーの「つなぎ」（ドロワーの見出しは「トランジション」）がその継ぎ目にフォーカスして開くので、種類と長さを選びます。種類と長さはサイドバーだけで入力します（タイムラインの上では入力しません）。クリップが 1 つだけのときは継ぎ目がないため置けません。トランジションのある継ぎ目の側の端には、クリップのフェードを置けません。

種類
フェード / ディゾルブ / ワイプ（左へ・右へ）/ スライド（左へ・右へ）/ 黒フェード / 白フェード の 8 種類
置き方
タイムラインの継ぎ目の {% include icon.html name="Scissors" class="inline h-3.5 w-3.5 align-[-2px]" %} のバッジ（はさみ）を押し、メニューから「つなぎ」を選びます。サイドバーの継ぎ目の一覧（「前のクリップ → 次のクリップ」）でその継ぎ目の行が選ばれるので、種類を選び（「なし」で外れます）、長さを 0.1〜5 秒で指定します。置くと継ぎ目に前後のクリップが重なる長さの斜線の帯が出ます。前後のクリップがその長さだけ重なるため、映像全体はその分短くなります
帯とバッジ
斜線の帯をクリック（選んで Enter でも可）すると、メニューを経ずにサイドバーの「つなぎ」が開きます。バッジにマウスを乗せると、今の種類と秒数が表示されます
空白のある継ぎ目
空白（黒い画面）を挟んだ継ぎ目には置けません。サイドバーのその継ぎ目の行に理由が表示されます（空白は自動では詰めません）。設定した後で間に空白を作るとトランジションは効かなくなり、空白を詰めると元に戻ります
クリップのフェード
クリップのフェードが入っている継ぎ目では、行に「つなぎを置くとこの継ぎ目のフェードは書き出しで無視されます」と注記が出ます。フェードは自動では消えません
プレビュー
重なりのあいだは、前後のクリップを書き出しと同じ種類の切り替えで合成して表示します。後ろのクリップの側には、プレビューではモザイクが表示されません（書き出しではかかります）
